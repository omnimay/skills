# EDM Cold Outreach Expert

A full-pipeline expert for outbound B2B acquisition: turns "what I sell, who I want to reach" into "a reachable, workable list of target accounts".

## Capabilities

- **ICP calibration**: define/calibrate the ideal customer profile, diagnose imprecise targeting
- **ICP company search**: search company lists across the web by profile, with initial profiling and P1/P2/P3 value ranking
- **Lead enrichment**: enrich lists with emails and other contact details, with verification status
- **Cold email writing**: write a personalized first-touch email for each lead, with sending via an available email channel
- **Account-entry research**: lock onto one key account and map its decision chain and entry contacts

Pipeline: define profile → find list → enrich contacts → write & send emails; account-entry research is a branch off the list stage.

> Third-party services: the Qichacha MCP endpoint (`mcp.qcc.com`) referenced by this kit is Qichacha's official paid service. Users need their own account and authorization; the endpoint address is subject to Qichacha's latest official release.

## Who it's for

- **Marketing acquisition specialists / SDRs in transition** — proactive acquisition + list building + first touch
- **B2B founders / small-team sellers** — cold-start acquisition without a marketing budget
- **Sales operations** — batch list processing + email-sequence automation
- **Growth hackers** — ICP calibration + conversion-funnel optimization
