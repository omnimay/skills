# 决策链挖掘方法（references）

> 主 SKILL.md 阶段②③的落地技巧。**主线 = 找影响老板决策的核心人**，不是找大老板本人。

## 主线认知（先立住，别被"拍板人"带偏）

**老板会拍板"用不用"这个产品，但他不会亲自去了解和推这件事**。在老板拍板之前，可能**多个角色都向老板汇报各自看法**——业务侧（需求/ROI）、产品侧（方案/匹配）、技术侧（可行性/自研评估）、采购（成本/流程）——**但一定有一个核心主导/推进人物**：
- **牵头**：这事是他在推进、立项、协调
- **深入**：最了解这个产品/这事（需求发起人、业务负责人、部门负责人）
- **汇总**：把各方意见收拢，向老板做**最终主汇报/定论**
- **推动**：在内部替你说话、推着这事往前走

**这个"核心主导/推进人物"才是你要找、要触达、要搞定的对象**——搞定他，就等于打通了整条汇报链；只搞定某个汇报侧（如只有技术认同）而没搞定主导人，单子仍会卡住。

**偷懒的后果**：搜出 CEO/大老板就当"决策人"交付，销售打过去老板一脸茫然"这事我不清楚，你找 XX 吧"——第一通电话就暴露你没挖到真正影响决策的人。

## 怎么判断谁是"核心主导/推进人物"

在相关业务线/部门里，先摸清**有哪些人/角色在向老板汇报**（业务侧/产品侧/技术侧/采购），再从里面找**核心主导/推进人物**（不是按职位高低，是按"这事谁在牵头"）：
1. **牵头立项/推进的人**：谁在推动这事往前（立项、找供应商、协调）——通常是对口业务线/部门负责人（如卖会员SaaS→会员运营负责人；卖工程软件→工程管理/成本负责人）
2. **评估/把关人**：负责试用、比对、技术评估（技术负责人/IT/采购）——他的定论直接影响老板，但未必是主导人
3. **向老板做最终主汇报的人**：各方意见收拢后，谁向老板汇报"结论"——通常就是主导人本人或其上级
4. **推动者（Champion）**：在内部替你说话的人——可能是主导人，也可能是主导人信任的经办

**判断口诀**：问"这事如果老板要拍板，会有哪些人向他汇报？其中**谁是牵头主导、做最终定论汇报**的那个？"——多方汇报里的核心主导人，才是你要找的。

## 角色辅助视角（帮助分工，不是主线）

主线是找"影响老板决策的核心人"，下面的角色帮你识别不同分工，**不要为了填角色而填**：

| 角色 | 定位 | 与核心人的关系 |
|---|---|---|
| **EB（名义拍板人）** | 老板/高管，最终签字"用不用" | 不是你要搞定的人，是他信任的人（核心人）的意见决定他拍板 |
| **核心人（重点）** | 业务负责人/需求发起人/评估人，形成定论向老板汇报 | **你要找、要触达的人** |
| **TB（评估/把关人）** | 技术/采购，试用比对定标准 | 可能是核心人本人，或核心人团队的一员 |
| **UB（使用者）** | 真正用产品的人，痛点最真实 | 需求发起源头，可能是核心人的下属 |
| **Gatekeeper（信息把关）** | 前台/采购/财务控信息流 | 过路通道，不是决策人；**把采购经办当决策者是最常见陷阱** |

## 判断"影响核心人"在哪个层级

- **金额小/常规需求**：业务负责人/部门负责人就能定，老板只是走流程签字
- **金额大/战略级**：业务负责人评估定论 → 分管副总认可 → 老板拍板（核心人是业务负责人或分管副总）
- **首次引入新技术**：即使金额小，业务负责人也会上请（怕担责），核心人 = 业务负责人 + 技术评估人
- 拿不到按企业类型推断（国企盯流程/民企盯老板信任的人/外企盯中国区权限），标依据和置信度

## 挖掘途径（中国中层网上搜不到是常态，按序试）

1. **转介绍/提问技巧（最快）**：打总机/客服，靠提问把"信息员/前台"变"指路人"——"负责 XX 的是哪位？""这块采购谁评估？""这事归哪个部门牵头？"。**第一通电话产出目标 = 问出核心人的名字**
2. **官网 /about/team 页 + 新闻稿署名**：常露部门负责人名字和头衔；新闻稿"在 XX 主持下"是核心人线索
3. **招聘信号反推组织（中国差异化王牌）**：公开可见的招聘 JD"所属部门/向XX汇报"暴露部门归属和汇报线 → 部门负责人/需求发起人从这里挖；平台内对接人联系由用户在其账号自行操作
4. **年报/招股书高管简历 + 巨潮/同花顺 F10**：上市公司必走，简历正文段"自XX年起担任XX"反推业务线分管负责人（往往就是影响该业务线决策的核心人）
5. **周边联系人定位**：公开新闻/公告/署名交叉定位能联系到核心人的经办/同事；职场社交平台（脉脉等）上的搜索与询问由用户在其账号自行完成
6. **框架逐格填，找不到标 evidence gap（不编造）**
7. **工商外围**：招标联系人（财政部 87 号令法定公开姓名电话）/ 年报关联交易 / 协会理事 / 专利发明人 / 政府认定名单签字人

## 识别"还没触达真正影响决策的人"的信号

- 只给"找老板/找采购" → 还没找到核心人（真核心人是懂这事的业务人）
- 事事请示只会"转交" → 信息员/传声筒
- title 大但说"这事我不清楚，你找 XX" → 老板不是核心人，XX 才是
- 只谈参数不谈业务价值 → 评估人（TB）不是拍板汇报人
- "领导不见你" → 中基层还没把你引荐到核心人，或核心人不认可

## 证据分层（硬隔离）

- **真实命中**：两独立可点源确认人名+职位+公司 → 直接交付
- **混合**：单源 → 标"单源未验证"+二次核验路径
- **推导**：仅 fixture/记忆 → 标"fixture 推导"，不当真实核心人交付

**禁止把推导人物当真实核心人交付**——销售打了就是假目标。**人名主体归属自检**：每个具名人物挂所属主体全称，对不上直接删（防跨用例串名）。
