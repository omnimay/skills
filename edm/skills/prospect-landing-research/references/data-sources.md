# 通用数据源分层（中国渠道 + 来源替代）

> 供通用兜底分支 + 各分支通用字段使用。按可信度从高到低。

## 数据源优先级

1. **政府/官方**：ccgp.gov.cn 政府采购网 / 公共资源交易平台 / 国家企业信用信息公示系统 gsxt.gov.cn / 巨潮资讯（年报）/ 四库一平台（工程）
2. **客户自有**：官网（团队页/新闻稿/项目案例/采购公告）+ 官方公众号 + 年报/招股书/ESG
3. **招聘信息**：BOSS直聘 / 猎聘 / 智联**公开可见的职位描述**（搜索引擎收录/转载）——JD"所属部门/向XX汇报"反推组织结构；平台登录后页面与对接人联系由用户在其账号自行操作
4. **工商**：企查查 / 天眼查 / 爱企查（结构化字段走官方 MCP 或用户自有账号；公开摘要多源对齐：百度百科+投资界+36Kr+新京报+官网披露任二可点源）
5. **行业**：招投标 / 行业协会 / 奖项 / 峰会 / 媒体署名
6. **金融**：年报 / 招股书 / 同花顺 F10 / 雪球 / 智通财经 / 证券之星（HKEX 404 时二手源替代）
7. **专利/IP**：ipr 专利数据库（发明人 = 真实技术团队）
8. **社媒**：知乎 / 公众号（"XX总"线索）/ 脉脉（在职与架构核验由用户在其账号自行完成）
9. **二手源**：36Kr / 界面 / 网易 / 搜狐 / 新浪（36Kr 跳安全检测页 → 用其他家）

## 挖掘途径（按序试，中层网上搜不到是常态）

1. 转介绍/提问技巧（打总机"负责 XX 的是哪位"）——最快，第一通电话产出目标 = 问出名字
2. 官网 /about/team 页 + 新闻稿署名
3. 招聘信号反推组织（JD"所属部门/向XX汇报"，中国差异化王牌）
4. 年报/招股书高管简历 + 巨潮/同花顺 F10（上市公司必走）
5. 公开新闻/公告/署名交叉定位周边联系人；职场社交平台上的搜索由用户在其账号自行完成
6. 买委会框架逐格填，找不到标 evidence gap（不编造）
7. 工商外围：招标联系人/年报关联交易/协会理事/专利发明人/政府认定名单签字人

## 来源替代策略（主源不可达时）

主源不可达 → 36Kr/界面/网易/搜狐等其他媒体报道 → 多源对齐标"二手源"。数据源三态：✅原文核 / ⚠️多源对齐或二手源 / ❌未核。

## 在职验证（强制）

禁止用"没搜到近期活动"断言"在职存疑"（搜索盲区≠离职）——按"近 30 天履职行为"核验（新中标/新任命/新招聘帖/新合作新闻任一即"在职"，全无才"待核"）；查企查查任职退出记录是强信号。
