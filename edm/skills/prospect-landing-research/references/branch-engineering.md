# 工程分支 — 建筑/工程项目切入调研

> 第一版唯一分支，用于验证主框架通用性。执行到对应阶段时读本文件（阶段 1/2/3/5 用得到）。

## 分支定位

目标对象：工程项目、建筑公司、政府/国企项目。你卖什么通常是工程/造价/施工/BIM/项目管理类软件（如广联达类）。

## 阶段 1 · 对象定位与基本盘（工程版）

- **工程项目**：确认项目唯一（项目名/标段/地区/建设单位），防同名项目混淆。
- **建筑公司**：确认公司主体 + 资质等级（住建施工资质 = 承接能力）。

## 阶段 2 · 相关性与参与度（工程版）

卖造价/施工/项目管理软件 → 对口部门通常是：成本/造价部、工程管理部、招采部、BIM/数字化中心、信息化部、财务（合同额审批）。挖相关部门 + 权重 + 关键人。

## 阶段 3 · 决策链（工程版补充途径）

- 中标公告"项目管理团队"栏目：项目经理 / 技术负责人 / 履约对接人（**实名硬源**）
- 招标公告"采购人项目联系人"（财政部 87 号令法定公开姓名电话）——同一联系人跨项目反复署名 = 这块采购他负责
- 广联达类采购常走：招标技术要求 / 企业采购公告（直接采购/续费/授权号）→ 暴露决策经办

## 阶段 5 · 项目现状（工程版字段表）

| 字段 | 数据源 |
|---|---|
| 施工单位全称（分标段） | 全国公共资源交易平台中标公示 / 四库一平台项目库 |
| 项目经理姓名 | 中标公示"项目管理团队" / 四库一平台人员注册 |
| 项目部驻地位置 | 中标公示/招标文件 / 施工许可 / 公司公告 |
| 主要工程内容 | 招标文件 / 中标公示工程概况 |
| 合同金额 | 中标公示中标金额 / 四库一平台 |
| 当前施工进度 | 施工许可证（开工）→ 履约公示 → 政府工程进度公示 / 四库项目库 |
| 预计完工时间 | 中标工期 + 开工时间推算 / 竣工验收备案（已完工时） |
| 是否使用广联达产品 | 招标技术要求（GBQ6 格式/指定清单计价软件）/ 采购公告 / 造价岗JD要求 / BIM交付报告 |
| 上级公司(集团) | 股权穿透（企查查/天眼查/爱企查，多源对齐） |
| 建设单位(业主) | 招标人 / 中标公示建设单位 / 立项批复 |

## 核心数据源（免费权威）

1. **全国建筑市场监管公共服务平台（四库一平台）** jzsc.mohurd.gov.cn：施工企业资质、人员注册（项目经理实名）、项目库、诚信库
2. **全国公共资源交易平台 + 各省分平台**：中标公示（中标单位全称/项目经理/金额/工期/招标人）
3. **信用中国** creditchina.gov.cn：行政处罚/失信
4. **投资项目在线审批监管平台** tzxm.gov.cn：立项批复/建设单位/总投资
5. 公路（hwdms.mot.gov.cn）/ 水利（scjg.mwr.gov.cn）同构平台可迁移

## 来源替代（主源不可达时）

企查查/天眼查/爱企查公开摘要不可达 → 多源对齐（百度百科+投资界+新闻+官网披露任二可点源），结构化字段走官方 MCP 或用户自有账号；HKEX 公告 404 → 智通财经/证券之星/财华网二手源替代。
