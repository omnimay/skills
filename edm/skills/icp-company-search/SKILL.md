# ICP 检索/全网找公司

你是获客助手。用户给出客户特征或明确 ICP，你产出**客户名单**（含初步画像）。数据源按下表能力分层检索。

> **合规边界**：本 skill 面向用户自身的获客调研，仅使用公开企业信息与官方/授权通道（官方 API/MCP、用户自有账号、公开检索）。不绕过登录墙、验证码等访问控制，不对受限页面做自动化抓取；使用者自行确保遵守目标平台服务条款与《个人信息保护法》。

## 输入 / 输出

- **输入**：客户特征描述，或 icp-calibration 产出的画像结论（筛选条件、名单来源、信号检索词）
- **输出**：客户名单表（CSV/Markdown 表格），每行一家公司，含初挖摘要与来源列

## 主线流程

### 第 1 步：先估池子，再拉名单

检索前先用组合条件估算目标量级（搜索结果数、"第X批名单共N家"等），确认池子够大再拉全量。目标 100 家以上名单时按 1.5-2 倍超量拉取（经验值，覆盖后续折损）。

### 第 2 步：按数据源能力分层检索（按序使用）

**主力源：通用工商库（全行业通用——各行各业的 ICP 都先从这里圈公司）**

| 数据源 | 怎么用 | 通道（按优先级，断了换下一条） |
|---|---|---|
| 企查查 / 天眼查 / 爱企查 | 高级筛选组合圈公司：**国标行业 × 地域 × 参保人数 × 企业性质 × 成立年限**——全国企业全量覆盖，不受行业限制；直接输出公司名/法人/注册资本/联系方式等结构化字段 | ①企查查官方 MCP `https://mcp.qcc.com/basic/stream`（企查查的第三方收费服务，需用户自行开通账号与授权，额度以官方为准）②请用户在其自有账号内检索/导出名单 |
| 国家企业信用信息公示系统 gsxt.gov.cn | 官方权威工商全量，按名称/统一社会信用代码逐家精确核验与兜底验证；筛选能力弱，不做批量圈公司主力 | 请用户在官网自行查询后提供结果（匿名程序化请求返回 521；不绕过验证码） |

**补充源（工商库查不到的面，或给名单加信号）**

| 数据源 | 用法 | 说明 |
|---|---|---|
| 政府公示名单 | 搜索 `专精特新"小巨人"名单 公示 site:gov.cn`、`高新技术企业认定 名单 <地域>`——特定子集（政策认定企业）+ 官方背书信号。公示页正文通常只有企业名，联系方式可能在附件，遇到即记录不作为预期产出 | 公开可检索 |
| 巨潮资讯（上市公司及其作为角色的公告） | POST `https://www.cninfo.com.cn/new/hisAnnouncement/query`，表单参数 `pageNum=1&pageSize=20&tabName=fulltext&searchkey=<关键词>&isHLtitle=true`，可选 `seDate` 时间窗。无 UA 亦可访问；`column` 参数在 fulltext 下不改变结果（沪深北全覆盖），市别按 secCode 前缀判断（6/688=沪，0/30=深，8/4/92=北）；翻页 pageNum 递增、跨页按 secCode+announcementId 去重；标题含 `<em>` 标签入库前剥离 | 公开接口，支持关键词全文检索 |
| 招投标 | 政采面：中国政府采购网 search.ccgp.gov.cn（全量政采中标，官方源；站点有访问频率限制——控制请求间隔 ≥10 秒/次，仍受限即改用通用搜索或请用户自行查询）；综合面：招投标聚合站（剑鱼标讯等）首页/栏目页可直接读；逐条检索改用通用搜索 `公司名/行业 + 中标 + 年份` | 聚合站栏目页可直读；政采网需控制访问频率 |
| 融资事件库 | 融资数据库（IT桔子等）按 `公司名/行业 + 融资` 查轮次与时间——创投面信号源 | 页面为 JS 渲染，公开检索拿不到结构化数据时改用新闻搜索佐证融资信号 |
| 通用搜索信号 | 搜 `行业关键词 + (中标 OR 融资 OR 扩产 OR 招聘)` 取近期新闻，给名单加"为什么是现在" | 政务/新闻内容可用 |
| 行业协会/展会名录 | 搜索 `行业 + 协会会员名录 / 展会参展商名录`，抓静态页。头部展会名录常在 SPA/登录墙后——抓不到记入放弃路径，勿反复重试 | 命中率因行业而异 |

**兜底：语义搜索**（通用工商库通道全断、或 ICP 过概念化无法结构化筛选时）——用自然语言描述画像搜"行业报告/榜单/盘点"类文章，从文中提取公司名单，预期丢弃 30-50%。

**名单载体处理**：公示名单常见三种载体——网页正文表格（直接抓）、附件 PDF/Excel（下载解析文本；图片型放弃计入折损）、图片公示（同前）。gov.cn 老站常为 GBK 编码，乱码时按 GBK 转码重试一次。

**通道纪律**：一个源访问失败时，先分清**源不可用还是通道不可用**——匿名请求被拦（登录墙/验证码/521）只证明匿名通道不可用，不代表源不可用，依次换官方 API/MCP → 用户自有账号（用户自行检索/导出）→ 降级换源，不绕过访问控制。误把通道失败当源失败而放弃工商库，会只剩覆盖特定子集的片面源（政策名单只含认定企业、公告库只含上市公司，圈不了大多数行业主体）。逐请求间隔 ≥10 秒，遵守站点频率限制。

**不可行通道（指匿名通道，不绕过——换授权通道或换源）：**
- 企查查/天眼查/爱企查/gsxt 匿名抓取（登录墙/验证码/521）→ 走上方授权通道（官方 MCP / 用户自有账号）
- 融资数据库匿名抓取（页面为 JS 渲染空壳）→ 改用新闻搜索佐证
- 搜狗/百度/必应等搜索引擎直接匿名抓取（受限）→ 名单与信号搜索依赖具备语法过滤的联网搜索通道；仅有匿名抓取通道时跳过补充源，直接走兜底
- 中国政府采购网高频访问（"频繁访问"限制）→ 控制间隔 ≥10 秒，仍受限改用通用搜索

### 第 3 步：初挖（每家公司补最小画像）

对入围公司逐家补齐：主营业务（一句话）、地区、规模档位、命中信号（中标/融资/名单/招聘，注明信号日期）、与 ICP 的匹配理由。信息只写有来源的，查不到就标"未查到"，不编造。

名单拉够不等于完成——交付质量在逐家初挖，别把检索预算全花在建名单上。

### 第 4 步：去重与消歧

中国重名公司极多：同名公司用地域/法人/官网域名消歧，无法消歧的分行列出并标注。

### 第 5 步：价值排序

按信号强度与画像契合把名单分三档：**P1**（契合 + 近期强信号）/ **P2**（契合但信号弱）/ **P3**（无信号或存疑）。档位从各家的命中信号和匹配理由推出来，不是孤立判断；表后给 Top 3-5 家触达目标，每家一句"为什么先碰"。

### 通用纪律

- gov.cn/协会站点逐请求间隔 ≥10 秒（遵守站点频率限制）
- 每个源测一个查询词确认能出结果后再批量；批量中连续搜空 2-3 次即换词/换源

## 查不到时的备选路径（按序降级）

1. 行业词搜不出名单 → 换**产业集群/地域词**再搜（"佛山 家具 企业名录"）
2. 名单页抓不到正文 → 搜索 `名单关键词 + 转载/全文`（政府名单常被行业媒体全文转载）→ 若只是附件/图片形态，按"名单载体处理"解析，图片型放弃计入折损
3. 结构化条件过窄 → 放宽一个维度（先去行业限制或先去规模限制），拉回后再按 ICP 过滤
4. 上市公司信号查不到 → 该公司可能非上市：明确告知"非上市公司中标/融资信息无公开结构化源，改用新闻搜索"

## 输出格式

```
公司名 | 档位 | 地区 | 主营(一句话) | 规模 | 命中信号(类型+日期) | 匹配理由 | 来源(_source)
```
- 档位三值：P1（本周跟进）/ P2（持续观察）/ P3（暂不跟进）——第 5 步的排序结论，交付表头下加一行图例说明
- `_source` 列必须写来源（名单名/公告标题[剥掉 `<em>`]/文章标题），无来源的公司不进名单
- 表后给 Top 3-5 家触达目标（每家一句"为什么先碰"）
- 末尾附一行检索路径说明（用了哪些源、各贡献多少家、放弃了哪些路径及原因）

## 相关技能

- **icp-calibration**（上游）：用户只有模糊的客户特征、说不清筛选条件时，先做 ICP 校准再来找名单
- **lead-enrichment**（下游）：名单到手后补联系人邮箱与联系方式
- **prospect-landing-research**（支线）：名单里锁定某一家重点客户后，深挖决策链与切入点
- **cold-email**（下游）：拿名单+信号写首触达邮件
