# 证言/案例素材采集（evidence-collection.md）

> 主线步骤 2「采集证言/案例素材」的完整做法。采用四维评分/The Ask/draft-on-behalf/iteration 采集法 + 被动挖掘 + verbatim 原话提取，按中国场景替换数据源。

## 一、被动挖证言（优先，客户已经夸过的不用再问）

客户的好话散落在日常沟通里，先挖再 ask：

| 数据源 | 挖什么 |
|---|---|
| 微信/企微群聊 | 客户群里的认可、感谢、表扬截图（复用 首价值证明 微信证据收集法；注意隐藏其他客户信息） |
| 验收记录/验收报告 | 验收结论、达成指标 |
| QBR/首价值记录 | 客户认可的价值证据（`success-business-review` 产出直接转素材） |
| 朋友圈/客户公开分享 | 客户自己发的使用分享 |
| 通话/录音文字 | verbatim 原话提取（每条带 speaker-confidence + 来源 + 日期） |

**成功时刻分类**：quantified_result（量化结果）/ problem_solved（问题解决）/ team_praise / product_praise / recommendation_offer（主动推荐）/ renewal_enthusiasm / expansion_interest / general_satisfaction。每条标 testimonial_potential（excellent/good/moderate/low）。

**被动挖规则**：只挖客户真说出口的话，不加工不拔高；未授权的挖到的原话仅入内部素材库，对外需走分级授权。

## 二、主动 ask 三路

### 路 1：直接问 3 问（客户自己写）
```
1. 之前是什么情况/痛点？
2. 用我们的产品后改变了什么？
3. 你会推荐给同行吗？为什么？
```
微信版开场（中国）：「X 总，最近咱们这个季度合作挺顺的，方便花两分钟说说感受吗？我们想做点真实反馈放给同行看，您这边是权威。」要点：不施压、给选择、说明用途。

### 路 2：代写 draft-on-behalf（请客户确认）
规则：
- tone 匹配客户原话（翻微信/记录里的用词习惯）。
- 结构：Situation（一句话处境）→ Changed（交付了什么）→ Result（具体数字）→ Recommendation（自然推荐语）。
- **禁无据 superlative**（业界领先/一流/最先进）。
- **不加客户没说的数字**；估算必须标注「约」。
- 长度：短 50-75 字 / 中 100-150 字 / 长 200+ 字。
- 发给客户时明说「这是我替您拟的草稿，您改，改完才算数」。

### 路 3：邀请出镜/上案例
视频证言 / 案例访谈 / 发布会站台（走 L3/L4 授权流程）。先给客户价值（曝光/行业背书/联合宣传），再谈配合。

## 三、逼数字铁律

- 无数字不成证言。客户说「很好用」→ 追问：「具体省了多少/快了多少/涨了多少？rough estimate 也行，大概数字更有说服力。」
- 追问一两次仍无数字 → 用 proxy 语言兜底（「流程现在无需手工盯」），但该条素材质量档降级，不能当硬结果用。
- 数字入库必标来源（微信截图/验收单/QBR 记录）与日期。

## 四、四维质量评分（每条证言入库前必评分）

| 维 | 1 分 | 3 分 | 5 分 |
|---|---|---|---|
| Specificity | 无细节 | 泛泛提及 | 具体结果/场景 |
| Measurability | 「很好」 | 「明显改善」 | 「省了 40% 时间」 |
| Authentic Voice | 像广告词 | 略生硬 | 读起来像客户本人 |
| Length | 太短无上下文 | 偏薄 | 够三种格式用 |

**规则**：全 ≥4 才入库「可对外」；任一 ≤2 → 走 iteration（gentle 追问数字 → 仍无 → proxy 语言 + 档级降）。评分是采集的质量门槛，不是客户的评价。

## 五、三格式（入库时同步产出）

| 格式 | 结构 | 用途 |
|---|---|---|
| 短（2 行） | 首句 punchy outcome + 署名 | 官网证言墙/提案/朋友圈 |
| 中（2-3 句） | Problem → Changed → Result | 售前材料/案例摘要 |
| 长（叙事） | Context → Transformation → Results → 推荐语 | 案例页/白皮书/发布会 |

## 六、证言素材卡模板

```
## 证言素材卡：<客户名> — <日期>
### 来源：微信截图 / 验收记录 / QBR 记录 / 通话文字 / 主动 ask
### 原话（verbatim）："..."
### 数字：<指标 + 数值 + 来源 + 日期>
### 四维评分：Specificity x/5 · Measurability x/5 · Voice x/5 · Length x/5
### 格式：短/中/长（按需出）
### 建议层级：L<0-4>（待授权流程确认）
### 成功时刻类型：<八分类之一>
### 授权状态：Documented / Verbal / Not documented
```
