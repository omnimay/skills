# 可代言客户判定（candidate-qualification.md）

> 主线步骤 1「识别可代言客户」的完整判定方法。采用硬限/软限/打分判定 + 候选池分层，按中国场景改造。

## 一、三维判定（先过三维，再谈授权）

| 维 | 问 | 不过关的信号 |
|---|---|---|
| 价值兑现 | 有可量化的结果数字吗（outcomes 非 activities） | 无数字 → 先回 `success-business-review` 补价值证据，证据到手再回本场景 |
| 关系好 | 满意度/关系温度计到温了吗 | 客诉中、温度计冷、健康分 At Risk |
| 有意愿 | opt-in 三档到哪了 | 未授权且无配合史 |

**价值未兑现回补法**：无数字不入候选池。回 `success-business-review` 收复盘记录或首价值证据（outcome + baseline→target 进度），拿到数字再回本场景判定。禁止用「客户说挺好」替代可量化结果。

**关系温度计**（中国改造，替代海外 referenceable 字段）：冷/温/热/铁 四档。来源 = 满意度回访 + 客诉记录 + 最近互动（QBR 出席率/微信响应率/续约意向）。

**opt-in 三档**：
- Documented：已书面授权可代言（记录授权文件编号/日期）。
- Verbal：口头认可未记录（可做 L1-L2 前置，升 L3+ 前必须书面补录）。
- Not documented：未授权（最多 L0-L1，且需走授权流程才能升）。

## 二、三阶判定（硬限 → 软限 → 打分）

### 硬限（任一命中 = 卡死，不算分，直接不配被代言）

| 硬限 | 说明 |
|---|---|
| 价值未兑现 | 无可量化结果数字 |
| 关系温度计冷 | 客诉中/健康 At Risk/满意度回访差 |
| 180 天内 ≥3 次代言 ask | 频控超限（任何联系人/账户级） |
| 上次代言完成 <21 天 | 静默期未过（联系人级） |

命中硬限 → 返回原因 + 具体数据（分数/日期/次数），不给替代路径，不软化。

### 软限（命中 = 标记，交 CSM 把关后才可用）

| 软限 | 说明 |
|---|---|
| 无 opt-in 记录 | 未书面授权 |
| 90 天内第 2+ 次 ask（联系人级） | 频次偏高 |
| 连续 2 次拒绝 | 意愿存疑 |
| 合作 <6 个月 | 关系未稳 |

### 打分定档（无硬限时算分）

| 维 | 分值 | 计分 |
|---|---|---|
| 价值兑现 | 30 | 有数字且客户认可 30 / 有数字我方估算 20 / 无数字 0（硬限） |
| 关系 | 30 | 铁 30 / 热 25 / 温 15 / 冷 0（硬限） |
| 意愿 | 40 | Documented 40 / Verbal 25 / Not documented 10 |

| 总分 | 档位 | 动作 |
|---|---|---|
| ≥70 | 可代言 | 可走 L2+ 授权流程 |
| 50-69 | 条件性 | 软限项交 CSM 确认后可用 |
| <50 | 不可代言 | 不进资产库，记回访提升计划 |

## 三、疲劳管理（防代言透支）

- **频控**：同一账户 180 天内 ≤3 次代言 ask；同一联系人 90 天内 ≤1 次。
- **静默期**：上次代言完成（含被拒绝）后 21 天不打扰。
- **轮换**：标记「高频代言」客户，新客户代言优先于老客户；每次 ask 记录入库（谁/何时/类型/结果）。
- **单一事实源**：代言状态集中一处管理，防两个销售同时找同一客户。

## 四、最优联系人选择（未指定时的优先级）

1. 已授权代言 champion（历史 ask 完成者/显式 opt-in）。
2. 高满意度者（满意度回访/微信群积极发言者）。
3. 长任期 exec/决策层（title 带总/长）。
4. 主 CSM 联系人（兜底）。

选择后给一句理由；CSM 可能有记录外的信息，尊重其否决。

## 五、判定输出模板

```
候选客户：<名> | 联系人：<名/title>
三维：价值兑现(<数字>) / 关系(<温度计档>) / 意愿(<opt-in 档>)
硬限：无 / <原因+数据>
软限：<列表或空>
打分：<值>/100 → <档位>
疲劳记录：<近180天 ask 次数 / 上次完成日期 / 连续拒绝数 / 合作时长>
建议层级：L<0-4>
```
