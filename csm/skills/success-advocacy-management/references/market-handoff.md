# 市场物料交接（market-handoff.md）

> 主线步骤 4「对接市场物料」的完整做法。采用引荐运营五步法（intake→match→logistics→post-call→governance）+ 单一事实源原则。本 skill 管源头，物料制作归下游。

## 一、交接边界

本 skill 产出**源头资产**（证言原话/数字/授权层级/客户清单），物料制作（PPT/案例文档/官网页面）与投放运营归市场团队。交接单随资产走，标注授权层级与可用范围，市场拿到的直接是「可用的料」。

## 二、交接单模板

```
## 市场物料交接单 — <日期>
### 证言素材卡（N 条）
- <客户> | <原话摘要> | <数字> | 四维评分 | 层级 L2 | 授权状态已确认 | 三格式已备
### 案例摘要（N 个）
- <客户> | <场景> | <数字> | 层级 L3 | 授权书编号 | 审核通过日期
### 标杆客户清单（N 个）
- <客户> | <行业> | <可站台形式> | 层级 L4 | 一把手确认日期
### 待授权项（N 个）→ 授权流程进行中，先不用
### 交接去向（市场团队）
- 案例物料：<案例文档/PPT/白皮书>
- 投放渠道：<官网/公众号/发布会>
### 月报 scorecard
- 本月新增证言 x / 新授权 x / 被引用 x 次 / 参考电话 x 场 / 预估成交影响 <值>
```

## 三、临时参考请求快速匹配

售前/销售要参考（标书/客户来访/竞标答辩）→ 快速匹配：

| 匹配维度 | 优先规则 |
|---|---|
| 行业 | 同行业 > 同细分 > 泛行业 |
| 场景/use case | 同场景 > 同功能 > 泛场景 |
| 语言/规模 | 客户对标规模优先 |
| 层级 | 优先已授权 L3+；L2 仅引语 |
| 疲劳 | 标记高频代言客户，轮换 |

匹配必带：客户授权状态 + 层级 + 疲劳状态 + 话术要点。**未授权客户一律不匹配给外部参考**（哪怕是口头应酬，给名单前先确认授权）。

## 四、月报 scorecard（向市场/领导要资源）

- 资产健康：新增证言数 / 素材库总数 / 授权覆盖率。
- 使用量：被引用次数（官网/销售材料/提案）/ 参考电话场次。
- 影响：参考电话×成交率、评论量×受影响管线、AI 引用量（第三方平台对产品的提及）。
- 缺口：缺哪个行业/场景的素材 → 下月采集重点。

## 五、单一事实源纪律

- 代言状态/授权状态/疲劳状态集中一处维护，禁止散落在各销售微信里。
- 每次 ask/授权/发布都更新记录（谁/何时/类型/结果），防两个销售找同一客户。
- 对外发布版本与授权确认版必须一致；不一致 = 违规发布，整单返工。
