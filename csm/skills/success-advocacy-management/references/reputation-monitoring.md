# 口碑监测与改进（reputation-monitoring.md）

> 主线步骤 5「NPS/口碑监测与改进」的完整做法。采用 NPS 聚合/参考电话五问 + 中文案例实践（满意度回访/度量证明），NPS 按中国场景改造。

## 一、NPS 中国改造

中国 B2B/政企客户填 NPS 的比例低，NPS 只能当辅助信号，不能当主判：

| 海外 | 中国改造 |
|---|---|
| NPS 9-10 高分触发代言 | 满意度回访（定期电话/微信回访）+ 客户关系温度计（冷/温/热/铁）为主判 |
| NPS 是唯一满意信号 | NPS（如有）作辅助加分，微信群活跃度/验收好评/续约意向作补充信号 |
| NPS 公开统计 | 内部用，客户面不晒分 |

## 二、满意度回访

- **触发时机**：上线后 30/90 天 + 业务回顾后 + 客诉处理后。
- **回访问题**（微信版，<3 问）：用得顺不顺？最值的一处是什么？有没有想改进的？
- **记录**：回访结果入温度计（冷/温/热/铁）+ 口碑信号捕获（客户顺口说的好话直接入采集池）。

## 三、口碑信号捕获（入资产库）

| 信号 | 来源 | 动作 |
|---|---|---|
| 微信群夸/感谢 | 客户群 | 截图入库（隐藏他客信息）→ 待授权 |
| 验收好评 | 验收记录 | 入采集池 |
| 朋友圈主动分享 | 客户朋友圈 | 记录 → 客户意愿加分 |
| 转介绍苗头 | 客户主动问「有没有同行需要」 | 记录 → 交接 `success-referral-generation`（本 skill 不追线索） |

**温度计规则**：信号升温（热/铁）→ 该客户可升级代言层级候选；温度降（冷）→ 移出候选池，先做挽回（交接续约/流失挽回）。

## 四、度量证明（向市场/领导要资源）

| 度量 | 算法/口径 | 说明 |
|---|---|---|
| 参考电话 ROI | 参考电话场数 × 平均成交额 × 参考支持成交率提升 | 证明参考程序价值 |
| 评论/证言影响 | 评论增长量 ↔ 受影响管线/成交速度 | 有参考支持的成交更快/更大 |
| AI 引用量 | 第三方平台对产品的提及量/排名 | LLM 决策时代口碑新信号 |
| 授权覆盖率 | 已授权素材 / 素材库总数 | 资产「可用率」 |

度量结果月更，进 market-handoff 月报 scorecard。

## 五、监测改进闭环

```
满意度回访 → 口碑信号捕获 → 温度计更新
  → 温度升：升级代言候选 → 回识别步骤
  → 温度降：移出候选 → 交接挽回/续约
  → 度量月报 → 市场/领导 → 资源 → 回采集步骤
```

## 六、Reference Call 五问（售前参考对话参考）

| 类 | 问题 |
|---|---|
| Problem/Solution | 解决什么问题？当时还考虑过什么方案？ |
| Implementation | 实施过程如何？多久见效？ |
| Value Delivered | 拿到了什么结果？ROI 如何？ |
| Relationship | 团队响应如何？会推荐吗？ |
| Future | 有扩展计划吗？有没有顾虑？ |

五问用于参考对话提问框架（客户已授权 L3+ 才能安排），产出回填证言素材库。
