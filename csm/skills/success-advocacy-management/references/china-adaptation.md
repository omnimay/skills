# 中国适配（china-adaptation.md）

> 本 skill 相对海外 advocacy/reference program 方法论的中国化差异总表。

## 一、中国式「标杆客户」行业惯例

海外用「advocacy program / reference program」，中国 B2B 惯用：

- **标杆客户**：重点经营头部客户，做成行业标杆，供新客户对标。
- **案例中心**：官网「客户案例」栏目 + 行业/场景分类，售前标书直接取用。
- **发布会/授牌**：标杆客户授牌、战略合作挂牌、发布会联合演讲——客户的「政绩感」诉求。
- **行业评选/示范单位**：客户要的是行业地位背书，与厂商联合申报。

判断要点：**客户代言在中国更强调「对等背书」**——客户图的是曝光/政绩/行业地位，厂商图的是可信社会证明，价值交换必须双方都算得清账。

## 二、决策层三层与授权链

中国决策层三层：一把手（拍板）/ 分管副总（分管）/ 部门负责人（执行）。对外宣传涉及客户名义的：

- L2 署名证言：对接人确认即可（一般部门负责人/客户经理）。
- L3 案例出镜：分管副总/项目负责人签字授权。
- L4 标杆站台：一把手/分管副总确认 + 法务 + 市场。

**铁律**：授权对象要「对得上号」——找的是有权对外承诺的人，不是执行层随口答应。

## 三、微信/企微采集通道（替代 email/NPS）

海外靠 email 收证言、NPS 触发 ask，中国政企客户不发 email、不填 NPS：

- 证言收集主通道 = 微信/企微群聊、验收记录、业务回顾会（复用 首价值证明 微信证据收集法）。
- 主动 ask 开场走微信/企微，不群发邮件。
- 客户原话带截图来源（隐藏他客信息），避免截图泄露其他客户。

## 四、央企国企反腐红线

- 价值交换以非货币为主：曝光/行业背书/授牌/联合宣传/行业论坛席位。
- 礼品/实物激励额度受限，先与客户采购/合规对齐；严禁用「给回扣」换证言。
- 效果数据要经得住审计（广告法 + 客户内部审计双重要求）。

## 五、合规红线（个保法/广告法/保密协议）

1. 客户信息对外发布需客户书面授权（个保法个人信息处理合规基础）。
2. 效果数据不夸大、不误导（广告法对虚假/引人误解宣传的限制）。
3. 技术方案描述不泄商业秘密（保密协议约束）。
4. 授权书 + 审核链 + 归档是硬流程，不是建议。

## 六、NPS 与满意度

NPS 在中国 B2B 覆盖率低 → 满意度回访 + 关系温度计（冷/温/热/铁）为主判，NPS 作辅助。详见 `reputation-monitoring.md`。

## 七、与海外 skill 的做法对照

| 海外做法 | 本 skill 处理 |
|---|---|
| email testimonial ask | 微信/企微 ask + 被动挖群聊/验收 |
| NPS 高分触发 | 满意度回访 + 温度计 |
| referenceable 字段 | 温度计 + opt-in 三档 + L0-L4 层级 |
| NDA/consent | 书面授权书 + 多部门审核 + 发布前终审 |
| referral ask 同场 | 转介绍交接 `success-referral-generation`（本 skill 不追） |
| 礼品卡激励 | 非货币价值交换为主（曝光/背书/授牌） |
