# 4 维可挽回性评分细则（拒绝救错客户）

> 目的：拒绝救错客户（占用 CSM 时间、挤压其他客户、损害团队士气）。4 维评分给「值不值得追」的客观判定。
> 方法论来源：OneWave renewal-predictor 健康分模型（7 维加权，MIT）+ 4 维评分骨架（Time/Depth/Champion/Signal）。

## 一、4 维评分细则

每维 1-5 分（5=最有利于挽回，1=最难挽回）。

### 维度 1：Time 触发新鲜度（权重 25%）

**判定逻辑**：流失事件距今多久？决策是否可逆？

| 分 | 触发新鲜度 | 时间范围 | 行动建议 |
|---|---|---|---|
| 5 | Fresh | 0-30 天 | 立即启动挽留，决策未固化 |
| 4 | Fresh | 31-90 天 | 高优处理，2 周内首次接触 |
| 3 | Recent | 91-180 天 | 标准挽留，1 月内首次接触 |
| 2 | Stale | 181-365 天 | 仅做主动发掘，触发升级才深度介入 |
| 1 | Stale | >365 天 | 基本放弃，转团队避坑沉淀 |

**判定要点**：
- 「流失事件」= 客户明确不续约/停用/竞品替换生效/公司解散日（不是合同到期日）
- 政企客户「过紧日子」专项期可放宽到 6 个月（财年节奏差异）
- 客户主动询价/老同事打听 = Fresh 重新计时

### 维度 2：Depth 关系深度（权重 25%）

**判定逻辑**：客户历史合作多深？是否多层级覆盖？合同额多大？

| 分 | 关系深度 | 判定 |
|---|---|---|
| 5 | 战略级 | 多层级覆盖+共建案例+合同额>100万+多次续约 |
| 4 | 深度合作 | 多层级+合同额>50万+曾共建 |
| 3 | 标准合作 | 单层级 champion+合同额 20-50万 |
| 2 | 浅接触 | 1 个浅对接+合同额<20万 |
| 1 | 一次性 | 仅 1 次 POC/试用+无续约 |

**判定要点**：
- 「多层级」= champion（使用层）+ 部门负责人（业务层）+ 副总/总监（决策层）均覆盖
- 「共建案例」= 客户主动参与过产品迭代/案例包装/标杆参观
- 「战略级」客户即使 Time = 1 也值得追（战略价值 > 时间衰减）

### 维度 3：Champion 留存（权重 30% — 最高权重）

**判定逻辑**：原 Champion 还在不在？是否有备份 Champion？

| 分 | Champion 状态 | 判定 |
|---|---|---|
| 5 | 原 Champion 还在+活跃 | champion 朋友圈/微信群活跃，仍表态支持 |
| 4 | 原 Champion 在但失权 | champion 还在公司但失去决策权，需新决策层 |
| 3 | 新 Champion 已识别 | 原 Champion 走了+新对接人已出现可触达 |
| 2 | 无备份 Champion | 原 Champion 走了+无新对接人，需主动发掘 |
| 1 | 全部离开 | champion+决策层+对接人全部离职/解散 |

**判定要点**：
- **最高权重（30%）**——Champion 是触达决策层的钥匙，没有钥匙打不开门
- 中国特有「**领导换届**」根因 → Champion 多半状态 = 2 或 3
- 「新 Champion 已识别」≠「新 Champion 愿意接」——3 分是「可触达」，4 分是「愿意支持」

### 维度 4：Signal 重新打开信号（权重 20%）

**判定逻辑**：客户有任何重新打开的信号吗？

| 分 | 信号强度 | 判定 |
|---|---|---|
| 5 | 主动信号 | 客户主动询价/咨询/老同事打听/朋友圈互动 |
| 4 | 半主动 | 客户群未拒绝互动/朋友圈点赞/饭局口头表态 |
| 3 | 中性 | 无明显信号，但客户群未删除 |
| 2 | 被动拒绝 | 客户群不回消息/邮件已读不回 |
| 1 | 明确拒绝 | 客户拉黑/明确表态「不合作」/合同已签竞品长约 |

**判定要点**：
- 「主动信号」= 客户在微信/朋友圈/老同事圈主动提及或询问
- 「明确拒绝」= 客户合同已签竞品（如签 3 年），挽回概率 < 5%，基本 No
- 朋友圈点赞/评论 = 半主动信号（4 分），微信群未拉黑 = 中性（3 分）

## 二、复合分公式 + 5 档判定

```
复合分 = Time × 0.25 + Depth × 0.25 + Champion × 0.30 + Signal × 0.20
```

| 档位 | 分数 | 行动 | 投入产出比 |
|---|---|---|---|
| 🟢 Definitely | 4.0-5.0 | 立即启动挽留，CSM+销售+决策层三层介入 | 高（优先） |
| 🟢 Likely | 3.0-3.9 | 高优处理，2 周内首次接触 | 高 |
| 🟡 Possible | 2.0-2.9 | 标准挽留，1 月内首次接触，挂账监控 | 中 |
| 🟠 Marginal | 1.0-1.9 | 仅做主动发掘，触发升级才深度介入 | 低 |
| ⚫ No | <1.0 | 团队避坑沉淀为主，不投入挽留 | — |

**判定原则**：
- 复合分取 1 位小数
- 档位优先级：Definitely > Likely > Possible > Marginal > No
- 任一维度 = 1 且无补救可能 → 直接降档到 Marginal 或 No（单项否决）

## 四、案例

### 案例 1：政企客户领导换届（4 维评分 4.0 → Definitely）

- **Time = 5**：30 天内决策（合同到期 15 天）
- **Depth = 4**：多层级覆盖+原合同 80 万+曾共建案例
- **Champion = 3**：原 Champion 调岗+新对接人已出现（决策层办公室副主任）
- **Signal = 4**：客户群未拉黑，新对接人朋友圈点赞

复合分 = 5×0.25 + 4×0.25 + 3×0.30 + 4×0.20 = 1.25 + 1.00 + 0.90 + 0.80 = **3.95 ≈ Definitely**

行动：决策层介入 + 微信企微群重建 + 决策层饭局。

### 案例 2：民营客户被竞品替换（3 维评分 3.0 → Marginal）

- **Time = 3**：120 天前合同到期（Stale 边界）
- **Depth = 3**：单层级 champion+合同额 30 万
- **Champion = 2**：原 Champion 离职+无新对接人
- **Signal = 2**：客户群不回消息，邮件已读不回

复合分 = 3×0.25 + 3×0.25 + 2×0.30 + 2×0.20 = 0.75 + 0.75 + 0.60 + 0.40 = **2.50 → Possible**

但 Champion = 2 + Signal = 2（无主动信号），单项否决 → 降档 Marginal。

行动：仅做主动发掘（老同事打听/客户大会），触发升级才深度介入。

### 案例 3：央国企预算冻结（4 维评分 4.1 → Likely）

- **Time = 4**：60 天（合同到期 30 天后客户邮件反馈）
- **Depth = 5**：战略级+共建案例+合同额 150 万
- **Champion = 4**：原 Champion 在但失权，新 Champion 已识别（财务总监）
- **Signal = 3**：客户群未删除，但客户主动表态「过紧日子」

复合分 = 4×0.25 + 5×0.25 + 4×0.30 + 3×0.20 = 1.00 + 1.25 + 1.20 + 0.60 = **4.05 → Likely**

行动：多年期+缩年限 + 共建 90 天成功计划 + 等财年 Q1 预算重启期。

## 五、评分常见错

1. **不评 Time 直接打高优**：>180 天的 Stale 客户救回来概率 < 10%，但 Depth 高 + Champion 仍在会让评分虚高。Time 必须独立判定。
2. **Champion 维度打 5 分因为「在原公司」**：原 Champion 在但失权是 4 分不是 5 分——能否触达决策层是关键。
3. **Signal 维度忽略被动拒绝**：客户拉黑 = 1 分，不能因为「还在客户群」给 3 分。
4. **复合分 = 4.0 直接 Definitely 但某维度 = 1**：单项否决 → 降档。
