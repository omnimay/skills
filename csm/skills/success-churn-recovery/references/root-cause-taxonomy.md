# 根因 Taxonomy — 10 大类（中国 B2B 流失）

> 方法论来源：6 大类 + 36 子类沿用 [OneWave churn-autopsy](https://github.com/OneWave-AI/claude-skills/blob/main/churn-autopsy/references/root-cause-taxonomy.md)（MIT），另新增中国式 4 类。
> 主根因选 1 + 辅因 0-3 个；每类带识别信号 + 占比权重（影响挽回策略选择）。

## 一、沿用 OneWave 6 类

> OneWave churn-autopsy 的 6 类共 36 子类，本 skill 沿用。

### 1. 产品缺口（Product Gap）

**典型症状**：缺功能/坏功能/超规模/UX 差/性能差/集成失败/安全合规缺口。

**识别信号**：客户在 QBR 中反复提某功能缺失；工单集中在某模块；客户侧使用率持续下降。

**影响权重**：30% 上下（产品难改，挽回难度高）。

### 2. 关系失败（Relationship Failure）

**典型症状**：CSM 失职/CSM 频繁换/信任崩塌/高管不对齐/响应慢/文化冲突/入门失败。

**识别信号**：CSM 调动记录；客户邮件抱怨响应慢；高管未见面；入门期投诉多。

**影响权重**：15-20%（关系线断=重接成本高）。

### 3. 预算财务（Budget/Financial）

**典型症状**：预算削减/ROI 未证明/价格敏感/供应商整合/采购变更/经济下行。

**识别信号**：财年 Q4 突然沉默；客户邮件提「预算紧缩」；降级请求。

**影响权重**：25-30%（海外标准做法折扣即可挽回，但中国慎用）。

### 4. 竞品赢得（Competitor Win）

**典型症状**：功能超越/价格碾压/捆绑销售/关系杠杆/市场叙事/老供应商回潮。

**识别信号**：客户提及竞品名字；招标公告比价；RFP 邀标。

**影响权重**：20-25%（差异化必须显式）。

### 5. Champion 失（Champion Loss）

**典型症状**：Champion 离职/降权/疲劳/无备份/新领导/重组。

**识别信号**：朋友圈突然不互动；客户群沉默；新决策层头像变更。

**影响权重**：30-35%（最常见根因之一）。

### 6. 战略变更（Strategic/Organizational Change）

**典型症状**：M&A/业务转型/裁员/自建/合规变更/退出市场。

**识别信号**：天眼查 M&A 记录；公司业务公告；行业新闻。

**影响权重**：30%+（战略变更难逆，但可等窗口）。

## 二、新增中国式 4 类（差异化补齐 — 海外未覆盖）

### 7. 领导换届（中国特有）

**典型症状**：Champion/决策层调岗/转岗/退休/提拔；新领导带自有供应商偏好。

**识别信号**：
- 微信群突然沉默（决策人不发言）
- 决策人朋友圈头像/风格突变
- 公司组织架构调整公告
- 新领导上任后「调研/盘点」动作
- 朋友圈/脉脉出现新领导发言

**影响权重**：35-40%（**中国最常见根因之一**——领导换届 = 供应商洗牌）。

**挽回判定**：原 Champion 还在=高优（warm reach）；原 Champion 已走+无备份=Medium（必须新 Champion 重接）。

### 8. 国产化替换（中国特有）

**典型症状**：信创/等保 2.0/合规审查强制替换；客户公司被纳入国产化目录；新采购流程卡信创要求。

**识别信号**：
- 招标公告「国产化优先」「信创目录」
- 等保 2.0 测评报告要求
- 客户公司被纳入「国产化替代目录」
- 领导讲话提及「自主可控」
- 同行/竞争对手已发布国产化版
- 客户主动询问「你们有信创版吗」

**影响权重**：40-50%（**最难逆**——政策驱动，无差异化空间）。

**挽回判定**：
- 有信创/等保合规材料 = Likely（出方案 + 等政策细则）
- 无信创/等保材料 + 政策窗口未关 = Marginal（先出材料，再等窗口）
- 无信创/等保材料 + 政策窗口已关 = No（放过，转增购钩子）

### 9. 预算冻结（中国特有 — 海外有但驱动不同）

**典型症状**：财年紧缩/编报延期/审计/暂停非必要支出；**不一定是真没钱，是预算窗口关闭**。

**识别信号**：
- 财年 Q4 突然沉默（11-12 月）
- 采购流程卡编报（次年预算未批）
- 领导表态「过紧日子」「降本增效」
- 合同到期静默不续（**不是主动不续，是流程卡住**）
- 朋友圈/客户群出现「审计」相关
- 央国企/政府「过紧日子」专项通知

**影响权重**：20-30%（**窗口判定是关键**——Q1/Q2 重启期重新开口）。

**挽回判定**：
- 财年 Q1（3-5 月） = Likely（预算重启期）
- 财年 Q2（6-8 月） = Possible（视预算落地）
- 财年 Q3-Q4（9-12 月） = Marginal（窗口已关，转下一年）
- 跨年预算延期 = 盯紧编报节点

### 10. 采购竞品替换（中国特有 — 流程驱动）

**典型症状**：招标流程/集采/比价压价；客户采购线「换品牌」指令；**不是产品不行，是采购线流程强制**。

**识别信号**：
- 招标公告（中国招标投标公共服务平台 + 地方公共资源交易）
- 集采目录（央国企/政府集中采购）
- 采购线 KPI 调整（降本/换品牌）
- 比价流程（3 家以上询价）
- 客户主动透露「采购流程要求」

**影响权重**：25-35%（**流程驱动=可干预**——招标策略 + 多年期打包）。

**挽回判定**：
- 招标未发 = Likely（提前介入 + 关系维护）
- 招标已发但未开标 = Possible（递交差异化方案 + 比价防御）
- 招标已开标 + 竞品中标 = Marginal（保留续标机会）
- 招标已开标 + 客户已签长约 = No（放过）

## 三、根因分类操作要点

### 主根因判定 3 步法

1. **病史重建证据匹配**：把 12 项证据归类到 10 类，看哪类证据最多。
2. **外部信号交叉验证**：招聘/工商/招标/新闻信号确认内部推测。
3. **客户主动表态优先级最高**：客户邮件/口头/朋友圈明确说的原因，权重 > 推断。

### 辅因识别（0-3 个）

- 辅因 = 不是触发主因但是「加速/加重」主因的因素
- 辅因百分比权重 = 客户表态中提及的频次/印象比例
- 辅因影响 pathway 叠加（主因走 path A，辅因加 path B 的部分动作）

### 百分比权重示例

```
主根因：领导换届（60%）
辅因 1：关系失败-CSM 频繁换（25%）
辅因 2：预算冻结-财年紧缩（15%）
合计：100%
```
