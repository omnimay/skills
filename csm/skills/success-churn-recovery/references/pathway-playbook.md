# Pathway 选择法（5 条路径按主根因走分支）

> 主根因决定 pathway——选错 path = 救不回来。本 skill 设计 5 条 pathway，按根因 taxonomy 主根因走分支（速查表见根因 taxonomy 文件末）。
> 注：本 skill 对象是已流失客户；未流失但停滞的死单场景同构适用。

## 一、5 条 Pathway 总览

| Path | 触发（主根因） | 核心思路 | 中国差异化 |
|---|---|---|---|
| **A. 新 Champion 重接** | Champion 失 / 领导换届 / 关系失败 | 找新决策层，重建关系线 | 微信企微群重建 + 决策层饭局 + 一页纸 |
| **B. 预算重启期** | 预算冻结 / Budget-Financial | 等财年/Q4/审计过窗口 | 多年期+缩年限+匹配预算周期 |
| **C. 合规窗口** | 国产化替换 / 合规变更 | 等政策细则+出合规材料 | 信创适配证明+等保 2.0 材料 |
| **D. 采购竞品重投** | 采购竞品替换 / Competitor Win | 招标策略+比价差异化 | 招标双平台+集采打包+多年期 |
| **E. 价值重述** | 产品缺口 / ROI 未证明 / Champion 疲劳 | 业务回顾+价值证据包 | 现场标杆参观+共建典型场景+POC 重做 |

## 二、Path A：新 Champion 重接（最常见 — 中国领导换届高发）

### 触发条件

- 主根因 = Champion 失 / 领导换届 / 关系失败
- 原 Champion 走了或失权，无触达决策层的钥匙
- 客户公司仍存在，未解散/未 M&A

### 核心动作（4 步）

1. **找新决策层**（5 工作日）
   - 朋友圈/脉脉/LinkedIn 找新对接人
   - 老同事打听（CSM/Sales 私人网络）
   - 客户群观察（看谁在活跃发言）
   - 公司组织架构公告/招聘官网验证

2. **微信企微群重建**（10 工作日）
   - 把新决策层拉入企微群（不是 cold add，先通过中间人引荐）
   - 群内定期发价值证据包/案例（不要直接开口挽留）
   - 朋友圈点赞/评论建立弱连接
   - 决策层朋友圈主动互动（评论不刷屏）

3. **决策层饭局**（15 工作日）
   - 通过中间人约饭局（不是 cold call）
   - 饭局上不开口挽留，先聊行业/政策/趋势
   - 临走前送一份价值证据包（纸质版+一页纸）
   - 饭后朋友圈互动强化关系

4. **一页纸 + 决策层汇报**（20 工作日）
   - 一页纸内容：客户原合作成果 + 价值证据 + 新决策层视角的差异化
   - 决策层汇报：约会议或饭局二次跟进
   - 决策层愿意听 = 关系线建立，进入价值重述阶段

### 成功标志

- 新决策层愿意见面+听汇报
- 企微群活跃（新决策层发言>3 次/月）
- 朋友圈互动稳定

### 失败 fallback

- 30 天无触达 → 转入 Marginal 档
- 新决策层明确拒绝 → 团队避坑沉淀
- 客户公司解散 → 团队避坑沉淀

## 三、Path B：预算重启期

### 触发条件

- 主根因 = 预算冻结 / Budget-Financial
- 客户表态「过紧日子」「预算紧缩」或合同到期静默不续
- 中国财年节奏：央国企/政府 Q4（11-12 月）冻结，Q1（3-5 月）重启

### 核心动作（4 步）

1. **判定财年节奏**（立即）
   - 央国企/政府：财年 1-12 月，Q4 冻结，Q1 重启
   - 民营企业：财年 1-12 月或 4-3 月，看客户惯例
   - 外企：财年 7-6 月或 10-9 月，看总部节奏

2. **多年期 + 缩年限方案**（预算重启前 30 天）
   - 多年期（2-3 年）：客户预算可分期，单年压力小
   - 缩年限（按客户财年）：让客户预算匹配窗口
   - 灵活付款（季付/月付）：降低单次支出压力

3. **共建 90 天成功计划**（与方案同时）
   - 不夸大 ROI：客户预算冻结期对夸大 ROI 反感
   - 价值证据包：原合作成果 + 节省成本/合规避险
   - 90 天里程碑：每月小成果汇报
   - 客户决策层签字（不是 champion 单独签）

4. **Q1 主动接触**（财年重启期）
   - 客户预算批复后第一时间接触
   - 不在 Q2-Q3 催（客户已批预算）
   - 不在 Q4 开口（客户正在冻结）

### 成功标志

- 客户预算重启期主动询价
- 客户认可多年期+缩年限方案
- 客户愿意参与 90 天成功计划

### 失败 fallback

- 客户跨年预算延期 → 继续盯编报节点（3-4 月追加）
- 客户明确「不续」 → 转 Marginal，团队避坑沉淀

## 四、Path C：合规窗口

### 触发条件

- 主根因 = 国产化替换 / 合规变更
- 信创/等保 2.0/合规审查强制要求替换
- 客户公司被纳入「国产化替代目录」

### 核心动作（4 步）

1. **判定合规窗口**（立即）
   - 信创目录发布期（央国企政策窗口）
   - 等保 2.0 测评期（年度/季度）
   - 客户行业合规要求（金融/政府/能源）
   - 竞品已通过合规（差异化空间）

2. **出合规材料**（15 工作日）
   - 信创适配证明（产品+部署+运维）
   - 等保 2.0 测评报告（如有）
   - 国产化证书（工信部/保密局/相关认证）
   - 行业合规案例（同行业已通过案例）

3. **等政策细则落地**（视政策周期）
   - 不在政策空窗期催客户（客户决策受政策细则影响）
   - 政策细则落地第一时间接触客户
   - 出方案：合规材料 + 多年期 + 替换路径图

4. **替换路径设计**（与方案同时）
   - 数据迁移：从竞品到本产品的迁移路径
   - 培训：客户使用层培训计划
   - POC：合规材料通过后 2-4 周 POC 验证
   - 切换：分阶段切换（试点→全量）

### 成功标志

- 客户认可合规材料
- 政策细则落地后客户主动询价
- POC 成功标准达成

### 失败 fallback

- 客户已被纳入竞品信创目录（无差异化空间） → 放过
- 政策窗口关闭 + 无合规材料 → Marginal，团队避坑沉淀

## 五、Path D：采购竞品重投

### 触发条件

- 主根因 = 采购竞品替换 / Competitor Win
- 招标流程/集采/比价压价
- 客户采购线「换品牌」指令

### 核心动作（4 步）

1. **招标监测**（立即）
   - 中国招标投标公共服务平台（国家级）
   - 地方公共资源交易（省/市级）
   - 招标双平台同时监测（不漏标）
   - 客户公司招标公告关键词（公司名+产品关键词）

2. **招标前介入**（招标未发时）
   - 客户群/朋友圈持续互动
   - 行业大会/客户大会维持曝光
   - 标前技术交流（合规范围）
   - 客户内部决策人触达（不直接接触采购线）

3. **比价差异化**（招标已发未开标）
   - 递交差异化方案：功能+TCO+服务
   - 多年期打包：单年报价降 + 多年期锁定
   - 集采目录申请（如客户是央国企）
   - 增值服务：免费培训/数据迁移/POC 延长

4. **续标机会保留**（招标已开标 + 竞品中标）
   - 不强求翻盘（合同已签竞品）
   - 保留续标机会：合同到期前 6 个月重新接触
   - 客户群持续互动（朋友圈/客户大会）
   - 等竞品服务不到位时再切入

### 成功标志

- 招标前介入成功（标书入围）
- 比价差异化胜出（中标）
- 续标期再切入成功

### 失败 fallback

- 客户合同签竞品 3 年长约 → 放过，转续标期
- 客户被竞品锁定 → Marginal，团队避坑沉淀

## 六、Path E：价值重述

### 触发条件

- 主根因 = 产品缺口 / ROI 未证明 / Champion 疲劳
- 客户质疑「付了有什么用」「产品不如 X」
- Champion 疲劳（不想继续 fighting 内部）

### 核心动作（4 步）

1. **价值证据包重构**（10 工作日）
   - 原合作成果量化（节省人天/工时/合规避险）
   - 客户侧使用层真实反馈（视频/截图）
   - ROI 计算（保守-进取区间）
   - 同行业可比案例（不是包装，是事实）

2. **现场标杆参观**（15 工作日）
   - 同行业同规模客户参观（不是大客户，是可比客户）
   - 客户使用层+业务层+决策层都参与
   - 现场答疑（不是演示，是问答）
   - 决策层朋友圈/客户群分享参观感受

3. **共建典型场景**（20 工作日）
   - 客户业务场景 → 产品能力映射
   - 客户主动参与场景设计
   - 共建案例客户署名（不是单方面包装）
   - 标杆案例对外发布（客户决策层站台）

4. **POC 重做 / 扩展**（25 工作日）
   - 不在原合同范围做 POC（客户已付过钱）
   - 新模块/新功能 POC（增值）
   - POC 成功标准客户决策层确认
   - POC 成功 → 续约+扩展；POC 失败 → 复盘

### 成功标志

- 客户决策层认可 ROI
- 现场标杆参观后客户主动跟进
- POC 成功标准达成

### 失败 fallback

- 客户决策层仍质疑 ROI → Marginal，转团队避坑沉淀
- 客户已签竞品 → 放过

## 七、路径叠加处理

主根因选 path，但**辅因可叠加 path 的部分动作**：

### 叠加示例

```
主根因：领导换届（60%）→ Path A 新 Champion 重接
辅因 1：关系失败-CSM 频繁换（25%）→ 加 Path A 第 2 步「微信企微群重建」
辅因 2：预算冻结-财年紧缩（15%）→ 加 Path B 第 2 步「多年期+缩年限方案」
```

### 叠加判定

- 辅因占比 > 20% → 必须叠加 path 动作
- 辅因占比 10-20% → 选择性叠加
- 辅因占比 < 10% → 仅作为风险标注，不叠加

### 资源预算

- 单 path 资源：1 个 CSM + 1 个 Sales + 2 周时间
- 叠加 1 个辅因：+0.5 个 CSM + 1 周
- 叠加 2 个辅因：+1 个 CSM + 2 周
- 资源预算 > 团队可承受 → 降档到 Marginal
