# 病史重建 Checklist（流失挽回头一步）

> 目的：穷尽所有可用证据，缺口明标，禁止补全/编造。病史重建是后面根因分类 + 评分 + pathway 的输入——没证据下面全错。

## 5 类证据 × 12 项具体记录

### 证据类 1：合同/计费

| 项 | 来源 | 关键问题 |
|---|---|---|
| 合同期限与终止日 | CRM / 合同原件 | 合同到期日？终止生效日？自动续约条款？ |
| 付款记录 | 财务系统 / 发票 | 最后一次付款日？是否逾期？争议发票？ |
| 终止条款 | 合同原件 | 是否有提前终止罚则？通知期多长？ |
| 合同金额与折扣历史 | CRM / 报价单 | 原 ARR？历史折扣率？续约是否被拒过？ |

### 证据类 2：业务回顾/QBR

| 项 | 来源 | 关键问题 |
|---|---|---|
| 最近 2-3 次 QBR 纪要 | CRM / 共享文档 | 客户目标达成？价值证据包？客户表态？ |
| 首价值证据包 | 首价值证明阶段产出 | 是否在客户侧展示？客户认可？ |
| 客户共创成果 | 项目交付文档 | 客户主动参与？共建案例？ |

### 证据类 3：工单/支持

| 项 | 来源 | 关键问题 |
|---|---|---|
| 未解决工单清单 | 工单系统 | 关键/升级工单？超期未解决？ |
| 客户投诉历史 | 工单系统 / 客服记录 | 投诉频次？抱怨主题？响应时长？ |
| CSAT/满意度趋势 | 满意度调查 | 满意度下降节点？评论关键词？ |

### 证据类 4：沟通历史

| 项 | 来源 | 关键问题 |
|---|---|---|
| 邮件/会议记录 | 邮件 / 会议纪要 | 关键决策人表态？异议历史？ |
| Champion/决策层变更 | 组织架构图 / 朋友圈 | Champion 调岗？决策层换届？ |
| 关键时刻沟通（招标、比价、终止谈判） | 邮件 / 微信群聊截图 | 客户主动提及的根因？ |

### 证据类 5：外部信号

| 项 | 来源 | 关键问题 |
|---|---|---|
| 招聘网站（业务侧） | BOSS 直聘 / LinkedIn | 关键岗位招聘？相关团队调整？ |
| 工商信息（天眼查/企查查） | 公开工商平台 | M&A？股权变更？法人变更？ |
| 招标公告 | 招标投标公共服务平台 / 公共资源交易 | 招标方向？是否比价？竞品是否在标书？ |
| 行业新闻/政策 | 行业媒体 / 监管公告 | 国产化政策？等保 2.0 测评？行业整顿？ |

## 缺口处理规则

1. **明确标注**：每条缺失的证据注明「未获取」+ 最小跟进动作（如「需向财务拉取发票最后付款日」）。
2. **禁止补全**：缺数据时评分给中性 3 分，不推断。
3. **评分降权**：缺口 > 50%（12 项中 > 6 项缺失）→ 整体评分置信度从「高」降为「中」，结论标「需补证据后重评」。
4. **不可获取的证据**：制度性不可获取（如客户解散工商已注销）→ 该项标「N/A 不适用」，不计入缺口比例。

## 关键问题清单（病史重建后必问）

病史重建完成后，必须回答这 5 个问题，否则根因分类不可靠：

1. **客户是「主动不续」还是「被动静默」？**（主动=已选竞品/被动=预算/采购流程卡）
2. **原 Champion 还在吗？**（还在=关系线存续 / 不在=必须重接）
3. **决策层有表态吗？**（表态=有信息/静默=需主动发掘）
4. **有没有外部信号？**（招标/招聘/M&A=可推断根因）
5. **同批次其他客户有没有类似症状？**（单点=个案 / 批量=流程问题）

回答完这 5 个问题，再进入根因分类阶段。
