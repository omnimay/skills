# 团队避坑沉淀模板（同批次其他账户排查）

> 单客户赢回只是冰山一角——同批次（同期签约/同行业/同决策链/同产品版本）的其他账户可能有相同根因，必须排查。
> 主参考：OneWave churn-autopsy Phase 6 Lessons Learned（流程改进+系统性信号）。

## 一、同批次账户筛查 4 维交叉

### 维度 1：同期签约

| 筛选条件 | 数据源 |
|---|---|
| 合同开始日 ±30 天 | CRM 合同表 |
| 同一销售/CSM 团队 | CRM owner 字段 |
| 同一产品版本/模块 | CRM 产品字段 |

### 维度 2：同行业

| 筛选条件 | 数据源 |
|---|---|
| 同一行业代码（如金融/政府/能源/制造） | CRM 行业字段 |
| 同一客户分级（A/B/C） | CRM 客户分级字段 |
| 同一决策链结构 | 客户档案决策链字段 |

### 维度 3：同决策链

| 筛选条件 | 数据源 |
|---|---|
| 同一 Champion（已离职/调岗的客户） | CRM champion 字段 |
| 同一决策层（已换届的客户） | 客户档案决策层字段 |
| 同一采购流程（已换品牌的客户） | 客户档案采购字段字段 |

### 维度 4：同产品版本

| 筛选条件 | 数据源 |
|---|---|
| 同一产品 SKU | CRM 产品字段 |
| 同一部署方式（私有化/公有云） | CRM 部署字段 |
| 同一合规要求（信创/等保） | 客户档案合规字段 |

## 二、风险信号比对

### 高风险信号清单（任一命中 = 高风险）

- [ ] 同一 Champion 已离职/调岗
- [ ] 同一决策层已换届
- [ ] 同一 CSM 已调岗/离职
- [ ] 同一合同模板问题（条款/付款/折扣）
- [ ] 同一产品模块出现集中工单
- [ ] 同一行业出现合规变更（信创/等保）
- [ ] 同一财年周期出现预算冻结
- [ ] 同一采购线 KPI 调整

### 信号比对方法

1. **本客户流失根因** → 找主根因的「关联信号」（如领导换届 → 找同决策层客户）
2. **关联信号清单** → 4 维交叉筛高风险账户
3. **高风险账户清单** → 标记预警 + 预防性介入

## 三、行动项模板

```markdown
## 团队避坑沉淀：[流失客户名]
**沉淀日期：** [date] | **沉淀人：** [CSM Manager / Sales Manager]

### 流失根因
- 主根因：[类别] + 占比 60%
- 辅因 1：[类别] + 占比 25%
- 辅因 2：[类别] + 占比 15%

### 同批次高风险账户清单
| 客户名 | 关联维度 | 风险信号 | 行动建议 | 责任人 | 完成日期 |
|---|---|---|---|---|---|
| [客户 A] | 同期签约+同 CSM | 工单 spike | 主动健康检查 | [CSM] | [date] |
| [客户 B] | 同行业+同决策层 | Champion 调岗 | 新 Champion 重接 | [Sales] | [date] |
| [客户 C] | 同产品版本 | 同模块集中投诉 | 功能采用冲刺 | [CSM] | [date] |

### 流程改进项
1. [流程 gap] → [改进方案] → [责任人] → [验收日期]
   - 例：CSM 调岗无交接流程 → 出 CSM 调岗交接 checklist → CSM Manager → 30 天
2. [流程 gap] → [改进方案] → [责任人] → [验收日期]

### 系统性信号
- 同批次 [N] 个客户出现 [信号] → 系统性问题 → 触发产品/流程改进

### 责任人签字
- CSM Manager: ___________
- Sales Manager: ___________
- Product Manager: ___________ (如有产品问题)
```

## 四、流程改进 checklist

### 流程类改进

| Gap 类型 | 典型症状 | 改进方案 |
|---|---|---|
| CSM 调岗无交接 | 新 CSM 不了解客户历史 | CSM 调岗交接 checklist（含 12 项病史） |
| 决策层换届无监控 | Champion 走了无人知晓 | 决策层换届监控 + 朋友圈/脉脉观察 |
| 工单 SLA 超期无升级 | 关键工单超 30 天 | 工单 SLA 升级机制（7/15/30 天升级） |
| 续约启动晚 | 到期前 30 天才开口 | 续约提前 90/120/180 天启动 |
| 价值证据缺失 | 客户质疑 ROI | 价值证据包季度更新 |
| 主动发掘机制缺失 | 等客户主动联系 | 老同事打听+客户大会机制 |

### 产品类改进

| Gap 类型 | 典型症状 | 改进方案 |
|---|---|---|
| 某模块集中工单 | 客户频繁投诉 | 产品优先级调整 + 工单趋势分析 |
| 某功能采用率低 | 客户决策层质疑 | 功能改造 + 培训资源投入 |
| 集成失败 | 客户无法对接 | 集成方案重做 + 客户验证 |
| 合规缺口 | 信创/等保不达标 | 合规材料补齐 + 行业认证 |

### 团队类改进

| Gap 类型 | 典型症状 | 改进方案 |
|---|---|---|
| CSM/Sales 流动率高 | 关系频繁断 | 激励机制 + 团队稳定性 |
| 决策层触达能力弱 | 救不回来 | 决策层饭局培训 + 中间人网络 |
| 主动发掘能力弱 | 错过最佳窗口 | 老同事打听机制 + 客户大会 |

## 五、典型避坑沉淀案例

### 案例 1：领导换届批量流失

**流失主根因**：领导换届（60%）+ 关系失败（25%）+ 预算冻结（15%）。

**同批次高风险账户**：
- 同期签约 12 个客户，5 个有 Champion 调岗信号
- 同一决策层（某省国资委），2 个客户决策层换届中
- 同一 CSM（已离职），3 个客户无新 CSM 接手

**流程改进**：
1. CSM 调岗交接 checklist → CSM Manager → 30 天
2. 决策层换届监控机制 → 销售管理 → 60 天
3. 决策层触达培训 → 销售培训 → 90 天

**系统性信号**：某省国资委换届 → 该省所有客户高风险 → 启动预防性介入。

### 案例 2：国产化替换批量流失

**流失主根因**：国产化替换（70%）+ Champion 失（20%）+ 预算冻结（10%）。

**同批次高风险账户**：
- 同行业（金融/政府/能源）客户 25 个，其中 8 个已纳入国产化目录
- 同期签约 5 个客户，已通过信创认证 2 个，未通过 3 个
- 招标公告显示 3 个客户在招标国产化产品

**流程改进**：
1. 信创/等保合规材料补齐 → Product Manager → 90 天
2. 国产化目录客户清单 → CSM Manager → 立即
3. 替换路径图设计 → 解决方案团队 → 60 天

**系统性信号**：行业合规变更 → 该行业所有客户高风险 → 启动预防性介入 + 出合规材料。

## 六、团队避坑沉淀产出节奏

| 节奏 | 产出 | 责任人 |
|---|---|---|
| **单客户流失后 24h** | 病史重建 + 根因分类 + 4 维评分 + pathway + 接触动作卡 | CSM + Sales |
| **单客户流失后 7 天** | 同批次高风险账户清单 + 风险信号比对 | CSM Manager |
| **单客户流失后 14 天** | 流程改进 checklist + 责任人 + 验收日期 | Sales Manager |
| **单客户流失后 30 天** | 流程改进验收 + 系统性信号汇总 | CSM Manager + Sales Manager |
| **季度** | 团队避坑沉淀汇总报告（所有流失客户） | CSM Manager + Sales Manager |
| **年度** | 流程改进复盘 + 系统性问题升级 | Management |

## 七、与其他 skill 的交接

### 上游

- `success-renewal-management`：续约失败转流失挽回
- 健康度预警：健康度预警未救回转流失挽回
- `success-business-review`：QBR 发现流失风险转预防性介入

### 下游

- `success-renewal-management`：赢回后转续约管理
- `success-expansion`：赢回后转增购钩子
- `success-referral-generation`：赢回客户成为转介绍种子
- `success-advocacy-management`：赢回客户口碑沉淀
