# 流失挽回（success-churn-recovery）

## 目的

把已流失客户从"等客户找回来"变成"周内可执行的求救方 + 借刀方双轨挽留"——销售 15 分钟内能判定该走哪条路、明天该打哪通电话、周三汇报前该交哪三份材料、什么时候该停手。

**边界**：不做续约前预防（续约管理场景处理）；不做未流失死单的催单挽回；不做客户健康分评估。

## 首屏 — 场景感知 + 3 档判定

销售接单前先 echo 你眼前的客户：
- 客户名 / 行业 / 门店或工位数 / 签约时长 / 合同到期倒计时
- 症状（活跃 / 工单 / NPS / Champion 状态 / 决策层动作）
- 你（销售）当前的窗口期（距离下次汇报 / 招标 / 财年重启几天）

3 档判定（≥ 3 项症状 + 1 项窗口期）：

| 档位 | 特征 | 出手节奏 |
|---|---|---|
| **🔥 急救档** | 3-7 天内有汇报 / 招标 / 决策层会议 | D-3 / D-2 / D-1 倒排 |
| **🌊 挽回档** | 30 天内决策 / 评估中 | 30 / 60 / 90 天三阶段 |
| **❄️ 冻档** | 决策已固化 / 静默待解 | 信号发掘 + 间歇触达 |

---

## 岔路 0：求救方 vs 借刀方（销售上线第一问）

**周一上午第一通电话之前必须先答这题**——决定后续是「弹药供给」还是「流程外推」。

| 判定 | 含义 | 后续动作 |
|---|---|---|
| **求救方**（客户主动求助） | Champion 主动找你：「帮我准备对比方案」「副总要听汇报」 | 销售 = 弹药供给方，主提供材料 |
| **借刀方**（我们猜测） | 销售自己猜 / 第三方传出信号 | 销售 = 流程外推方，升级销售总监 / VP 借刀 |

**一句话问法**（周一上午打给 Champion 时用）：

> 「[Champion 称谓]，这次汇报您自己心里的倾向是什么？我按您的倾向准备材料，不按我的。」

- 客户主动要材料 → 求救方 → 走主流程（§一）
- 客户没表态 / 销售自猜 → 借刀方 → 升级主控，走 §二 Plan B + 决策层介入

> **这是生死岔路**：求救方走救流程，胜在弹药；借刀方走救流程，10 单输 9 单，因为客户内部没人替你说话。

## §一 主流程（求救方走这条）

### 步骤 1：诊断 — 政治处境优先（不是百分比加权）

立刻识别 Champion 的内部政治处境，三栏填一栏：

| 处境 | 信号 | 你的角色 |
|---|---|---|
| **被推的执行人** | Champion 主动来找 / 群内沉默被动回应 / 决策层朋友圈风格突变 | 弹药供给（材料让她站住脚） |
| **主动推的发起人** | Champion 主动设计评估流程 / 群里主动推方案 / 内部背书 | 协同方（共建对比方案 + 接入决策层） |
| **失权 / 调岗待确认** | 群内沉默 / 朋友圈不互动 / 决策链换人 | 借刀（升级销售总监，立即找新 Champion） |

**关键判定**（不是百分比加权）：服务失败是表象，政治处境才是根因——同样"工单量激增"，被推的执行人 vs 主动推的发起人，救法完全不同。30% 工单 + 50% 价值证据 + 20% 决策层看似严谨，但把"人"降维成"数"——真正的判定是这张三栏。

根因 / 评分 / 路径的完整分类与细则 → `references/root-cause-taxonomy.md` / `references/viability-scoring-rubric.md` / `references/pathway-playbook.md`。

### 步骤 2：诊断 — 病史重建（5 类证据 + 12 项）

5 类证据：合同计费 / 业务回顾 / 工单支持 / 沟通历史 / 外部信号。12 项记录 + 缺口标注 + 替代信号源 → `references/history-reconstruction-checklist.md`。

**关键纪律**：缺口明标禁止补全 / 编造——没证据下面全错。

### 步骤 3：选路 — D-X 倒排时间表（🔥 急救档必走）

| 节点 | 干什么 | 关键产出 |
|---|---|---|
| **D-3（周一）** | **取证 + 摸底**：①求救电话问 4 件事（汇报重点 / 竞品身份 / 参会人 / 自身倾向）②内部拆 3 条数据线（活跃下降的门店维度 / 工单根因归类 / NPS 关键人） | 一通电话 + 数据三角验证 |
| **D-2（周二）** | **交付材料 + 内部锁承诺**：①切换成本清单（数据迁移 / 培训 / 联调 / 爬坡期 / 沉没成本，每项给区间数字）②问题归因与整改承诺书（带日期 + 人名）③一页纸价值回顾 | 三份材料 + 内部承诺时间表锁定 |
| **D-1（周三）** | **陪跑 + Plan B 兜底**：①汇报前 1 小时发"全天待命"消息②当天下午主动问反馈③风向不对立即启动 Plan B（见 §二） | 一次汇报 + 风向裁定 + Plan B 决策 |

**汇报现场话术**（Champion 拿得出手的 3 句话）：
1. 过去 12 个月我们交付了 [结果 A]、[结果 B]、[结果 C]，[门店数] 都用起来了。
2. 切换成本 = 数据迁移 + 培训 + 合规重做共 [金额]，窗口期仅 [天数] 月——给副总的硬数据。
3. 我们备了 3 年锁定 + 降 [百分比]% + 工单修复承诺方案，您方便时详细汇报。

**11 个 Save Plays 完整动作卡**（决策层介入 / 紧急技术 review / 价值重塑工作坊 / 微信企微群重建 / 共建 90 天成功计划 / 多年期+缩年限 / 竞品防御 / 主动健康检查 / 功能采用冲刺 / 现场标杆参观 / 财务重组）→ `references/save-plays-china.md`。

### 步骤 4：算账 — 投入产出 + 止损红线

**投入上限** = 挽回后年 LTV × 0.3（战略级至 0.5）。投入项：折扣让步 ≤ 15% / CSM 工时 / 决策层饭局 / 合规材料 / 招标比价。**产出对照**：赢回概率 × 挽回后年 LTV × 续约年数 ≥ 投入 × 1.5。

**3 个停手信号**（出现任一立即降级为体面收尾 / 降级续约 / 转介绍种子）：

1. **客户信号停摆**：周会后 Champion 不回消息 / 把我们转给采购或法务对接——关系链已断。
2. **竞品已实质落地**：竞品在做 POC 或已进场对接接口——窗口期已关。
3. **我方承诺没兑现**：内部整改承诺到期未达成——我们先判了自己的死刑。

**主动放弃 5 条硬规则**（4 维评分 < 1.0 / 战略不可逆 / 国产化窗口已关 + 无合规材料 / 竞品签 ≥ 2 年长约 + Champion 离职 / 投入 > 挽回后年 LTV × 0.5）→ 团队沉淀去向 = 增购钩子 / 转介绍种子 / 同批次避坑。

### 步骤 5：沉淀 — 同批次避坑 + 中国 B2B 适配

**同批次排查**（单客户赢回只是冰山一角）：同期签约 / 同行业 / 同决策链 / 同产品版本 → 4 维交叉筛高风险。流程改进项 + 责任人 + 验收日期 → `references/team-lessons-template.md`。

**中国 B2B 适配**（央国企 / 民企 / 外企的关系链长度、决策节奏、替代信号源、典型根因）→ `references/china-adaptation.md`。

## §二 决策延期型 Plan B（30 天联合验证期）

**触发条件**（任一即启 Plan B）：
- 客户汇报环境恶劣（强竞品 + 决策层已倾向 + 整改时间不够）
- 周三汇报现场风向不对（副总当场向竞品倾斜）
- 决策层要求"再观察一次"

**打法**（把 binary 决策改成延期验证）：

> 「副总，这次切换牵涉 [门店数] + 历史数据 + 合规要求，建议先做 30 天联合验证——我们把工单密度、活跃度、响应时长三个指标打到原合同基线，您看数据说话。30 天后再决定续约还是切换。」

**为什么有效**：
- 不需要副总当场否定自己前面的立场（保全面子）
- 30 天里我方能用事实证明问题已被修（vs 销售口说无凭）
- 即使 30 天后仍判切，关系没断，续标期还有戏

**配套动作**：
- 30 天内每周一次现场 check-in（而非单点交付）
- 30 天后必须出一份"客观数据单页"（非营销话术）
- 30 天后仍判切 → 转 30 天防守 / 降级续约 / 转介绍种子

## 判定标准（一份直接可用的挽留急救卡）

> 销售 15 分钟拿这张卡就能开始打电话。

1. **首屏 3 档判定**：场景 echo + 急救 / 挽回 / 冻档 + 出手节奏
2. **岔路 0 判定**：求救方 vs 借刀方（销售一句话问 Champion 即可）
3. **政治处境判定**：Champion 三栏（被推 / 主动推 / 失权）
4. **D-X 倒排表**：D-3 取证 + D-2 交三份材料 + D-1 陪跑 + Plan B
5. **3 句口头话术**：过去做了 / 切换成本 / 备好方案
6. **3 个停手信号**：客户停摆 / 竞品落地 / 我方爽约
7. **Plan B 模板**：30 天联合验证期一句话 + 配套动作
8. **同批次清单**：同期 / 同行业 / 同决策链 / 同产品 4 维交叉

**待确认问题**（最多 3 个）：合同原件 / QBR 纪要 / Champion 现任汇报线 / 竞品厂商身份——按需取，不超过 3 个。

## 易踩坑（归因式反例）

| 念头 / 做法 | 后果 |
|---|---|
| 不问求救方 / 借刀方直接走救流程 | 借刀方走救流程 10 单输 9 单，客户内部没人替我方说话 |
| 百分比加权 30/50/20 代替政治处境判定 | 把"人"降维成"数"，根因看似严谨实则误判 |
| 「填完表格再走下一步」式流程（病史 12 项 + 4 维评分 + 11 个 save play 全列） | 销售 15 分钟拿不到主线，CR 推不动 |
| 把决策当作 binary 争辩（续 vs 切） | 副总当场要面子必须选边，救不回来 |
| 救回来不管下游续约 | 赢回 = 续约起点；没衔接 `success-renewal-management` = 再次流失 |
| 把流失挽回当 cold outreach | 已成交客户有旧合同 / 旧 POC / 旧发票抬头——warm reach 不是 cold outreach |
