# 增购对话（expansion-conversation）

> 按 signal 开口 + 向上/交叉分支 + 三层决策链话术 + 异议→应对 + 中国沟通形态。
> 开场用 conversation starters 话术；三层话术沿用首价值证明的 value-narrative。

## 按 signal 分类的开场

| signal | 开场方向 | 示例钩子 |
|---|---|---|
| 用量到顶 | 肯定团队增长，点出容量临顶，引加坐席/升级 | 「看到你们最近扩招，坐席快到顶了吧？要不要算一下加多少够用」 |
| 功能请求 | 把客户询问连到对应升级能力 | 「你之前问的 XX 功能，正好在高级版里，要不要看看怎么用」 |
| 公司增长/融资 | 祝贺+问团队结构+增长规划 | 「恭喜完成这轮融资，团队接下来怎么扩？我们配合规划下坐席」 |
| 新部门 | 共建跨部门用例，champion 介绍 | 「听说财务部也在看这类工具，能不能帮你引荐下，看看跨部门怎么协同」 |
| 竞品替换 | 不贬竞品，讲整合经济性+我方补齐差距 | 「你们现在 A 工具做这块，我们也有，整合到一个平台省两份钱+数据打通」 |
| 战略举措 | 把举措连到我方能力 | 「你们在做数字化转型，我们这块正好支撑 XX 环节」 |
| power user | 高阶功能/专属服务 | 「你们几个重度用户，高级版/专属服务能让他们更顺手」 |
| 服务/工单高 | 专属支持/服务包 | 「工单量最近高，专属 CSM 能帮你更快响应」 |

## 推进分支

### 向上销售（同产品线升级）
- 升级套餐：讲 capacity 解锁 + tier 权益对比（做对比表，单价差 vs 解锁价值）。
- 加坐席：按团队增长规划算数量，绑定续约打包算总账。
- 加模块：先 POC 降门槛（见 opportunity-record POC 路径），价值证据驱动。

### 交叉销售（跨产品线/跨部门）
- 新部门/新 BU：引 champion 介绍对应部门联系人，共建用例。
- 新用例：用首价值证明的价值叙事证明跨场景价值。
- 跨部门协同价值：数据打通/流程协同/统一管理是关键卖点。

## 三层决策链话术（按受众抬一层）

| 层 | 话术重点 | 语言 | 示例 |
|---|---|---|---|
| 使用层（champion/骨干） | outcome—省时/提效/解痛点 | 业务语言 | 「每周省 10 小时手工活」 |
| 业务层（部门负责人） | ROI—人天/工时/合规/部门政绩 | 部门业务语言 | 「省 340 小时=0.2 人头，合规事件降 X%」 |
| 决策层（分管副总/CFO） | impact—人民币回报/降本增效/合规避险/政绩/对标 | 人民币+战略语言 | 「年化 3.4× 回报，降本 ¥X 万，对标行业标杆」 |

**规则**：永远给受众看比他已知高一层。少用海外「board ROI」话术，用人民币+降本增效+合规避险+政绩+对标。每个叙事版本只挑一个 headline metric（如「3.4× 回报」或「审批时长降 42%」）。

## 异议→应对

| 异议 | 应对 |
|---|---|
| 「等续约再说」 | 续约打包算总账更划算，现在加锁定价格/避免续约时临时加价 |
| 「预算没」 | POC 先试降门槛；预算申报期 timing；Q4 预算松动窗口；预算调整审批路径 |
| 「要招标」 | 衔接招标流程不绕过，timing 调整招标周期，我方配合标书 |
| 「现在用得挺好不需要」 | 点出用量到顶/功能差距的隐性风险（临顶会卡业务），给数据不空谈 |
| 「竞品更便宜」 | 整合经济性（替两份钱）+ 数据打通价值 + 补齐差距，不贬竞品 |
| 「要领导批」 | 准备决策层一页纸+微信版+口头版，champion 帮上推 |

报价/定价细节引用 `clinch-negotiation-pricing`，不在本 skill 自造。

## 中国沟通形态

| 形态 | 用法 |
|---|---|
| 微信群/企微群话术 | <200 字，1 数字+1 痛点/钩子+1 下步；可发客户群/企微 |
| 朋友圈信号互动 | 客户发招聘/搬迁/新业务线动态→点赞+评论切入增购话题 |
| 决策层一页纸 | headline metric + 3 条证据（标类型）+ 1 句客户认可 + 下步动作 |
| 微信版摘要 | <200 字，1 数字 + 1 客户认可 + 1 下步，可发领导微信群 |
| 口头/饭局 3 句话 | 痛点→结果→下步，用于线下/饭局/领导碰面 |

先讲已交付成果，再提增购诉求。先要钱再讲成果=决策层反感。
