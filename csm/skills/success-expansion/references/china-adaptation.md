# 中国适配（china-adaptation）

> 海外 land-and-expand → 中国化改造汇总。以下为相对海外同类方法论的核心差异化。

## 1. 三层决策链（替换单一 economic buyer）

海外同类方法论假定单一 economic buyer、三角色框架。中国存量账户增购常需三层会签：

| 层 | 角色 | 增购作用 |
|---|---|---|
| 使用层 | 业务骨干/champion | 发起需求、提供证据、向上推 |
| 业务层 | 部门负责人/处长 | 业务 ROI 认可、部门预算申请 |
| 决策层 | 分管副总/一把手/CFO | 战略/人民币决策、审批 |

超阈值（招标）→ 决策层 + 采购 + 财务会签，对话提前准备采购流程话术。stakeholder 矩阵按三层映射（economic/technical/champion → 决策层/业务层/使用层）。

## 2. 预算追加周期（替换 budget cycle 30-60 days before）

中国年度预算刚性：
- 年初申报期：客户做下年度预算，增购项可嵌入（提前 1-2 月介入）。
- Q4：财年/日历年关预算松动/尾款可用（短周期增购好窗口）。
- 年中追加：走预算调整审批，难度高（强信号+高层背书）。
- 财政/国企：追加最难，必须在申报期嵌入。

timing 信号加预算周期维度（见 renewal-handoff 表）。

## 3. 微信企微增购沟通（替换 email + QBR deck）

中国增购话术主战场：
- 微信群/企微群：话术 <200 字（1 数字+1 钩子+1 下步）。
- 朋友圈：看客户动态（招聘/搬迁/新业务线/融资=增长信号），点赞评论切入。
- 决策层：一页纸 + 微信版摘要 + 口头/饭局 3 句话（沿用首价值证明的 exec-reporting）。
- 政企客户不发 email、不填 NPS——别依赖这些渠道收证据。

## 4. POC→增购路径（替换 self-serve / in-app expansion）

海外同类方法论假定 self-serve/in-app expansion（自动 tier bump、应用内购买）。中国企业级不吃这套：
- 新模块/新坐席/跨部门拓展常先 POC（2-4 周）+ 成功标准 + 转单触发点。
- POC 降门槛：客户不敢直接拍大单，先试再买。
- POC 证据进 opportunity record，可信度 customer-validated+。
- 避免 POC 无限延期：必须设成功标准与截止日。

## 5. 招标双平台（替换单纯商务谈判）

增购金额超阈值或政企/国企需走招标：
- 中国政府采购网（财政单位/政府采购）。
- 地方公共资源交易中心（地方国企/公共资源）。
- timing 调整为招标周期（30-90 天），不按普通商务推。
- 标书环节进入合同流程，本 skill 提供证据支撑。
- 建案时金额阈值判定，标 `NEEDS_TENDER=true`。

## 6. 信创国产化（海外同类方法论未覆盖）

政企增购模块常需满足信创/国产化要求：
- 国产替代、自主可控政策窗口=竞品替换信号叠加。
- 增购模块需国产化适配证明/信创目录。
- 政企增购话术加「信创合规/国产化适配」卖点。
- timing 信号加信创政策窗口期。

## 7. 无 telemetry 替代（替换完整 telemetry 假设）

国产化/私有化常见无后台 telemetry：
- 用量信号用业务侧手动数据（工单数/报表人天/审批时长/坐席手动统计）+ 客户确认。
- feature 采用：业务部门负责人估算频次。
- 客户原话：微信/企微群聊截图 + 朋友圈 + 客户领导微信群认可（替代 email/NPS）。
- 客户确认的手动数据比我方估算可信 10×（沿用首价值证明场景做法）。
- 标可信度 data-derived / customer-validated，不冒充 customer-confirmed。

## 8. 续约+增购打包（强化 renewal alignment）

中国常把增购和续约打包谈（续约时加坐席/升级套餐）：
- 总账更优，避免续约后单独增购再走审批。
- 续约前 90 天评估增购打包机会。
- 衔接 success-renewal-management 主导续约，本 skill 提供增量部分。
- 不打包情况：金额大需招标、新部门独立预算、客户分账。
