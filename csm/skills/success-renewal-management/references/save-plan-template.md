# save 计划模板 + playbook card

## 中国式续约风险根因四类

替代海外 cancel flow / dunning（政企不走自助 cancel、无支付失败，被动流失≠支付失败）。

| 根因 | 信号 | save 动作 |
|---|---|---|
| 预算冻结 | 财年紧缩/预算编报延期/CFO 换人 | 缩短年限（1 年替 3 年）/分期付款/匹配下个预算窗口/缩范围保核心 |
| 采购流程延期 | 招标/审批卡点/合规材料缺失 | 早介入采购流程（120 天前）/补等保/信创材料/找采购 champion |
| 领导换届 | champion/sponsor 调岗离职/新领导不认旧账 | 多线程覆盖决策层（使用层+champion+决策层三层）/重新价值对齐/新领导首价值复盘 |
| 国产化替换 | 信创名录要求/等保到期重新测评/竞品国产化替代 | 证国产化合规（信创名录/等保证书）/替代方案防御（功能对标+迁移成本算账）/政策红利对齐 |

## save 计划模板

```
## save 计划：<客户名>

### 风险档位
- 健康分：<值>（档：<橙/红>）
- 合同价值：<ARR>
- 根因：<四类之一，可多根因>

### save 动作
| 根因 | 动作 | Owner | 期限 | 升级路径 |
|---|---|---|---|---|
| 预算冻结 | 缩 1 年 + 匹配 Q1 预算窗口 | CSM+Sales | 30 天内 | 财务审批不通过→高层介入 |
| 领导换届 | 新领导价值复盘 + 三层覆盖 | CSM | 45 天内 | 新领导不认→executive save |

### 决策点（升级人）
- [ ] 折扣权 / 定价 / 合同条款 → 人决定
- [ ] save-or-let-go（save 不足则转流失挽回）→ 人决定
- [ ] 高层介入时机 → 人决定

### 预期结果
- Save 率：40-50%（橙）/ 25%（红）
- Full renewal / Reduced renewal / Churn 三种 outcome 预判
```

## playbook card（6 字段，分档）

```
## playbook card：<客户名> · <档位>

- objective：<绿=续约+多年期+增购 / 黄=标准续约+早处理 / 橙红=save 后续约>
- trigger：<健康分档 / 到期天数 / leading indicator>
- assets：<价值证据包 / Value Bridge 叙事 / save 计划 / 一页纸>
- timeline：<分层 180/120/90/60/30 天动作>
- owner：<CSM / Sales / 高层 分工>
- metrics：<续约率 / NRR / save 率 / 多年期率>
```

## 分档 playbook 动作

### 绿档（健康）
- 轻触，月度 check-in。
- 价值复盘（Value Bridge 过去价值段）。
- 提多年期（价格保护+战略对齐，折扣 5-10%）。
- 埋增购钩子 → 交接 success-expansion。

### 黄档（中性）
- 标准续约，双周跟进。
- 早处理顾虑（75 天前 value review call 识顾虑）。
- 到期前锁定承诺。

### 橙红档（风险）
- 重投入，周度/日度干预。
- save 计划执行（根因→owner→期限→升级）。
- 高层介入（executive save）。
- 灵活条款（短期/缩范围/success-based terms）。
- save 不足 → 转流失挽回（交接 save 计划 + 根因记录）。

## 橙红档干预节奏（以 180 天 timeline 为例）

| 天数 | 橙档 | 红档 |
|---|---|---|
| 180 | 风险深挖+根因 | 高层升级 |
| 120 | save 计划启动 | executive save |
| 90 | 高层 check-in | go/no-go 决策 |
| 60 | 续约对话（仅健康改善时） | 最后努力 |
| 30 | 决策点（save 或转挽回） | 接受/转挽回 |
