# 中国适配

## 决策层三层（核心差异）

中国 B2B/政企决策链三层（海外常单层 sponsor）：

| 层 | 角色 | 续约诉求 | 叙事语言 |
|---|---|---|---|
| 使用层 | 业务处室/一线 | 好用/省活 | outcomes（省人天/省工时/省事） |
| champion | 部门经理/处长 | 合规避险/效率/政绩支撑 | 合规避险 + 效率 + 部门 KPI |
| 决策层 | 一把手/分管副总 | 降本增效/政绩/对标/战略 | 人民币 ROI + 政绩 + 战略对齐 |

**铁律**：续约对话要按受众抬一层（使用层讲 outcomes、champion 讲省人天·合规、决策层讲降本增效·政绩·对标）。单线程只找 champion = champion 调岗续约断线。

## 国产化/等保续约合规

- 政企续约常伴随**等保测评到期**（合同周期与等保周期绑定，续约需重新过等保）。
- **信创名录**要求（部分政企续约要求产品在信创名录，或国产化替代）。
- 续约 matrix 加「国产化合规」维度：等保/信创到期 = 续约伴随合规材料补齐 + 国产化替代方案防御。
- 国产化替换风险 = save 计划根因之一（证合规 + 替代方案防御 + 政策红利对齐）。

## 预算财年节奏

- 中国政企/国企预算编报：年底（Q4）编报下年度预算，Q1/Q2 采购窗口。
- 续约 timeline 要匹配客户预算窗口：180 天前首触 = 锁定下年度预算编报。
- 多年期要匹配预算周期（多年期锁定 = 锁定多年预算，对客户是承诺也是约束）。
- 预算冻结 = 续约风险根因（缩年限/分期/匹配窗口/缩范围）。

## 微信企微沟通主战场

- email 弱化（政企不发 email、不填 NPS）。
- 微信/企微群：续约提醒 + value review 预约 + 签字催办 + 客户领导微信群认可。
- 线下拜访：value review 会议（带一页纸）+ 必要时饭局/碰面。
- 证据收集：微信/企微群聊截图 + 朋友圈 + 客户领导微信群认可（替代 email/NPS）。

## 私有化无 telemetry 替代

- 私有化/国产化部署无后台 telemetry → 用业务侧手动数据（工单数/审批时长/报表人天/合规事件数）+ 客户确认。
- 客户确认的数据比我方估算可信 10×。
- 健康分 6 维的「Product Usage」「Feature Adoption」维度用业务侧手动数据替代。

## 绩效联动（中国 SaaS 成熟做法）

- 续费率红线（如 90%）作基本盘防御线。
- 挽回率专项奖金池（15-20% 流失客户可挽回，挽回收入可达总续费 7%）。
- 健康度作风险调节阀（低健康度客户必须触发主动服务任务并计入覆盖率考核）。
- 增购激励与续约基础互锁（防过度推销损害续约）。
- 本 skill 输出（续约预测表 + 风险档位 + save 计划）支持 CS 绩效包干考核。

## 海外做法删除/改造清单

| 海外做法 | 处理 |
|---|---|
| cancel flow 5 步 | 删除（政企不走自助 cancel） |
| dunning 栈 | 删除（被动流失≠支付失败，是预算冻结/国产化替换） |
| NPS/email 证据 | 改造（微信企微群截图+领导认可替代） |
| 90 天一刀切 timeline | 改造（分层 180/120/90 天） |
| 单层 sponsor | 改造（三层决策链） |
| 折扣/price lock 激励 | 改造（折扣非首选，先用价值复盘+战略对齐） |
