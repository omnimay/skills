# Value Bridge 叙事 + 按受众 3 版

## Value Bridge 三段（续约对话骨架，不只谈价）

| 段 | 内容 | 数据来源 |
|---|---|---|
| 过去价值 Past Value | 已交付 outcomes / ROI / 问题解决 | 首价值证据包（上游首价值证明阶段）+ QBR 历史 |
| 现状 Present State | 使用/健康/功能深度 | 健康分 + 核心功能启用率 + 团队 adoption |
| 未来价值 Future Value | roadmap / expand / 战略对齐 | 产品 roadmap + 客户下年度规划 + 数字化转型目标 |

**铁律**：永远给受众看比他已知高一层。续约对话用 Value Bridge 跨三段，不只谈价格（只谈价 = anti-pattern）。

## 按受众 3 版叙事（中国决策层三层）

| 受众 | 段落侧重 | 语言 | headline metric 例 |
|---|---|---|---|
| 使用层（业务处室） | outcomes / 省的具体活 | 「审批流转时长降 42%」「每周省 10 小时」 | 省人天/省工时 |
| champion（部门经理） | 省人天·合规·避险 | 「合规事件零发生」「报表人天降 60%」 | 合规避险/效率 |
| 决策层（一把手/分管副总） | 降本增效·政绩·对标·战略对齐 | 「年化 3.4× 回报」「对标行业标杆」「数字化转型落地」 | 人民币 ROI/政绩/战略 |

## 单 headline metric

每个叙事版本只挑一个最能概括价值的数字当头条（如「3.4× 回报」或「审批流转时长降 42%」），其余做支撑。

## 决策层一页纸续约汇报

```
## <客户名> 续约价值汇报（一页纸）

### headline metric
<一个数字，如「年化 3.4× 回报」>

### 过去价值（3 条证据，标类型）
1. <outcome> [customer-confirmed]
2. <outcome> [data-derived]
3. <客户原话> [customer-confirmed]

### 现状
- 健康分：<值>（<档>）
- 核心功能启用率：<%>
- 团队 adoption：<描述>

### 未来价值
- 下年度 roadmap 对齐：<>
- 多年期战略对齐：<>

### 下步
- 续约方案：<提案要点>
- 多年期选项：<>
```

## 微信版摘要（<200 字，可发企微群/领导微信群）

```
<客户名>续约价值汇报：
1个数字——<headline metric>。
1句客户认可——「<客户原话>」。
1个下步——<续约方案/多年期>。
健康分<档>，启用率<%>，建议<动作>。
```

## 口头/饭局 3 句话电梯版

1. 痛点：上线前<痛点>。
2. 结果：上线后<outcome>。
3. 下步：续约<方案>，建议<多年期/动作>。

## 铁律

- 先讲已交付成果，再提续约/多年期诉求。先要价再讲成果 = 决策层反感。
- 证据标类型（5 级可信度，assumed 禁用），估算必须标 estimated。
- 决策层一页纸 + 微信版 + 口头 3 句话三形态配套，不一份 deck 走天下。
