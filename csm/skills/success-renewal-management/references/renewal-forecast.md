# 续约预测与度量

## 概率加权预测公式

```
续约预测 = (绿 ARR × 95%) + (黄 ARR × 80%) + (橙 ARR × 50%) + (红 ARR × 25%)
```

档位概率为行业基准，建议按本企业历史续约数据校准。

## 度量基准

| 指标 | 定义 | 基准 | 卓越 |
|---|---|---|---|
| GRR 毛收入留存 | 续约前（不含增购） | 90%+ | 95%+ |
| NRR 净收入留存 | 续约+增购 | 105%+ | 120%+ |
| Logo 续约率 | 客户数续约 | 85%+ | 92%+ |
| ARR 续约率 | 金额续约 | 90%+ | 95%+ |
| 早续率 | 到期前续约 | 30%+ | 50%+ |
| 多年期率 | 2 年+ 续约 | 20%+ | 40%+ |
| expand-at-renewal | 续约带增购 | 25%+ | 40%+ |
| 按时续约 | 到期前成交 | 85%+ | 95%+ |
| 平均续约周期 | 天 | <45 | <30 |
| 折扣率 | 平均折扣 | <10% | <5% |

## 分层 GRR/NRR 目标

| 客户层 | GRR 目标 | NRR 目标 |
|---|---|---|
| 政企/国产化 | 95%+ | 115-130% |
| 中大 | 90%+ | 105-115% |
| 小客户 | 85%+ | 100-105% |

## NRR 北极星

- NDR/NRR 稳定 >110% 的 SaaS 企业估值倍数显著高于 NDR 90% 区间。
- 增购不计入本 skill（交接 success-expansion），但绿档 expand-at-renewal 钩子要埋。
- GRR 与 NRR 必须同时看（NRR 高 GRR 低 = 增购掩盖留存问题）。
