# 追踪与回报（tracking-and-reward）

> 配套 SKILL.md 主线第 6 步。追踪保证「要一次算一次」，回报保证「介绍人愿意再来」。回报合规红线是本文件重点。

## 一、线索交接单（交什么给 prospect- 桶）

每个转介绍线索一条记录，交接 prospect- 桶下游：

| 字段 | 说明 |
|---|---|
| 联系人 | 姓名 + 职位 |
| 公司 | 名称 + 行业/规模 |
| 介绍人 | 客户名 + 联系人 + 关系层 |
| 背书原话 | 介绍人原话（微信截图/口头转述，标来源日期） |
| 推荐时点 | 何时推荐（对时机判断有用） |
| 下一步首触动作 | 已发转发包 / 已拉群 / 已约电话（0-24h 内） |
| 来源标签 | **「转介绍」**（必须带，防回流后被当普通线索） |

**交接铁律**：线索录入前确认「介绍人已先问被介绍人」；未经被介绍人同意，不把其信息用于转介绍外的用途（个保法）。

## 二、24h 跟进 + 反馈回执

| 节点 | 动作 | 回执介绍人 |
|---|---|---|
| 拿到线索 | 24h 内首触 | 首触后：「已联系上王总，约了周五电话」 |
| 首触后 | 记录进展 | 结果出来：「聊了试用，进展不错，多谢你」 |
| 成交/推进 | 结果回执 | 成交：「你介绍的王总签了，回头我请你吃饭/发个小红包」（合规见下） |

不反馈 = 介绍人觉得白搭人情，下次不帮。

## 三、合规回报表（中国企业客户场景）

| 回报方式 | 合规判断 | 说明 |
|---|---|---|
| 对等业务帮助 | ✅ 推荐 | 介绍人公司有需求你帮忙引荐/协调，人情互惠 |
| 公开认可（客户/行业群提一句） | ✅ 推荐 | 表彰背书行为，成本低信用高 |
| 客户公司级奖励（团队经费/团建基金） | ✅ 可用 | 奖励给公司/团队，不落个人口袋 |
| 个人小额合规礼品（限额外，如节日礼盒） | ⚠️ 限额 | 企业客户员工收礼有内部上限，政企红线更严 |
| 给个人现金返点 | ❌ 红线 | 商业贿赂；政企客户经理被查、关系破裂 |
| 「介绍就给钱」裸交易 | ❌ 红线 | 被定性利益输送；转介绍变买卖，客户反感 |

**回报铁律**：回报奖励给公司/团队而非个人；现金返点给个人 = 商业贿赂红线（政企尤其）；不做「介绍就给钱」的裸交易。

## 四、度量指标（怎么判断转介绍渠道健康）

- 转介绍请求率：合格客户中被请求的比例（别只问最熟的几个）。
- 转介绍兑现率：请求 → 实际给线索的比例。
- 转介绍→成交率：线索质量（对齐 prospect- 桶数据）。
- 回执完成率：给了线索后是否都回执介绍人（决定下次帮不帮）。
- 二次转介绍率：同一介绍人第二次/第三次帮的比例（渠道枯竭信号）。

## 五、与下游 skill 的关系

- 线索交接给 prospect- 桶（有效性验证/分级、客户画像）。
- 本 skill 不做线索分级；只保证「来源 + 背书背景」随线索带走，让下游有据可依。
