# 介绍人对接（forwardable-and-group-chat）

> 配套 SKILL.md 主线第 5 步。介绍人点头后的落地机制——转发包 / 拉群 / 授权用名 / plan B。
> 方法论来源：gtmify referral（MIT）。核心论断：**可转发的那个文本是转介绍成败的关键——转发文本不好，就没有引荐。**

## 一、转发包（介绍人 → 被介绍人）

**规格**：<80 字、第三人称（「XX 公司用了我们…」不是「我用…」）、粘帖即用、无营销黑话。

**四要素**：
1. 谁介绍你（介绍人身份 + 我们关系）
2. 你们解决过什么（结果/原话）
3. 与对方的相关性（为什么对他有用）
4. 一个轻 ask（15 分钟电话 / 约个时间聊）

**模板（微信转发版）**：
> 张总，这是做客户管理的 XX 公司。我们用了他们的系统之后，客户建档从每天 2 小时降到 20 分钟。你们销售团队不是也在手动建档案吗，我觉得可以让他们发你一份材料看看，15 分钟的事。

**模板（邮件引荐版，政企正式场合）**：
> 主题：介绍 XX 公司给你认识
> [被介绍人]，给你介绍下 XX 公司的 YY。我们合作 X 个月，帮我们把审批流转时长降了 42%。想到你们也有同样的流程，觉得值得聊一次。我让 YY 直接联系你。

## 二、拉群脚本（中国特色三方群）

**适用**：微信/企微客户，介绍人愿出力但不想写。

1. **先问**：「我拉个群方便吗？把你和 XX 公司的人拉一起，你顺带说一句我们合作的情况就行」。
2. **介绍人背书**（一句）：介绍人发「这是我用的 XX 系统，我们这边用着不错」。
3. **销售补价值**（一句）：产品名 + 客户结果 + 一页纸/案例链接。
4. **约下一步**：「王总，你看这周哪天方便，电话聊 15 分钟？」
5. **群维护**：资料发群里，@双方确认；首次电话后群里说结果，让介绍人看到闭环。

**注意**：介绍人背书必须自然（不当托、不刷屏）；被介绍人沉默不逼问。

## 三、授权用名

- 适用：介绍人给名单/点名（「你可以提我」）。
- 外联第一句：「XX 公司的张总介绍我联系你，他说你们也在做客户管理」。
- **纪律（合规）**：必须经介绍人同意 + 提醒介绍人**先问被介绍人**（个保法：他人联系方式/信息不得擅自处置）；被介绍人明确不想被联系 → 停。

## 四、跟进节奏与 plan B

| 时间 | 动作 |
|---|---|
| 0-24h | 首触（转发包/拉群/第一句外联）+ 记入交接单 |
| 24h 内 | 回执介绍人：「已联系上王总」 |
| 5 天无回复（介绍人侧） | 一次礼貌 bump / 换介绍人 / 经同意后授权冷触 |
| 被介绍人 5 天无回复 | 一次跟进 + 转 prospect- 桶日常节奏 |

## 五、避坑

- 转发文本写「我/我们」第一人称 → 介绍人没法直接粘帖，引荐卡壳。
- 未经同意在群/邮件里提介绍人名 → 隐私 + 面子双输。
- 群拉完不推进 → 介绍人觉得搭了脸面没下文，下次不帮。
