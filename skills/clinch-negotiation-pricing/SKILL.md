# 谈判/报价策略

## 目的

在合同条款敲定前，为单个商机交付一份完整的议价策略包——报价档位清晰、议价区间心里有数、砍价时知道换什么、让步不白给、底线不出让。

## 完整画面

策略包由 4 个阶段产物拼成，按"诊断 → 报价 → 议价 → 交付"递进：

1. **诊断**：客户砍价背后的真实动机（O1-O5 哪一类）
2. **报价**：4 档结构 + Why These Tiers 哲学
3. **议价**：客户 BATNA / 我方底价 / ZOPA 区间 + 3 种对话应对
4. **落地**：让步交换原则 + 折扣权限 + 风险登记 + 交付汇总

每一阶段都先想明白再做——跳过诊断直接开价是常见错误。

---

## 阶段 1 · 议价前诊断

**期望产物**：判断客户砍价属于 O1-O5 哪一类（或组合），决定后续应对方向。

**方法论做法**：先识别动机，再回应价格——同样的砍价动作，动机不同、回应不同。

| 动机 | 真实诉求 | 应对方向 |
|---|---|---|
| **O1 预算不足** | 真没钱 / 预算被砍 | 调账期/范围/多年合同，不调单价 |
| **O2 价格对比** | 在跟竞品比 | 价值再锚定，回到 ROI / 差异化 |
| **O3 决策风险** | 怕买错 / 怕担责 | POC / 绩效挂勾，把风险从客户转出 |
| **O4 政治因素** | 内部有人反对 | 帮客户找内部支持，绕过反对者 |
| **O5 优先级** | 真没急迫性 | 重塑紧迫感（成本/竞品/时间窗口） |

判定锚：**砍价是表象，动机才是抓手**。详见 [references/motivation-taxonomy.md](references/motivation-taxonomy.md)。

---

## 阶段 2 · 报价结构

**期望产物**：4 档报价 + 配套的 Why 哲学说明，让客户在"选择框架"内决策，而非"买 vs 不买"。

**方法论做法**：永远给 4 档——少 1 档客户没选择框架、议价空间小；多 1 档选择过载、决策延迟。

| 档位 | 倍数 | 角色 |
|---|---|---|
| Powerhouse 高锚 | 1.30-1.50x | 拉高心理价位 |
| Value ⭐ | 1.0x | 推荐档（甜蜜点） |
| Baseline 底线 | 0.40-0.50x | 范围/服务缩减 |
| Performance | 0.30-0.40x + bonus | 风险共担 + KPI 奖金 |

**Why 必附**——告诉客户为什么是 4 档、为什么中档 1.0x、为什么有绩效档、为什么高锚不夸张失信。每个 why 都回答一个"为什么不"。详见 [references/pricing-tiers.md](references/pricing-tiers.md)。

## 阶段 3 · BATNA + ZOPA + 议价对话

**期望产物**：议价区间 [客户底线, 我方底线] 清晰；3 种对话策略 + 砍价幅度分级应对就位。

### BATNA / ZOPA

**方法论做法**：议价目标是 ZOPA 中位偏上——锚定客户底线（最差）→ 锚定我方底线（不可越）→ 落点向中位偏上收敛。

- 客户 BATNA = 竞品 + 自建 + 不买（每条要有价格/成本/适配度）
- 我方底价 = 成本 + 折扣权限 + 战略价值 + 长期收益
- 议价区间 = [客户底线, 我方底线]

详见 [references/batna-zopa-checklist.md](references/batna-zopa-checklist.md)。

### 议价对话

**方法论做法**：3 种应对按"客户表达清晰度"选用——

| 策略 | 适用 | 目标 |
|---|---|---|
| **Reversal** 反问 | 客户说不清 / 模糊 | 让客户说出真实顾虑 |
| **Reframe** 重新框架 | 客户锚定竞品 / 只看价格 | 从 ROI/差异化重新定义问题 |
| **Clarify** 澄清 | 多顾虑 / 需优先级 | 确认客户真正在意的点 |

**砍价幅度分级**（规则——因为是判断锚）：

| 砍价幅度 | 应对 |
|---|---|
| < 5% | 接受，但换条件（年付/提前/案例权） |
| 5-15% | 让步 + 换回报（积累议价资本） |
| 15-25% | 升级 + 让步包 |
| > 25% | 触发红线 → 改范围/服务/账期，不改价格 |

判定锚：**每个让步都换回报，平白让步是最常见的失败模式**。详见 [references/negotiation-scripts.md](references/negotiation-scripts.md)。

## 阶段 4 · 落地交付

**期望产物**：让步交换包 + 折扣权限合规 + 10 类风险登记 + 一份完整策略包。

### 让步交换原则

**铁律**：每让步必换回报。

- **可交换**（折扣 ↔ 条件）：年付 / 多年合同 / 提前付款 / 案例权 / 转介绍 / 范围缩减 / 产品反馈
- **可单独给**（增值 ↔ 价格不动）：培训 / 服务 / 模块升级 / 优先支持

详见 [references/concession-trades.md](references/concession-trades.md)。

### 折扣权限

| 级别 | 折扣权限 | 触发升级的条件 |
|---|---|---|
| 销售代表 | ≤5% | — |
| 销售总监 | 5-15% | 客户潜力 / 竞争态势 |
| GM | 15-25% | 战略性大客户 |
| 红线 | >25% | 触发红线 → 改条款而非继续折扣 |

详见 [references/discount-authority.md](references/discount-authority.md)。

### 风险登记（10 类）

报价阶段重点盯的三维风险：**报价后沉默 / 砍价过大 / 要求免费试用 / 要求加量不加价 / 审批拖延 / 竞品压价 / 合同条款分歧 / 账期分歧 / 价格红线触发 / 价格倒挂**。

每条风险用"概率 × 影响 × 触发信号"评估，对应预案前置。详见 [references/risk-rubric.md](references/risk-rubric.md)。

### 交付策略包

策略包 = 诊断（O1-O5 判定） + 报价（4 档 + Why） + BATNA/ZOPA + 议价对话脚本 + 让步交换包 + 折扣权限 + 风险登记册 + 信息缺口 + 后续建议。

中国适配：RMB 报价、微信/企微沟通、招投标/三方比价/账期博弈、决策链识别（采购/财务/业务三方）。详见 [references/china-adaptation.md](references/china-adaptation.md)。

反模式与红线详见 [references/anti-patterns.md](references/anti-patterns.md)。
