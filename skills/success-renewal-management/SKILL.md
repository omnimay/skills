# 续约管理（success-renewal-management）

**核心命题：续约是救单，不是续约。**

合同到期前先给客户定性——一步健康分定三档，三阶段推进、每个决策门判断一次，守不住转 Plan B，Plan B 也守不住转 Plan C。主线每一步都是「判断 → 行动」，不是按清单对账。下周一上午拿到本主线就能动手，不需要先读懂任何 skill 上下文。

## 一、一步健康分：定性三档

6 维 0-10 加权：Usage 25% / Adoption 20% / Support 15% / Engagement 15% / Billing 15% / Sentiment 10%。**leading indicator 并入维度口径**——维度内出现风险信号就在该维内扣分（启用率 <60% 扣 Adoption；champion 离职 / 决策层失联扣 Engagement；竞品在评估扣 Sentiment；工单 spike 扣 Support），**不算完加权再校正一次**。判定一句话：总分 <5 = 🔴 救单模式 / 5-7 = 🟡 谈判续 / >7 = 🟢 无忧续。

三类红旗按 checkbox 照打：致命（7 天内必解）/ 严重（T-60 前缓解）/ 隐性（谈判窗口放大）。**判档偏保守**：致命红旗 ≥1 未解即按红档救单，不因加权落在黄/橙就放松。权重表、0-100 四档精细带、无 telemetry 替代证据见 `references/health-score-and-matrix.md`；续约档位 = 健康分 × 合同价值 → 5 档 matrix 见同文件。

## 二、一页纸结论（TL;DR）

先给结论再给过程。一页纸必含 6 格：续约概率（裸跑）/ 涨价概率 / 最大单点风险 / 最大单点机会 / **若只做一件事**（如「T-60 前把老板拉回对话圈」）/ **若放弃一件事**（如「不死磕涨 25%」）。附三种最可能结局（按概率排序）。

## 三、90 天三阶段 × 3 决策门

以合同到期日 T-0 倒推。每阶段 = 目标一句话 + 行动 + 决策门。**决策门是主线的判断位——不达标直接进 Plan B，禁止惯性执行全套动作。**

| 阶段 | 目标 | 行动 | 决策门（不达标 → Plan B） |
|---|---|---|---|
| 重塑期 T-90→T-60 | 稳住接任者、重建 IT 支持、拉回老板 | 老板画像 / 接任者破冰 / IT 复盘 / 使用热力图 / 财务备案 | 门 1（T-60）：老板同意 30-45 分钟复盘 / 接任者明确表态 / IT 出建议续约函——三条至少一条 |
| 决策期 T-60→T-30 | 把续约决策推上老板桌面、铺垫涨价 | 老板会议（先价值后价格）/ 涨价分阶段透露 / IT 深度绑定 | 门 2（T-45）：老板已表态 / 商务进入报价-还价 / 竞品评估状态明确——三条至少两条 |
| 锁定期 T-30→T-0 | 签约 + 条款敲定 + 防流失植入 | 报价单 / 锁定条款 / 还价管理 / 签约会 | 门 3（T-30）：正式报价已发 / 有明确签约路径 / 竞品未近签——三条至少两条 |

逐周动作 × 责任人 × 产出见 `references/renewal-timeline.md`；4 类人打法见第八章。

## 四、Plan B 撤退预案

3 触发信号：T-45 老板仍未表态且接任者明确在选竞品（续约概率 <20%）/ T-30 客户已与竞品签意向（<5%）/ 客户内部出现「必须换」强信号。进 Plan B 做 5 件事：保 1 年延保、争标杆案例授权、提供过渡期服务、锁 1 年内回流折扣、争取转介绍——把流失变成新单入口。合同保护条款（数据归还 / 过渡期 / 回流优惠 / 优先谈判权）见 `references/upstream-downstream-handoff.md`。

## 五、Plan C 战略性撤退

当 Plan B 也守不住（连缩量续的当前 ARR 都保不住）时，接受「撤」也是选项：接受免费/极低价续 6 个月，重点保留**数据迁移服务收费 + 转介绍收入 + 行业口碑维护**。体面退出，今天的客户是明年的合作伙伴。

## 六、Red Team 红蓝对抗

交付前演练对手剧本。**[竞品A] 常见 2-3 套**（「[核心卖点] 第一，[我方短板] 您保留」/「客户成功团队大 N 倍」/「打大幅折扣」）+ **[竞品B] 常见 2-3 套**（「老牌更稳定」/「同行业客户比你们多」）+ 我方反击：组合 TCO 拆穿（双系统/双账号/双培训/双维护 = 实际 TCO 显著更高）、数据锁定（历史数据迁移成本可达首年合同价的相当比例）、服务对比（已证服务次数 over 承诺）。话术按你实际面对的竞品现填，不预设结论。

## 七、续约谈判：报价 5 套餐 + 让步底线

报价直接上谈判桌，5 套餐由销售组合（以当前 ARR 为基准）：A 标准续约（现 ARR）/ B 长期锁定（现 ARR 打 9 折，签 3 年，涨幅锁 ≤8%）/ C 增购绑定（现 ARR 基础 + 增购模块价）/ D 标杆案例版（略降 + 公开授权）/ E 1 年延保（约现 ARR 的 8 折，Plan B 用）。先讲价值后报价，永远不先出价，降价必须换对价（年限/增购/授权/转介绍）。可让步：价格 / 付款节奏 / 赠模块 / 赠服务时长 / 赠培训。不可让步红线：价格跌破毛利兜底线 / 数据所有权让步 / 合同期 <1 年 / SLA 降级——红线由 VP/GM 人决策，AI 只给 scenario。Value Bridge 三段叙事与谈判话术见 `references/value-bridge-narrative.md`。

## 八、内部建联：4 类人 4 种打法 + 可直接抄的话术

| 角色 | 打法 | 话术（可直接复制） |
|---|---|---|
| EB（决策人） | 战略叙事：不第一封谈续约，走协会 / 引荐 / 老 champion 私交 | 「[EB 称谓]好，我们和贵司一起启动的 XX 系统已稳定运行一段时间，最近整理了一份运行情况，想当面请教几个战略问题，15-20 分钟就够」 |
| 接任 champion | 共赢绑定：用系统数据帮他「交作业」，信任期 4-6 周 | 「[接任者称谓]，接手这块半年，最大挑战是什么？我看看系统上怎么帮您减负」 |
| IT 盟友 | 升级赋能：给他稳定性报告让他向上汇报 | 「[IT 对接人称谓]，您提的几个建议我们都接入了，年底客户技术峰会想请您做分享嘉宾」 |
| 基层用户 | 故事化激活：3-5 个标杆一线用户录 30 秒视频 | 让老板在决策前已听到一线的声音 |

决策结构重画与画像细节见 `references/save-plan-template.md`。

## 九、关键数字备忘（每周一更新）

7 个指标表：续约概率 / EB 触达次数 / 接任 champion 信任度（0-10）/ IT 盟友书面支持 / 竞品评估状态 / 签约价格 / 合同年限，每列当前值 + T-60/T-30/T-0 目标。**周一上午第一件事更新这张表——数字不动就是动作没做。**

## 十、收尾：给销售自己的心理建设

你不是在续约，你是在救单。涨价一次性拿走的概率通常不超过 25%，别赌。最优解大概率是保住现 ARR 的 8-9 折、签 3 年 + 增购 + 标杆授权——终身价值比现 ARR/1 年高 30-50%。EB 是命门，所有动作的优先级都是让他重新出现在对话圈。即便输了，也要让客户输得体面。做对的事，不做容易的事。

## 判定标准（交什么）

交付一份「续约作战手册」，必含：① 一页纸结论 ② 一步健康分 + 三类红旗 ③ 90 天三阶段 × 3 决策门 ④ Plan B ⑤ Plan C ⑥ Red Team（竞品剧本与反击）⑦ 报价 5 套餐 + 让步底线 ⑧ 建联话术 ⑨ 关键数字备忘表 ⑩ 心理建设。附待确认问题（最多 3 个）；要量化预测时出概率加权预测表（`references/renewal-forecast.md`）。**交付不含「自检」**——自洽检查是出版前动作，不进用户方案。

## 边界

- **做**：存量合同临近到期，续约分档、预测、save、谈判、成交。
- **不做**：新单报价（`clinch-negotiation-pricing`）/ 增购扩张（`success-expansion`，本 skill 只续旧约）/ 已流失挽回（流失挽回场景）。上游接首价值证明 + `success-business-review`。
