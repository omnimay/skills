# ICP 校准/画像定义

ICP（Ideal Customer Profile）回答一个问题：**我到底该卖给哪类公司**。它是公司/账户层面的描述（不是具体的人），上游决定找线索去哪找，下游决定什么样的线索该淘汰。

**真实 ICP 来自成交数据，不是拍脑袋。** 从 0 定义的 ICP 只是假设，拿到 10-20 个真客户后必须修订。

## 先澄清（只问最改变产出的 2-3 个，不逐条问卷）

澄清问题按使用场景选，不固定三问：
- 有没有成交客户（哪怕 3-5 家）？——决定走"从客户校准"还是"从 0 定义"
- 产品帮客户完成什么任务（JTBD）？——锚定行业/替代方案/触发信号
- 现有哪些触达渠道（EDM/企微/电话/展会/招投标网/协会）？——够不着客户的 ICP 是纸上谈兵
- 谁拍板/客单价量级？——决定目标企业规模档位（小微/中型/大型/政企）

停止规则：用户说"直接出"就带假设推进，假设列在交付开头。

## 八维参考框架

思考时按这八维过一遍，**交付时只写与本次提问相关的维度，不必八维全出**：

| 维度 | 写具体，不写虚词 |
|---|---|
| 行业 | 国民经济行业分类口径（"汽车零部件制造"而非"制造业"）；可加产业集群（佛山家具、深圳3C、苏州生物医药、义乌小商品） |
| 企业性质 | 央企/国企、民企、外企、专精特新/高新技术企业——不同所有制采购流程完全不同 |
| 规模 | 用**参保人数**（工商口径）而非"员工数"：如 100-2000 人 |
| 地域 | 具体到省/市/产业带 |
| 买家角色 | 一把手（老板/总经理）、分管副总、部门经办——写清本产品主攻哪层 |
| 现状替代 | Excel+人工 / 本地软件 / 不解决 / 竞品 |
| 触发信号 | 融资到账、中标新项目、政策补贴/认定、扩产招聘、数字化改造立项、领导换届 |
| 可达渠道 | 本产品能触达的通道：邮件、企微、电话、展会、招投标网、行业协会 |

检验标准：另一个销售读完你的画像，能不问你就说出"该找谁、不该找谁"。

## 决策框架

**锐利度检验**：按这个描述，明天能把一份符合的公司名单交给电销吗？不能就再收窄。
- 虚："快速增长的消费品牌" 
- 锐："华南消费品行业，参保 100-500 人，有 30 人以上电销团队，用企微做客户沟通，销售沟通质检还靠人工抽查"

**淘汰力标准**：真 ICP 必须能淘汰掉大多数公司。"100-10000 人的企业""有创新精神的公司"等于没说。

**触发信号强弱**：
- 强（引发采购动作）：新领导上任 60 天内、融资到账、中标大项目、政策认定公示（专精特新/高新）、扩产招聘、数字化改造立项
- 弱（不构成时机）："他们可能需要""他们有预算"

**可达性检验**：每个 ICP 都要过一遍——现有渠道能找到并联系上他们吗（EDM 邮箱可得？有行业展会？在协会名录里？）。够不着 = 学术练习。

**资格打分清单**：ICP 要给销售用，就得蒸馏成 yes/no 打分项（行业/规模/性质/决策人参与/痛点确认/预算/时间窗），如 5 个 yes = 强线索、<3 个 = 淘汰。定义和校准类交付通常都该带一份。

## 常见使用场景

**1. 从 0 定义（新产品/新方向）**
用设计伙伴/试点客户当代理，或访谈 5-10 个理想目标 → 产出 ICP 定义（含假设声明+资格打分清单）→ 标注"10-20 个真客户后修订"。
验证：销售能从 inbound 里认出这些公司吗？营销能定向到这批名单吗？

**2. 从成交客户校准**
拉 top 20 客户（按健康度/收入/增购排序）→ 找共性（规模/行业/角色/触发信号/技术栈）→ **对比原 ICP 找差异** → 产出：差异报告 + 更新后的打分清单 + 行动项（含**砍掉不在真实 ICP 里的老分段**）。

**3. 管道诊断（线索多但转化差）**
对比 closed-won vs closed-lost 的 ICP 契合度 → 常见病根：管道里塞满"边缘 ICP"（过了行业规模，但买家角色错/没决策人参与）→ 产出：诊断 + 收严入口的处方（预期线索量下降、转化率上升）。

## 反模式（见到就拦）

- **ICP = 谁都是** → 获客资源稀释
- **用产品定义客户**："需要我们产品的公司" → 方案思维，客户画像不是产品功能镜像
- **没有触发信号** → 有名单没紧迫感
- **现有渠道够不着** → 纸上谈兵
- **淘汰不了任何公司** → 不是 ICP
- **没有打分清单** → 销售用不起来
- **三年不刷新** → 客户数据早已揭示真实 ICP

## 数据源能力边界（支撑可达性判断，写进交付帮用户设定期望）

| 能力 | 说明 |
|---|---|
| 政府公示名单（专精特新/高新技术企业认定） | 公开可检索，名单原文可直接获取；公示页通常只有企业名，联系方式可能在附件 |
| 上市公司公告信号（中标/融资/年报） | 巨潮资讯网公开接口可查，支持关键词全文检索 |
| 工商全量筛选（企查查/天眼查/爱企查高级筛选，全行业通用主力） | 走企查查官方 MCP（`https://mcp.qcc.com/basic/stream`，第三方收费服务，需用户自行开通账号与授权）或用户自有账号；匿名访问会触发登录墙/验证码，不绕过 |
| 招聘/职场社交平台（BOSS直聘/脉脉等） | 平台限制严格：公开可见部分（搜索引擎收录的职位信息）可用；平台内查询由用户在其账号自行完成 |

## 相关技能

- **icp-company-search**（下游）：用户校准完 ICP 想直接找名单时，把画像结论交给它执行全网检索
- **lead-enrichment**：名单到手后补联系人/联系方式
- **prospect-landing-research**：名单里锁定重点客户后，深挖决策链与切入点
- **cold-email**：触达话术及邮件发送
