# 需求验证（Requirement Validation）v0.1.0

## 一、场景感知（报告头必挂）

**报告头 5 行强制写**，禁止用模板场景替换用户实际场景：

```
客户：[公司名 · 规模/行业]
场景来源：[外联后续 / 客户主动联系 / 招标平台 / 会议纪要]
对接人：[姓名 + 职务]
已收到信号（3-5 条原话）："[客户原话 1]" / "[原话 2]" / ...
粒度：单条需求（不是账户级、不是线索级）
```

→ **没挂这 5 行不算出报告**。这步是阻断"用模板场景替换用户场景"的关键。

---

## 二、判定体系（4 档 + 5 件套）

### 5 件套（按优先级串行）

1. **硬排除** —— 非目标行业 / 长期竞品续约 / 能力完全不匹配 / 空壳失信 / 监管限制 → 命中 = 直接假痛+淘汰
2. **真伪信号** —— 真痛信号 ≥3 条且含 +2 = 真痛候选；假痛信号 ≥3 条或命中 #10（拒数字）= 假痛
3. **急迫性档** —— 急 ≤30 天 / 中 30-90 / 慢 90-180 / 不急 >180；客户原话时间 > 推断
4. **Gap 三件套** —— 现状 + 不作为代价 + 切换成本；三件齐 = 真痛；二件齐 = 部分真；切换成本 > 不作为代价 = 假痛
5. **能力匹配** —— 行业 / 产品 / 交付 / 合规 4 维；硬不符 = 假痛

信号词典、急迫性档位、硬排除清单、Gap 三件套判据 → `references/pain-truth-signals.md` + `references/gap-quantification.md`

### 4 档动作路径（每档必须接动作，不停在分析）

| 档位 | 判定条件 | 下游动作 |
|---|---|---|
| **真痛** | 5 件套全过 | 进入 ROI 论证（高优 24h 内启动） |
| **部分真** | 任 1 件不过 | **限定投入 + 二次验证**（指定补哪件信号 + 14 天退出闸门，**不停在"再挖"**） |
| **假痛** | 硬排除命中 / 假痛信号 ≥3 | **淘汰 + 资源归还**（不入漏斗） |
| **不急** | 痛点真 + 急迫性 >90 天 | **长尾监测**（3-6 月复查 + 触发事件） |

### 中国适配速判（4 类）

| 需求类型 | 信号特征 | 验证重点 |
|---|---|---|
| **央国企流程合规** | 招标 / 政策驱动 / 委员会 | Gap 合规权重极高；决策人 = 招标委员会 + 分管副总 |
| **民企效率需求** | 老板直接拍 / 业务驱动 | Gap 客户流失/老板问责权重高；节奏快 |
| **政绩工程** | 领导要求 / 节点性强 | 急迫性高但**要追业务真痛**（政绩 ≠ 真痛 = 部分真） |
| **真业务痛点** | 多部门抱怨 / 数字可量化 / 已尝试过 | 标准路径走全流程 |

## 三、追问路径（SPIN + 5 Why + 含蓄解码 + 微信适配）

### SPIN 四层顺序（不让客户自己讲 = 反编造核心）

```
S 现状  →  P 问题  →  I 影响  →  N 价值
"现在怎么做的"   "具体哪里卡"   "不解决会怎样"   "如果搞定了您最受益什么"
```

**纪律**：一次只问一层；客户答空用原话再追一次；**N 必须让客户自己讲**（销售不替解释"您应该是想降本增效"）；跳步 = 客户答得空。

### 根因追问三选一

- **5 Why** —— 线性原因（"为什么 X"层层下挖）
- **假设验证** —— 主观判断（"老板说过哪句话让你判断他重视"）
- **复盘对照** —— 方向选择（"XX 行业 XX 公司这样做效果 XX"）

三选一按场景取，混用 = 错位。SPIN + 5 Why + MEDDIC Identify Pain 5 子问法 → `references/bant-need-framework.md`

### 中国含蓄表达解码（10 类必追）

| 客户原话 | 实际信号 | 第一句追问 |
|---|---|---|
| "最近难做" | 含蓄痛点 | "具体哪个环节？" |
| "不太好管" | 含蓄痛点 | "团队多大、怎么分工？" |
| "上面抓得紧" | 真实触发 | "哪位领导推、要求什么？" |
| "今年要降本增效" | 真实方向 | "公司定的、有指标吗？" |
| "我们都想这样" | 低信号套话 | "您身边谁做到了？" |
| "我再了解一下" | 大概率不急 | 标长尾，3-6 月复查 |
| "行，回头再聊" | 大概率不急 | 标长尾，等触发事件 |
| "价格再谈谈" | 中信号 | "预算大概范围？" |
| "我们也有别的方案" | 中信号有竞品 | "现在用什么、卡在哪？" |
| "你们不错/口碑好" | 社交礼仪 | 不当真痛，追问场景 |

**核心纪律**：含蓄表达 ≠ 无需求；客套话 ≠ 高意向；沉默 ≠ 拒绝。完整解码 + 微信场景适配 → `references/china-implicit-language.md` + `references/wechat-conversation-flow.md`

### 三角色对位硬纪律（中国三角分离 = 常态）

- **决策人**（拍板 + 批预算 + 签合同）—— 民营：总经理；国企：分管副总 / 招标委员会；互联网：VP
- **使用人**（每天用 + 反馈问题）—— 业务负责人 / IT / 执行岗
- **受益人**（KPI 挂钩 + 背锅）—— 老板 / 业务线总监 / 合规

**三角缺一 = 部分真**，必须再挖指定信号。中国 title 映射 + 识别方法 → `references/pain-triad-china.md`

### Gap 三件套量化（中国 = 合规 > 客户流失 > 老板问责 > 钱）

- **现状**：现在怎么凑合（不是痛点本身；"3 人维护 4 张 Excel"）
- **不作为代价**：6/12/24 月代价，至少答一档可量化；优先算合规罚款 / 客户流失 / 老板问责
- **切换成本**：钱 + 时间 + 学习 + 风险至少 2 维

## 四、24 小时动作三件套（强制输出）

> **每条带：动作 / 责任人 / 时间 / 产出物**。4 档每档必须给 ≤3 条具体动作，**禁止停在"再挖指定信号"**

### 真痛档（推下游）

1. 推 ROI 论证 → 责任人 = 销售；24h 内；产出物 = ROI 资料 + 客户回执
2. 邀约决策人会议 → 48h 内；产出物 = 会议邀请 + 议程
3. 内部对齐报价基线 → 72h 内；产出物 = 团队确认 + 报价单骨架

### 部分真档（限定投入，不停在"再挖"）

1. 二次会议（限定 1 个补信号）→ 责任人 = 销售；产出物 = 议程 + 退出条件
2. 限定跟踪期 ≤14 天 → 产出物 = 进度看板（每日/每周更新）
3. 退出闸门 → 14 天未达信号 = 降级长尾；产出物 = 升级/降级决定（含客户通知话术）

### 假痛档（淘汰）

1. 资源归还 + 退出邮件 → 责任人 = 销售；24h 内；产出物 = 内部通知 + 客户告别（不贬损）

### 不急档（长尾监测）

1. 标长尾 + 触发事件 → 24h 内；产出物 = CRM 长尾标签 + 触发事件定义（如"库存周转恶化 / 老板重启"）
2. 微信 3-5 天后再触（≤80 字 / 一次一问）
3. 季度复查 → 3/6 月；产出物 = 复查表 + 升降级决定

## 五、自检与避坑

### 5 条自检（出报告前必过）

1. 报告头 5 行挂了？（场景感知）
2. 4 档结论有证据？每条挂"客户原话 + 来源 + 置信度"？无证据标 `missing`？
3. 三角色齐全？缺一 = 部分真？
4. Gap 三件套齐？缺件标"未量化"？
5. 24 小时动作三件套挂了？每条带责任人 + 时间 + 产出物？

### 归因反例（10 条必避）

| 念头 | 后果 |
|---|---|
| 「客户说痛就是痛」 | 嘴上痛、无行动、无事件、无数字 = 假痛；**按信号分档** |
| 「含蓄表达 = 无需求」 | "难做/不太好管/抓得紧"是含蓄痛点；不追问 = 漏真痛 |
| 「没验证就跳下游算 ROI」 | 给假痛客户白送 ROI 资料；**先验证真伪再推下游** |
| 「客户客气 = 高意向」 | "会考虑/回头再聊/了解一下"= 大概率不急 |
| 「只打分档不分证据」 | 销售拿到不知道怎么用 |
| 「对接人 = 拍板人」 | 中国三角分离；只问对接人 = 错位 |
| 「用 LinkedIn / G2 / Apollo 判信号」 | 中国无此数据；改用企查查 / Boss 直聘 / 招标 / 知乎 / 微信搜一搜 |
| 「算账给纯财务数字」 | 中国客户对钱敏感度低；优先算合规 / 老板问责 / 客户流失 |
| 「用面对面对话模板跑微信」 | 微信断点多 / 可被截图 / 可被转介；按 wechat-conversation-flow 适配 |
| 「部分真档不停在"再挖"」 | 必须接动作 = 限定投入 + 二次验证 + 退出闸门 |

## 附录 · Ready-to-use 话术（按需复制）

### A. 30 秒电梯版（部分真 / 不急后动）

> 张总，[场景来源] 这条需求目前看 [一句话档位判断]。我这边 [限定动作：试点 / 二次会议 / 长尾监测]，具体 [时间 + 责任人]。您看方便吗？

### B. SPIN 四阶段第 1 句

- **S**："您 [痛点] 这块，现在团队怎么处理的？"
- **P**："具体哪里卡？卡多久了？"
- **I**："不解决会怎样？老板/客户/合规怎么看？"
- **N**："如果搞定了，您这边最受益的是什么？"（让客户自己讲）

### C. 决策人识别 4 句

- "您拍板这事的话，自己定还是要走流程？"
- "合同怎么走？"
- "预算哪条线批？"
- "做成了谁拿到好处最大？"

### D. 含蓄表达标准追问（10 类见正文三章"中国含蓄表达解码"）

### E. 不替客户解释反例

- ❌ "您应该是想降本增效吧" → 销售脑补
- ✅ "如果搞定了，您最希望看到什么变化？" → 让客户自己讲

### F. 微信场景 5 阶段节奏

开场（≤3 句）→ 试探痛点（1-3 轮一次一问）→ 影响追问（2-3 轮假设性问题）→ 决策人识别（自然融入）→ 推进/收尾（不推产品/报价，约 30 分钟电话/腾讯会议）
