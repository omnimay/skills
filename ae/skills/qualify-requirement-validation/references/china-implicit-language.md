# 中国含蓄表达解码

> 本文件是 SKILL.md 主线 Step 2 追问 + Step 3 解码的**语言判据词典**。中国 B2B 销售沟通的最大风险 = 把含蓄表达当无需求、或把客套话当真痛。

---

## 一、核心纪律（先背这条）

```
含蓄表达 ≠ 无需求
客套话 ≠ 高意向
沉默 ≠ 拒绝
```

**反例**：把"最近难做"当无需求 = 漏真痛；把"会考虑"当真痛 = 误判假痛。

---

## 二、常见含蓄表达解码（10 类）

| # | 客户原话 | 实际信号 | 处理 |
|---|---|---|---|
| 1 | "最近难做" / "不太好做" | **含蓄痛点**，有潜在需求 | 追问"具体哪块难做" |
| 2 | "不太好管" / "管不过来" | **含蓄痛点**，多半缺工具/流程 | 追问"团队多大、怎么管的" |
| 3 | "上面抓得紧" / "领导要求" | **真实触发**，合规/政策驱动 | 追问"哪位领导、要求什么" |
| 4 | "今年要降本增效" | **真实方向**，需追问落点 | 追问"具体降什么、增什么" |
| 5 | "我们都想这样" | **低信号**，套话 | "举个最近例子" |
| 6 | "我再了解一下" | **大概率不急/不痛** | 标"长尾"，3-6 月复查 |
| 7 | "行，回头再聊" | **大概率不急/不痛** | 标"长尾"，等触发事件 |
| 8 | "价格再谈谈" | **中信号**，需追预算/痛 | 追问"预算大概范围" |
| 9 | "我们也有别的方案" | **中信号**，有竞品 | 追问"现在用什么、卡在哪" |
| 10 | "你们不错" / "口碑好" | **低信号**，社交礼仪 | 不当真痛，要追问场景 |

---

## 三、追问方法

### 追问三原则

1. **用客户原话再追问一次**——让客户展开，不替他说。
2. **追问一个具体场景**——从"行业/公司"问到"上周/昨天/某个具体动作"。
3. **不问"为什么"，问"怎么发生的"**——"为什么难做" = 防御；"具体怎么个难做法" = 引导叙述。

### 标准追问话术

| 含蓄表达 | 第一层追问 | 第二层追问 |
|---|---|---|
| "最近难做" | "具体哪个环节？" | "上周什么场景最明显？" |
| "不太好管" | "团队多大、怎么分工？" | "最近最操心哪件事？" |
| "上面抓得紧" | "哪位领导推？要求什么？" | "不改会有后果吗？" |
| "降本增效" | "公司定的？有指标吗？" | "最难的是哪一块？" |
| "我们都想这样" | "您身边谁做到了？" | "做到最缺什么？" |
| "我再了解一下" | "主要想了解哪方面？" | "需要我准备什么资料？" |

## 四、微信场景的含蓄表达

微信沟通比面对面更含蓄：

| 微信表达 | 实际信号 |
|---|---|
| 客户发 "嗯" / "👌" | **已读**，但**不主动 = 低信号** |
| "最近忙，回头聊" | **大概率长尾** |
| 语音 vs 文字 | **语音 = 更放松** |
| 转发文章/链接 | **可能在暗示痛点**，追问"哪里说到您心里去了" |
| 客户拉群/介绍他人 | **可能进入决策流程**，但要先验证真伪 |

**微信追问纪律**：一次一个问题；客户已读不回 = 隔 3-5 天换个话题再接触，不催。

---

## 五、四个确认步骤

每次遇到含蓄表达：

1. **标信号**：用本文档表格打标（高/中/低信号）
2. **追问**：用对应话术问一层
3. **听回应**：客户能不能展开 = 真痛信号；转移话题 = 假痛信号
4. **判定**：按 pain-truth-signals.md 词典打档

**禁止**：把含蓄当无需求；把含蓄当真痛；销售替客户解释（脑补）。

---

## 六、含蓄表达的硬排除（直接判假痛）

- "我们有自己的办法" / "我们自己能搞定" = 无需求或拒绝
- "等老板回来再说" + 老板长期不在 = 无行动能力
- "价格太低/太高不考虑" 但说不出预算 = 比价 / 无痛
- "今年没预算" + 不给原因 = 假痛或不急

## 七、案例对照（3 个常见含蓄）

### 案例 1：含蓄真痛
- 客户："最近难做。"
- 追问："具体哪块？"
- 客户："团队从 5 人变 30 人，流程跟不上了。"
- 再问："什么时候开始？试过什么？"
- 客户："去年底，试过 Excel 不行。"
- **判定**：真痛候选（信号 #1 时间起点 + #4 已尝试）

### 案例 2：含蓄假痛
- 客户："我们都想这样。"
- 追问："做到最缺什么？"
- 客户："说不上来，大家都应该做。"
- 再问："身边有人做到了吗？"
- 客户："没特别了解。"
- **判定**：假痛（套话、无场景、无数字）

### 案例 3：含蓄不急
- 客户："今年要降本增效。"
- 追问："公司定的？有指标吗？"
- 客户："没具体指标。"
- 再问："您部门最想降什么？"
- 客户："还没想清楚，明年规划。"
- **判定**：不急（方向真但时间窗口长）
