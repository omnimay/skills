# 微信对话流程

> 本文件是 SKILL.md 主线 Step 2 追问 + Step 3 解码在**微信场景**下的适配。中国 B2B 销售 80% 以上的初次沟通在微信完成；面对面对话模板搬到微信 = 失灵。

---

## 一、微信 vs 面对面：5 个本质差异

| 维度 | 面对面 | 微信 | 适配要点 |
|---|---|---|---|
| **节奏** | 一气呵成 | 断点多（客户忙/开会/开车） | 不要假设马上回 |
| **信息密度** | 高 | 低（一句话一件事） | **一次问一个问题** |
| **可被截图** | 否 | 是（可转发老板） | **不说同行坏话、不承诺数字** |
| **可被转介** | 难 | 易（一条消息转发） | 转出去 = 你就在决策人面前 |
| **可被存档** | 否 | 是 | **白纸黑字**，要善用 |

---

## 二、微信对话节奏（5 阶段）

### 阶段 1：开场（≤3 句话）

```
张总您好，我是 XX 公司 XX。
看到您 [公号/Boss直聘/招标] 提到 [具体痛点]，
想请教 2-3 分钟，您看方便？
```

**禁忌**：一上来发产品介绍/PPT；一上来问"有没有 XX 需求"；不提具体来源。

### 阶段 2：试探痛点（1-3 轮）

- 每次**只问一个问题**。
- 客户答得空 = 换角度再问，**不要连续 3 次空就放弃**。
- 客户主动说事件/数字 = **立刻追问一个具体场景**。

**示例**：
- 你："您 [痛点] 这块，现在团队怎么处理的？"
- 客户："用 Excel 凑合。"
- 你："用多久了？" / "现在撑得住吗？"

### 阶段 3：影响追问（2-3 轮）

- 不直接问"这给您带来什么影响"。
- 用**假设性问题**："如果一直不解决，下个季度会怎样？"

### 阶段 4：决策人识别（自然融入）

- "您拍板这事的话，自己定还是要走流程？"
- "团队里还有谁会用到？"
- "做成了谁拿到好处最大？"

### 阶段 5：推进 / 收尾

- **不要在微信里推产品/报价**。
- 推进话术："我准备一个 XX 方案，约个 30 分钟电话/腾讯会议详细聊，您周几方便？"
- 客户客套 → 明确收尾："我先把资料整理好发您，有需要随时找我。"

## 三、断点处理（5 类）

| 断点 | 客户表现 | 处理 |
|---|---|---|
| **已读不回** | 读了但没回 | 隔 3-5 天换个话题（"看到您朋友圈提到 XX"） |
| **延迟回复** | 隔 1-3 天才回 | 正常，不催；下次缩短信息密度 |
| **客户转介** | "我让 XX 跟你聊" | **立刻问清 XX 是决策人/使用人/受益人**，按新角色追问 |
| **客户拉群** | 拉进 3 人以上群 | **立刻判断谁是决策人**，下次围绕决策人展开 |
| **客户截图给老板** | 突然问很细节 | **客户在验证你说的话**，一句话 + 一个证据，不长篇 |

---

## 四、信息密度（每条消息 ≤ 80 字）

**原则**：
- 一条消息 = 一个意思；超过 80 字 = 客户不会看。
- 能用问句不用陈述句（问句 = 客户必须回应）。
- 能用语音不用长文字（语音更放松，但要简短）。

**反例**：一条 200 字产品介绍 = 直接划走；一条塞 3 个问题 = 客户答哪个？

**正例**：
- ✅ "张总，方便问一句吗？您 [痛点] 是去年开始的吗？"
- ✅ "明白，那现在团队怎么分工？"
- ✅ 60 秒语音：一句问句 + 一个场景。

---

## 五、可被截图 / 转介的纪律

### 能说的

- 方法论框架（BANT/SPIN/Gap Selling）。
- 对客户行业的理解。
- 客户自己的话复述（共同确认证据）。
- 下一步动作（"我准备一个 XX 方案"）。

### 不能说的

- ❌ 同行坏话（截图 = 完蛋）
- ❌ 具体价格（截图 = 没回旋）
- ❌ 客户未确认的信息（"听说您 XX" = 反驳风险）
- ❌ 任何"独家"承诺

## 六、微信 vs 电话 vs 会议

| 方式 | 适合 | 不适合 |
|---|---|---|
| **微信** | 初次接触 / 试探 / 留证据 | 详细追问 / 拍板 |
| **电话** | 影响追问 / 决策人识别 | 初次接触 |
| **腾讯会议** | 方案讲解 / 三角色对齐 / 拍板 | 初次接触 |

**节奏**：微信试探 → 微信追问 2-3 轮 → 转电话 → 转会议拍板（每一步有升级条件，不一步到位）。

## 七、关键信号识别

| 信号 | 解读 |
|---|---|
| 客户语音 | **高信号**，愿意展开 |
| 客户主动追问 | **真痛候选** |
| 客户长文字 | **真痛候选** |
| 客户转发文章 | **可能暗示痛点** |
| 客户发 "👌" / "嗯" | **低信号**，已读不主动 |
| 客户转给老板 | **进入决策流程**，立刻调话术 |
| 客户问报价/合同 | **真推进**，回头验证痛点 |
| 客户突然冷下来 | **有变**（找竞品/老板否决），主动问 |

---

## 八、与下游 skill 的接力

- **微信里客户明确说痛 + 主动追问** → 真痛候选 → 转电话/会议 → 进入 ROI 论证
- **微信里客户含蓄/客套** → 部分真 → 本 skill 再挖指定信号
- **微信里客户已读不回 / 转介他人** → 标"长尾"，按痛点真伪信号打档
- **微信里客户转给老板** → 三角色对位完成一部分 → 转会议拍板

---

## 九、反例（不要踩）

- ❌ 用面对面对话模板跑微信（连珠炮 = 防御）
- ❌ 在微信里推产品/报价（截图传播 = 死局）
- ❌ 已读不回还硬催（关系破裂）
- ❌ 一条消息塞多个问题
- ❌ 客户转介后还跟原对接人聊（错失决策人窗口）
- ❌ 客户冷下来不主动问（错过调整窗口）
