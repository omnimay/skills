# 现状差距量化 · Gap Selling 应用

> 本文件是 SKILL.md 主线 Step 4 判定 + Step 5 交付报告「现状差距量化」章节的**量化判据词典**。Gap Selling 三件套（现状 + 不作为代价 + 切换成本）是真痛判定的硬条件；三件齐 = 真痛，二件齐 = 部分真，少于二件 = 假痛候选。

---

## 一、核心纪律（先背这条）

```
真痛 = 现状描述 + 不作为代价可量化 + 切换成本可承担
部分真 = 缺其中任一件
假痛候选 = 三件都缺 或 切换成本 > 不作为代价
```

**反例**：客户说痛但说不清现状/代价/成本 = 假痛；切换成本 > 不作为代价 = 假痛（他不会买）。

---

## 二、Gap Selling 三件套

### 件 1：现状（Where they are now）

**问什么**：现在用什么方式做？多久了？几个人？卡在哪？

**输出**：现状方案描述（**当前怎么凑合**，不是痛点本身）。

**示例**：
- ✅ "3 个人维护 4 张 Excel，去年开始，每次合并要 2 天"
- ✅ "用 XX SaaS，但只用 20% 功能，剩下靠人工"

### 件 2：不作为代价（Cost of inaction · CoI）

**问什么**：不解决的话，6/12/24 个月后会怎样？老板/合规/客户怎么看？

**输出**：不作为代价（**至少答一档可量化**）。

**中国客户对钱敏感度低、对合规/老板拍板敏感度高**，优先算这几类：

| 代价类型 | 量化方法 | 中国场景权重 |
|---|---|---|
| **合规罚款** | 监管罚款 + 整改成本 | **极高**（数据安全法/网安法/上市合规） |
| **客户流失** | 流失数 × 客单价 × 留存率 | **高**（续约型业务） |
| **老板问责** | KPI 完不成 → 晋升/奖金/换岗 | **高** |
| **竞品赶超** | 竞品上线 → 我方客户流失率 | 中 |
| **人力成本** | 多雇 X 人 × 年薪 | 中 |
| **加班/返工** | 每月加班费 + 返工损失 | 中 |
| **业务损失** | 错过商机/项目延期 | 中 |

**示例**：
- ✅ "数据安全法最高罚 5000 万，去年同行 XX 被罚"
- ✅ "续约流失 30% × 客单价 50 万 = 一年丢 1500 万"

### 件 3：切换成本（Cost of switch）

**问什么**：换个方式要付出什么？钱/时间/学习/风险？换多久能用起来？

**输出**：切换成本（**至少答 2 个维度**）。

| 维度 | 量化方法 |
|---|---|
| **钱** | 采购 + 实施 + 培训 |
| **时间** | 部署 + 学习 + 见效周期 |
| **学习** | 团队从 0 到能用要多久 |
| **风险** | 数据迁移 + 业务中断 + 试错 |

**示例**：
- ✅ "采购 80 万 + 实施 30 万 + 培训 20 万 = 130 万"
- ✅ "团队 30 人从 0 学，预计 3 个月用熟"

---

## 三、三件套组合判定

| 现状 | 不作为代价 | 切换成本 | 判定 |
|---|---|---|---|
| ✅ 清晰 | ✅ 可量化 | ✅ 可承担 | **真痛** |
| ✅ 清晰 | ✅ 可量化 | ❌ 不可承担（>代价） | **假痛** |
| ✅ 清晰 | ❌ 不可量化 | ✅ 可承担 | **部分真** |
| ❌ 不清晰 | ✅ 可量化 | ✅ 可承担 | **部分真** |
| ✅ 清晰 | ❌ 不可量化 | ❌ 不可量化 | **假痛** |
| ❌ 不清晰 | ❌ 不可量化 | ❌ 不可量化 | **假痛** |

**口诀**：三件齐 = 真痛；二件齐 = 部分真；二件齐但切换 > 代价 = 假痛；少于二件 = 假痛。

## 四、追问话术

### 追问「现状」

| 客户答得空 | 追问 |
|---|---|
| "我们就这样做" | "具体几个人做？维护什么？" |
| "用 Excel" | "多少数据量？谁合并？多久一次？" |
| "靠老员工经验" | "老员工离职怎么办？" |

### 追问「不作为代价」

| 客户答得空 | 追问 |
|---|---|
| "代价很大" | "最近一次痛的是哪次？" |
| "老板会不满意" | "不满意会怎样？影响什么？" |
| "没特别算过" | "如果一定要量化，一年多少？" |

**中国客户特殊追问**：
- "这事被监管查到，按数据安全法最高能罚多少？"
- "续约客户流失 X%，按客单价一年多少？"
- "KPI 完不成，老板会怎么处理？"

### 追问「切换成本」

| 客户答得空 | 追问 |
|---|---|
| "应该不大" | "钱 + 时间 + 学习 + 风险，估计多久上手？" |
| "我们不在意成本" | "切换出问题最坏情况是什么？" |
| "已经在用别的" | "现在卡点？换新要付出什么？" |

## 五、量化数字怎么算

**3 个技巧**：

1. **范围逼问法**："一年大概 XX 万？100 万以下？1000 万以下？" → 客户从大范围往小缩 = 真数字
2. **对比逼问法**："如果损失 X%，按客单价一年多少？" → 客户说"差不多" = 真信号
3. **第三方锚定法**："同行 XX 被监管罚了 X 万" / "数据安全法最高罚 5000 万" → 客户认可 = 真信号

**禁止**：销售自己编数字；用百分比代替绝对值；用模糊词代替数字。

## 七、与下游 skill 的接力

- **三件齐 + 真痛信号 ≥3** → 真痛 → 进入 ROI 论证（用本文件 CoI + CoS 数据）
- **二件齐 + 部分真痛信号** → 部分真 → 本 skill 再挖缺失那件
- **三件都缺 / 切换 > 代价** → 假痛 → 淘汰
- **三件齐但时间窗口长** → 不急 → 长尾监测 + 触发事件

---

## 八、反例（不要踩）

- ❌ "客户说痛就给三件套打勾" → 没量化 = 部分真
- ❌ "用百分比代替数字" → 不可信
- ❌ "只算钱不算合规/老板问责" → 中国客户不敏感钱
- ❌ "切换成本只算钱不算时间/学习" → 不完整
- ❌ "用 ROI 算账代替 Gap Selling" → Gap 是验证真伪，ROI 是下游算账
