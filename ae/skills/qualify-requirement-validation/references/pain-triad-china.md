# 三角色对位 · 决策人/使用人/受益人 + 中国 title 映射

> 本文件是 SKILL.md 主线 Step 3 三角色对位 + Step 5 交付报告「三角色对位」章节的**判据词典**。中国 B2B 三角分离是常态，三角缺一 = 部分真，必须再挖。

---

## 一、三角色定义（必须分清）

| 角色 | 职责 | 关键问题 | 错位典型 |
|---|---|---|---|
| **决策人** | 拍板、签合同、批预算 | "谁拍板？" / "合同谁签？" / "预算谁批？" | 把对接人当决策人 |
| **使用人** | 日常使用产品、提需求、反馈问题 | "谁每天用？" / "出问题谁找？" | 把老板当使用人 |
| **受益人** | 用得好能拿到好处（KPI/晋升/免责） | "用好了谁拿到好处？" / "出问题谁背锅？" | 把使用人当受益人 |

**核心纪律**：
- 对接人 ≠ 决策人（最常见错位）
- 使用人 ≠ 受益人（业务负责人用了，老板 KPI 受益）
- 缺一不可：三角色中**任何一个未对位 = 部分真**，必须再挖指定信号（哪个角色未对位 → 追问哪个人）。

## 二、中国 title 映射（按行业给常见映射）

### 通用企业（民营/股份制）

| 角色 | 常见 title | 备注 |
|---|---|---|
| 决策人 | 总经理 / 创始人 / 一把手 / CEO / 董事长 / 采购委员会 / CFO | 拍板 + 批预算 + 签合同 |
| 使用人 | 业务负责人 / 信息主管 / IT 总监 / CIO / 部门经理 / 具体执行岗 | 日常使用，反馈问题 |
| 受益人 | 老板 / 业务线总监 / 合规负责人 | 用好了 KPI/合规/免责 |

### 国企 / 央企

| 角色 | 常见 title | 备注 |
|---|---|---|
| 决策人 | 分管副总 / 总经理 / 董事长 / 党政联席会 / 招标委员会 | 国企**几乎不一人拍板**，常见委员会/分管副总 + 招标流程 |
| 使用人 | 部门主任 / 业务科室 / 信息中心主任 | 日常用，反馈给上级 |
| 受益人 | 分管副总（KPI 挂钩）/ 上级单位 | 出问题追责到分管副总 |

### 互联网 / 科技

| 角色 | 常见 title | 备注 |
|---|---|---|
| 决策人 | VP / CTO / CEO / 产品负责人 / 增长负责人 | 决策链路短，VP/总监级可直接拍板 |
| 使用人 | 产品经理 / 运营 / 工程师 / 数据分析师 | 日常高频使用 |
| 受益人 | 业务线 GM / 增长负责人 / CEO | 用好了业务增长受益 |

### 制造业 / 传统行业

| 角色 | 常见 title | 备注 |
|---|---|---|
| 决策人 | 厂长 / 总经理 / 集团采购中心 / 财务总监 | 制造业采购链路长，常见集团集采 |
| 使用人 | 车间主任 / IT / 工艺工程师 / 班组长 | 现场使用，反馈链路长 |
| 受益人 | 厂长 / 集团总部 / 业务部门总监 | 用好了产能/质量/合规受益 |

## 三、识别方法（怎么挖出三角色）

### 数据源（中国公开源）

- **企查查 / 天眼查**：查公司组织架构、高管 title、股权链、子公司。
- **Boss直聘 / 脉脉**：查关键人 title、在招岗位（=扩张/招人=有需求）。
- **招标平台**：查中标公告、采购公告 → 看采购委员会成员。
- **客户公众号 / 官网动态**：高管演讲、活动报道、合影站位（看谁站 C 位）。
- **知乎 / 微信搜一搜**：客户对接人在行业群/文章的发言痕迹。

### 提问话术（轻量背调 + 追问）

| 场景 | 提问 | 期望答案 |
|---|---|---|
| 初次接触 | "您这边是 XX 部门对吧？后续拍板是您这边还是另有领导？" | title + 决策路径 |
| 收到客户需求 | "您觉得这事最终需要谁拍板？合同怎么走？" | 决策人 + 流程 |
| 业务对接中 | "您这边用得最多，业务上谁看结果？" | 使用人 + 受益人 |
| 卡在预算 | "这种项目预算走哪条线？谁批？" | 决策人 + 财务链路 |

**纪律**：第一次接触就要问**拍板路径**，不要等客户主动说；客户不说 = 没问到 = 部分真。

## 四、对位缺口处理（如何补齐未对位角色）

| 缺口 | 补法 | 优先级 |
|---|---|---|
| 决策人未对位 | 查公开源找高管 title / 问对接人"拍板路径" / 申请参加决策人会议 | **高**（缺 = 不能推下游） |
| 使用人未对位 | 追问"日常谁用" / 申请试用 / 陪同部署 | 中 |
| 受益人未对位 | 追问"用好了谁拿到好处" / 算账时把受益人拉进来 | 中（影响下游 ROI 论证） |

**对位口诀**：
```
决策人 = 谁签合同 + 谁批预算
使用人 = 谁每天用 + 谁提需求
受益人 = 谁 KPI 挂钩 + 谁背锅
三角色齐全 = 真痛候选
缺任一 = 部分真（必须再挖指定信号）
```

---

## 五、常见反例（不要踩）

❌ **对接人=决策人**：销售以为客户经理就是老板，结果拍板的是集团采购中心 → 错位
❌ **使用人=受益人**：业务负责人用了产品但 KPI 不挂钩，他没动力
❌ **决策人不出现**：客户经理很热情但从不安排老板见面 → 大概率假痛或不急
❌ **三角色都在但对位关系错**：以为客户经理批预算，实际需走采购委员会 → 错位
❌ **只查对接人不查三角**：销售只跟对接人聊，没挖过决策人/使用人/受益人 → 错位高发

---

## 六、与下游 skill 的接力

- **决策人未对位** → 部分真 → 本 skill 再挖指定信号
- **三角色齐全 + 真痛信号 ≥3** → 真痛 → 进入 ROI 论证（算账时受益人必须参与）
- **三角色齐全 + 但决策人拒绝接触** → 假痛 → 淘汰
- **三角色齐全 + 但使用人无 KPI 挂钩** → 部分真 → 再挖使用人动力
