# 6 类卡点信号清单 + 中国专属反例

> 配合 SKILL.md「二、归因」使用。归因必须给证据，禁止"感觉卡在关键人"。

## 1. 关键人缺口（People Gap）

**信号**：
- single-threaded：只跟 1 人（不管这人态度多好）
- EB（经济买家/控预算能说 yes 的人）未见或只见 1 次
- 决策链五角色（发起者/评估者/决策者/采购方/使用方）缺 ≥1 角色
- champion 不愿向上推（被催多次未引荐决策者）
- 客户联系人离职/调岗未补上

**严重度**：
- Red：EB 完全未见 + single-threaded 到非 EB
- Yellow：EB 见过 1 次但无后续 / 决策链缺 1 角色但有替代接触
- Green：EB 有定期接触 + 五角色各有接触点

**推进方向**：多线程（让 champion/技术评价人引荐 EB）+ 画关系图 + 老板对老板站台。

**中国专属反例**：
- 国央企：业务部门支持但不动用上层关系推招标 = 业务接口人不是真 champion，只是发起者；要找"内部说客"（常是技术评价人或上级分管秘书）
- 民企：CEO 忙融资/业务，champion（运营总监）不愿"打扰"CEO = champion 权力不足，要本机老板站台做 CEO 对 CEO 对话
- 外企：本地团队认可但要全球审批 = 本地 EB 不是真签字权人，要识别区域/全球审批链

## 2. 流程卡点（Process Gap）

**信号**：
- 招标没排期 / 招标公告未发
- 合同审卡住（法务/财务/业务会签缺一）
- 付款条件未谈（预付款/进度款/尾款/质保金比例）
- 采购方式未核实（销售推断"应该走招标"但无书面确认）
- 安全审查/等保测评未启动

**严重度**：
- Red：采购方式未核实（可能根本不走招标，白等）/ 合同审卡 4 周+
- Yellow：招标排期未定但有窗口 / 付款条件未谈但签约前可谈
- Green：流程在推进中，各步有 owner

**推进方向**：核实采购方式 → 并行启动（法务备合同模板 + 售前备技术方案 + 盯招标公告）→ 付款条件前置谈。

**中国专属反例**：
- 招投标周期内临时更换友商（资格预审后换投标主体）= 客户内部博弈，要识别谁在推友商
- 付款条件恶化（签约后客户要求延长付款周期）= 签约前未锁定付款条件
- 国央企合同审多部门会签（法务+财务+业务+审计），任一部门卡住 = 流程卡点
- 单一来源采购 vs 公开招标路径完全不同，识别错 = 路径全错

## 3. 信息缺口（Info Gap）

**信号**：
- 决策标准不清（客户说"看方案"但无评价维度）
- 痛点没量化（"效率低"但无金额/工时/收入损失数据）
- 预算未书面确认（口头"有预算"但无金额/PO 流程）
- 竞争不明（"应该没友商"但无核实）
- 时间线不明（"越快越好"但无硬截止）

**严重度**：
- Red：预算未确认 + 痛点未量化（无内部立项依据）
- Yellow：信息部分确认，单源/推断
- Green：多源书面确认

**推进方向**：补 discovery（量化痛点/确认预算/挖竞争/锁时间线）。

## 4. 竞争卡点（Competition Gap）

**信号**：
- 友商已落子（客户已在接触）
- 决策标准被友商塑造（评价维度明显对齐友商强项）
- 友商强项踩中客户公开标准
- 客户回避谈竞争

**严重度**：
- Red：决策标准已对齐友商强项 + 友商有内部支持者
- Yellow：友商在接触但标准未定型
- Green：无友商或友商已出局

**推进方向**：竞争重塑（Winning/Battling/Losing 三角）+ landmine（设问题暴露友商短板）+ 多线程挤掉友商内部支持者。

> 友商格局判断用 Winning/Battling/Losing 三角。

## 5. 资源卡点（Resource Gap）

**信号**：
- 售前/解决方案/技术 demo 缺位
- 法务/财务未介入备合同/报价
- 老板未站台（大单缺高层对齐）
- 本机无该行业案例/资质（国央企常要案例资质）

**严重度**：
- Red：大单（≥100 万）无老板站台 + 无案例资质
- Yellow：资源部分到位
- Green：资源齐备

**推进方向**：内部协调（独立动作行）—— 调售前/法务/财务/老板站台/找案例。

## 6. 时机卡点（Timing Gap）

**信号**：
- 无 compelling event
- 预算周期不对（Q4 编制期推执行单 = 推不动，要等 Q1 执行）
- 客户内部优先级变化（融资/业务调整/人事变动）
- 季节性窗口（双 11/年底/财年截止）未锁定

**严重度**：
- Red：无 compelling event + 预算周期错位
- Yellow：compelling event 弱（口头"越快越好"未量化）
- Green：有硬截止（招标截止日/合同到期/监管时限）

**推进方向**：造紧迫（把弱事件量化成硬截止）or 等窗口（Q4 编制期转铺垫，Q1 执行期推成交）。

**中国专属**：
- 预算年度：Q4（10-12 月）编制下年预算，Q1（1-3 月）执行，Q2-Q3 调整。Q4 推执行单 = 推不动，要转"进下年预算"。
- 招标截止日是硬 compelling event，要倒推动作时间线。
- 上级督办/政策窗口（如等保 2.0 合规期限）是国央企硬 compelling event。
