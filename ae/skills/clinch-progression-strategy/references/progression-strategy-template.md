# progression-strategy.md 交付模板

> 每次skill 调用落盘此模板。字段定义在表后。

```markdown
# 商机推进策略：<客户名> · <产品>

## 一、商机画像（3-5 行）
- 客户：<名称>（类型：国央企/民企/外企）

- 金额区间：<金额>

- 降级触发条件：<何条件>→进入临门逼单节奏或重评投入
- 风险点：<3-5 条>，每条 owner + 缓解动作
```

## 字段定义

- **置信度**：高（多源书面）/ 中（单源书面）/ 低（口头）/ 推断（销售猜测）
- **五角色**：发起者（提需求的人）/ 评估者（技术评价人）/ 决策者（EB/签字权人）/ 采购方（招标办/采购部）/ 使用方（实际用产品的人）
- **compelling event 来源**：合同到期 / 监管 / 财年 / 招标截止 / 上级督办 / 政策窗口 / 预算年度 / 业务窗口（双 11 等）
- **严重度 R/Y/G**：Red = 阻断推进必须先解 / Yellow = 拖慢要排解 / Green = 已解或低风险
- **验收标准**：可客观判断"这关过了"的条件（如"副总见面会排上"而非"推进关系"）
- **内部协调**：本机要调的人（老板站台/法务备标/售前 demo/财务报价），独立成行不埋客户动作里
