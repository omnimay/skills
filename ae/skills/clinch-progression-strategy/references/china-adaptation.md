# 中国适配：决策链 + 招投标 + 预算周期 + 付款条件

> 配合 SKILL.md 采集/归因/路径使用。海外做法 → 中国判断见下各节。

## 一、决策链五角色

中国 B2B 决策链长、多关键人、关系驱动。五个角色都要识别，缺谁就是卡点。

| 角色 | 职责 | 中国特点 |
|---|---|---|
| **发起者** | 提需求的人 | 常是业务部门中层，有痛点但不掌预算 |
| **评估者** | 技术评价人 | 技术认可但不动用关系推；国央企常是信息中心副主任 |
| **决策者** | EB/签字权人 | 国央企：分管副总/部门一把手推立项，总经理/董事长大额签字；民企：CEO；外企：本地 EB + 全球审批 |
| **采购方** | 招标办/采购部 | 国央企独有，民企可能行政兼，外企常全球采购 |
| **使用方** | 实际用产品的人 | 常被忽略，但影响采纳和续约 |

**关键区分**：
- **发起者 ≠ champion**：发起者提需求但不愿向上推 = 不是真 champion。真 champion = 有权力/有 access/有个人动机（职业利益挂钩）。
- **业务 EB ≠ 签字权人**：业务 EB 推动立项和预算，但大额签字权可能在上层（总经理/董事长/党委会）。两者要分别识别和接触。
- **champion 常是多人网**：中国关系驱动，单 champion 罕见，常是"业务接口人 + 技术评价人 + 内部说客"组合。画关系图不是列单人。

**关系图字段**：姓名 / 职务 / 角色 / 态度（支持/中立/反对/不明）/ 关系强度（强/发展中/弱/未知）/ access（能见到决策者吗）/ 个人动机（这单成了对他/她有什么好处）。

## 二、招投标全流程（国央企核心关卡）

| 阶段 | 做什么 | 销售动作 | 常见卡点 |
|---|---|---|---|
| 标前策划 | 客户内部立项 + 确定采购方式 | 介入需求 shaping + 识别采购方式 | 采购方式未核实 |
| 资格预审 | 发资格预审公告 | 盯公告 + 备资质 | 资质缺/招标办未排期 |
| 投标 | 发招标公告 → 递交投标文件 | 备标书（商务+技术+报价） | 标书未备齐/法务未介入 |
| 评标 | 评标委员会评审 | 评标前多线程接触评委（合规范围内） | 评标未排/友商竞争 |
| 中标公示 | 中标公告发布 | 确认中标 | 友商中标/流标 |
| 合同审 | 中标后合同会签 | 法务备合同模板 + 推会签 | 多部门会签卡住 |

**采购方式识别**（决定路径）：
- 公开招标：公告发布，多家投标，国央企大额常用
- 邀请招标：定向邀请，少数投标
- 单一来源采购：定向一家，无竞争（特殊情形）
- 直采：民企/外企常用，无招标
- 框架协议采购：一次签框架，后续按需下单

**识别错 = 路径全错**：销售推断"走公开招标"但实际单一来源 = 白等公告。必须向采购方/招标办书面核实。

## 三、预算周期

中国预算年度驱动采购时机，错位 = 推不动。

| 季度 | 预算状态 | 销售策略 |
|---|---|---|
| Q4（10-12 月）| 编制下年预算 | 推"进下年预算"（铺垫），不推执行单 |
| Q1（1-3 月）| 预算执行 | 推成交黄金期 |
| Q2（4-6 月）| 预算执行 + 调整 | 推成交 + 抓调整窗口 |
| Q3（7-9 月）| 预算调整 + 年底冲刺规划 | 推剩余预算 + 为 Q4 编制铺垫 |

**错位信号**：Q4 推执行单 = 客户说"预算用完了"——转"进下年预算"不是硬推。Q1 客户说"预算还没批"——等编制完成，不催。

## 四、付款条件（独立关卡）

签约 ≠ 收钱。付款条件是独立关卡，签约前必须谈妥。

| 付款阶段 | 中国常见比例 | 卡点 |
|---|---|---|
| 预付款 | 10-30% | 签约后拖延付 = 启动卡 |
| 进度款 | 30-50% | 验收节点争议 = 拖付 |
| 尾款 | 10-20% | 验收后拖延 = 回款卡 |
| 质保金 | 5-10% | 国央企常要，延付 1-2 年 |

**签约前必谈**：付款比例 + 付款节点（触发条件）+ 质保金是否要 + 质保期。延后谈 = 签约后回款卡，影响现金流。

## 五、数据源（中国化）

- **企查查 / 天眼查 / IT 桔子**：公司画像、股权、高管、关联方
- **中国政府采购网 / 千里马招标网**：招标公告、采购方式、中标公示
- **微信朋友圈 / 行业群**：客户内部动态、人事变动、友商落子
- **Boss 直聘**：客户招人需求反推业务方向和预算
- **禁用**：LinkedIn / Apollo / G2 / Capterra（中国销售没这些数据或数据不准）
