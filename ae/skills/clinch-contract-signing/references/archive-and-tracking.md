# archive-and-tracking.md

> 归档体系 + OCR + CRM 关联 + 到期预警

## 1. 归档总目标

合同签完后，**24 小时内入档**，形成"**找得到 / 查得快 / 风险可见 / 留痕完整**"的检索基础设施。

## 2. 归档流程

```
合同已签 + 审计日志
    ↓
上传 PDF + DOCX（双份）到归档系统
    ↓
OCR 提取文字（中文 + 英文双语）
    ↓
自动打标签（客户名 / 合同号 / 金额 / 起止 / 风险评级 / 归档人）
    ↓
关联 CRM 客户主记录（双向链接）
    ↓
权限分层（销售看自己 / 法务看全部 / CSM 看分配的）
    ↓
30/60/90 天到期预警配置
    ↓
触发交接（webhook → CSM 通知）
```

## 3. 入库必填字段

### 3.1 必填字段清单（10 项）

| # | 字段 | 来源 | 必填 |
|---|---|---|---|
| 1 | **客户合同号**（甲方提供） | 合同首页 | ✅ |
| 2 | **内部审批单号** | 内部 OA / 审批系统 | ✅ |
| 3 | **签约日期** | 合同签字日 | ✅ |
| 4 | **合同起止日期** | 合同条款 | ✅ |
| 5 | **合同金额** | 合同条款 | ✅ |
| 6 | **付款节奏** | 合同条款 | ✅ |
| 7 | **风险评级** | 法务尽调 | ✅ |
| 8 | **归档人** | 销售 / 印章管理员 | ✅ |
| 9 | **归档日期** | 入库动作 | ✅ |
| 10 | **客户对接人 + 联系方式** | 客户档案 | ✅ |

**缺一项不入库**——避免后续找不到关键信息。

### 3.2 可选字段（提升检索效率）

- 行业（金融 / 医疗 / 政府 / 教育 / 制造）
- 客户类型（央企 / 国企 / 民营 / 外资 / 上市公司）
- 业务线（电商 / 跨境 / 本地）
- SLA 等级（99.9% / 99.95% / 99.99%）
- 是否有 NDA 附件
- 是否有数据跨境

## 4. 标签体系

### 4.1 三维标签

**维度 1：Correspondent（通讯方）**

- 客户公司全称
- 客户对接人
- 客户决策链（业务 / 财务 / IT）

**维度 2：Document Type（文档类型）**

- 销售合同
- 服务订单
- NDA / 保密协议
- 续约协议
- 补充协议
- 终止协议

**维度 3：自定义字段**

- 风险评级（低 / 中 / 高）
- 归档人
- 归档日期
- 客户行业
- 合同金额（用于金额区间检索）

### 4.2 标签使用示例

```
合同：ACME 公司 2026 年度 SaaS 订阅合同

标签：
- correspondent: ACME（中国）有限公司
- type: 销售合同
- custom:
  - 风险评级：中
  - 归档人：张三
  - 归档日期：2026-08-25
  - 行业：金融
  - 金额区间：100-500 万
  - SLA：99.95%
```

## 5. OCR 双层归档

### 5.1 双层归档的意义

- **原版 PDF**：法律效力（保留签字 / 盖章）
- **OCR 文本版**：检索便利（全文搜索 + 提取关键字段）

### 5.2 OCR 引擎选型

| 引擎 | 准确率 | 中文支持 | 商用 |
|---|---|---|---|
| **Tesseract** | 中 | ✅（简体 + 繁体） | 免费开源 |
| **Azure OCR** | 高 | ✅ | 商业 |
| **Google OCR** | 高 | ✅ | 商业 |
| **百度 OCR** | 高 | ✅（中文最优） | 商业 |
| **腾讯云 OCR** | 高 | ✅ | 商业 |

**推荐**：Tesseract（开源）+ 百度 OCR（中文补充）双引擎验证。

### 5.3 OCR 注意事项

- 扫描 PDF 建议 ≥ 300 DPI
- 歪斜矫正（自动或手动）
- 双语对照（中文 OCR + 英文 OCR 各一遍）
- OCR 校对：关键字段（金额 / 日期 / 当事人）由人工校对一次

## 6. CRM 关联

### 6.1 双向关联

```
CRM 客户主记录
    ↓ （1对多）
合同记录（历史所有合同）

合同记录
    ↓ （多对1）
CRM 客户主记录
```

### 6.2 CRM 客户主记录必带

- 客户公司全称
- 统一社会信用代码
- 客户行业
- 客户规模
- 决策链 + 联系人
- 历史合同清单（按时间倒序）

### 6.3 自动同步

- 合同入档 → 自动写入 CRM 客户主记录"历史合同"字段
- 合同状态变更（履约中 / 已到期 / 已续约）→ 自动同步 CRM
- 续约预警 → 自动写入 CRM 客户主记录"待办"字段

## 7. 权限分层

### 7.1 三级权限

| 角色 | 可见范围 | 备注 |
|---|---|---|
| **销售** | 自己负责的客户的所有合同 | 默认权限 |
| **法务** | 所有合同 | 含尽调报告 + 谈判历史 |
| **CSM** | 分配给自己的客户的合同 | 按交接 SOP 分配 |
| **销售经理 SM** | 团队所有合同 | 含风险评级 |
| **财务** | 所有合同的付款条款 | 财务专用视图 |
| **印章管理员** | 所有合同（用于盖章归档） | 仅归档权限 |

### 7.2 权限配置

- **默认收紧**：销售只能看自己 + 法务看全部 + CSM 按分配
- **特殊授权**：大客户 / 战略合同可临时扩大可见范围
- **审计日志**：谁什么时候下载 / 转发 / 修改 → 必留痕（应对客户法务问"谁看过我的合同"）

### 7.3 风险点

- 默认权限过宽（全员可见）→ 内部泄密风险
- 权限未及时调整（销售离职 / 转岗）→ 历史合同泄露风险
- 客户对接人变更 → CSM 可见范围未调整 → 履约风险

## 8. 到期预警（30/60/90 天）

### 8.1 三档预警

| 时点 | 触发动作 | 接收人 | 内容 |
|---|---|---|---|
| **T+90 天** | 续约预警 | CSM + 销售 | "合同将于 90 天后到期，建议启动续约洽谈" |
| **T+60 天** | 续约预警（升级） | CSM + 销售 + SM | "合同将于 60 天后到期，需提交续约方案" |
| **T+30 天** | 续约预警（紧急） | CSM + 销售 + SM + 销售总监 | "合同将于 30 天后到期，紧急续约或客户挽留" |
| **T+0 天** | 合同到期通知 | CSM + 销售 + SM + 销售总监 | "合同今日到期，请确认续约 / 终止决策" |

### 8.2 预警渠道

- 邮件（必发）
- CRM 待办（必推）
- 钉钉 / 飞书 / 企业微信（推荐）

### 8.3 预警触发逻辑

```
合同到期日 - 当前日 = X 天
    ↓
触发对应预警
    ↓
升级：X ≤ 60 天未提交续约方案 → SM 介入
升级：X ≤ 30 天未确认续约 → 销售总监介入
升级：X = 0 天未决策 → 转死单挽回流程
```

## 9. 检索能力

### 9.1 全文检索

支持自然语言检索：

- "ACME 公司 2026 年度合同"
- "包含 SLA 99.95% 的合同"
- "客户为金融行业的合同"
- "金额 100 万以上的合同"

### 9.2 结构化检索

按字段精确检索：

- 客户合同号
- 内部审批单号
- 签约日期范围
- 金额范围
- 风险评级

### 9.3 关联检索

- 客户主记录 → 该客户所有合同
- 合同 → 该合同相关谈判记录
- 合同 → 该合同对应 CRM 商机
- 合同 → 该合同对应 CSM

## 10. 审计与合规

### 10.1 审计日志（必留）

每个动作必留痕：

- 谁什么时候下载
- 谁什么时候转发
- 谁什么时候修改
- 谁什么时候删除

### 10.2 合规要求

- **《会计档案管理办法》**：合同档案保留 ≥ 6 年（一般企业）/ ≥ 10 年（建筑 / 房地产 / 金融）
- **《民法典》第 188 条**：诉讼时效 3 年，但合同档案保留 ≥ 6 年以应对追溯
- **PIPL / 数据安全法**：含个人信息合同归档后，存储 + 访问需符合数据安全要求

### 10.3 反例与归因

| # | 反例 | 错因 | 正确做法 |
|---|---|---|---|
| 1 | 合同散落销售个人电脑 | 缺乏归档体系 | 必走归档系统 |
| 2 | 入库字段不全 | 缺乏标准化 | 10 项必填字段强制 |
| 3 | 全文检索不到 | 只有 PDF 无 OCR | 双层归档（PDF + OCR） |
| 4 | 续约预警遗漏 | 缺乏自动触发 | 30/60/90 天自动推 |
| 5 | 权限过宽全员可见 | 默认配置不当 | 销售 / 法务 / CSM 三级权限 |
| 6 | 客户问"谁看过我的合同"答不上 | 缺乏审计日志 | 每个动作必留痕 |
| 7 | 合同到期无人管 | 缺乏自动预警 | 30/60/90 + T+0 四档 |

## 11. 推荐工具组合

### 11.1 开源自建（推荐中小团队）

- **paperless-ngx**（44,565 stars）—— OCR + 标签 + 检索
- **Documenso**（14,718 stars）—— 电子签 + 归档集成
- **Nextcloud** —— 私有部署 + 文件管理
- **CRM**：自研 / 开源（SuiteCRM）

### 11.2 商业 SaaS（推荐中大企业）

- **电子签**：e-签宝 / 法大大 / 上上签 / DocuSign
- **归档**：合同管理系统（CLM）—— 契约锁 / 秀合同 / Ironclad / Icertis
- **OCR + 检索**：百度 OCR + 内部搜索
- **CRM**：Salesforce / HubSpot / 销售易 / 纷享销客

### 11.3 混合方案（推荐）

- **电子签**：持牌平台（e-签宝）+ 自托管 OCR（paperless-ngx）
- **归档**：内部 CLM（契约锁）+ paperless-ngx 双层
- **CRM**：与归档系统 API 集成
- **到期预警**：归档系统 webhook → CRM 待办 + 邮件 + IM
