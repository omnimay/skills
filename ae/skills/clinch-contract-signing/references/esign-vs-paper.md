# esign-vs-paper.md

> 5 类签约动作对比 + 选型决策树

## 1. 5 类签约动作详解

### 1.1 电子签

**定义**：通过电子签名平台生成 PDF + 数字签名 + 时间戳，双方在线完成签字。

**适用**：

- 远程签约（客户 / 销售不在同一城市）
- 标准 SaaS 合同（条款成熟）
- 金额 < 50 万（小额高频）
- 时间紧（24-48 小时签完）

**工具**：

- **国内持牌**：e-签宝 / 法大大 / 上上签（CA 认证 + 可信时间戳，合规）
- **国际开源**：Documenso（自托管，需自行对接 CA）
- **海外合规**：DocuSign / Adobe Sign（eIDAS / ESIGN Act 合规）

**流程**：

1. 上传 PDF 到平台
2. 设置签字方（姓名 / 邮箱 / 签字字段位置）
3. 设置签字顺序（Sequential / Parallel）
4. 发起 → 邮件通知各方
5. 各方在线签字 → 平台生成带签名的 PDF
6. 审计日志留档

**优势**：

- 快（24-48 小时）
- 便宜（单份几元到几十元）
- 可追溯（审计日志完整）

**劣势**：

- 部分场景效力受限（中国电子签名法要求第三方 CA 认证）
- 部分客户不接受（如国企 / 事业单位的部分场景）
- 涉外需双轨

**风险**：

- 平台无 CA 认证 → 效力瑕疵（《电子签名法》第 13-14 条）
- 平台倒闭 → 审计日志无法调取
- 客户事后拒认 → 平台需出具"第三方电子证据存证证明"

### 1.2 纸质签

**定义**：传统纸质合同，打印 + 双方盖章签字 + 邮寄。

**适用**：

- 政企 / 事业单位（部分场景必须纸质）
- 大金额战略合同（≥ 500 万）
- 客户主动要求（如金融机构 / 上市公司）
- 涉外合同（纸质英文版作为正本）

**流程**：

1. 起草打印（A4 双面 / 骑缝章）
2. 我方先行盖章（销售经理 + 法人 / 授权代表签字）
3. 邮寄客户（顺丰 / EMS，可保价）
4. 客户盖章签字
5. 客户回寄（部分场景双方各执一份）
6. 我方接收 + 归档

**优势**：

- 效力最强（实体章 + 法定代表人签字 = 无可争议）
- 适用于所有场景
- 客户接受度高

**劣势**：

- 慢（邮寄 + 客户盖章周期，5-10 个工作日）
- 贵（打印 + 邮寄 + 仓储 + OCR 后处理）
- 邮寄丢失 / 损毁风险

**风险**：

- 邮寄丢失 → 重新打印 + 盖章（损失时间 + 邮费）
- 客户盖章后篡改 → 需骑缝章 + 双份各执一份
- 仓储不规范 → 6 个月后找不到合同

### 1.3 双轨（电子签 + 纸质签）

**定义**：同时使用电子签 + 纸质签，电子签版本作为日常执行，纸质版本作为正式正本。

**适用**：

- 涉外合同（中英双语，电子签中文 + 纸质英文盖章）
- 金融 / 医疗 / 政府（部分场景必须纸质，电子签作为效率补充）
- 跨国集团（中国子公司 + 母公司双重签字）

**流程**：

1. 中文版电子签（双方在线签字）
2. 英文版纸质签（双方邮寄盖章）
3. 中文电子版 + 英文纸质版并存
4. 争议时以纸质英文版为准（涉外场景）

**优势**：

- 兼顾效率 + 合规
- 涉外通用模式

**劣势**：

- 流程复杂（双重流程）
- 成本高（电子签 + 邮寄双份）
- 版本一致性管理难

**风险**：

- 中英版本条款不一致 → 履约争议
- 纸质版滞后 → 客户已按电子版履约，但纸质版条款不同

### 1.4 法定代表人签字

**定义**：合同由公司法定代表人本人签字 + 公司盖章。

**适用**：

- 大客户 / 战略合同（≥ 500 万）
- 客户主动要求"法人签字"
- 上市公司 / 国企 / 政府

**优势**：

- 效力最强（无可争议的代表权）
- 客户信任度高

**劣势**：

- 法人时间协调难（1-2 周预约）
- 流程慢

**风险**：

- 法人变更 → 需查最新营业执照
- 法人签字样本比对 → 需客户提供签字样本

### 1.5 授权代表签字

**定义**：合同由非法定代表人签字，需提供**授权委托书**。

**适用**：

- 标准合同 / 时间紧
- 法定代表人无法到场
- 客户主动指定签字代表

**授权委托书必填项**：

- 委托人（公司全称 + 法定代表人姓名）
- 受托人（姓名 + 身份证号 + 联系方式）
- 授权范围（标的 / 金额 / 期限）
- 授权期限（如 30 天）
- 法定代表人签字 + 公司盖章

**优势**：

- 灵活（可多人被授权）
- 效率高

**劣势**：

- 越权风险（受托人超出授权范围签字）
- 真实性审查难（授权委托书造假）

**风险**：

- 越权签字 → 表见代理（《民法典》第 172 条）——若客户事后追认，合同仍生效；若不追认，我方"善意相对人"举证困难
- 授权委托书缺失 → 效力瑕疵

## 2. 选型决策树

```
签约启动
    ↓
金额 ≥ 50 万？
    ├── 是 → 法定代表人 / 授权代表 + 实体章 + 纸质签
    │         ↓
    │       涉外？
    │       ├── 是 → 双轨（电子签中文 + 纸质英文）
    │       └── 否 → 纯纸质签
    │
    └── 否（< 50 万）
          ↓
        客户类型？
        ├── 政企 / 国企 / 金融 → 纸质签
        ├── 普通企业 → 电子签（持牌平台）
        └── 涉外 → 双轨
              ↓
            法定代表人能否到场？
            ├── 是 → 法定代表人 + 实体章
            └── 否 → 授权代表 + 授权委托书 + 实体章
```

## 3. 选型矩阵

| 场景 | 金额 | 客户类型 | 推荐签约 | 理由 |
|---|---|---|---|---|
| 标准 SaaS | < 50 万 | 中小企业 | 电子签（持牌） | 快 / 便宜 |
| 标准 SaaS | < 50 万 | 政企 / 国企 | 纸质签 | 部分场景必须 |
| 大金额战略 | ≥ 50 万 | 普通企业 | 法定代表人 + 实体章 | 效力强 |
| 大金额战略 | ≥ 500 万 | 上市公司 | 法定代表人 + 双份盖章 | 内部审批要求 |
| 涉外 | 任意 | 跨国集团 | 双轨（中英双语） | 涉外通用 |
| 紧急 / 时间紧 | 任意 | 普通企业 | 电子签 + 授权代表 | 24-48 小时 |
| 复杂条款 | ≥ 100 万 | 任意 | 法定代表人 + 实体章 + 双份 | 争议风险低 |

## 4. 平台推荐（中国市场）

### 4.1 国内持牌电子签平台

| 平台 | CA 认证 | 可信时间戳 | 适用 |
|---|---|---|---|
| **e-签宝** | ✅ | ✅ | 政企 / 金融 |
| **法大大** | ✅ | ✅ | 标准 SaaS / 中小企业 |
| **上上签** | ✅ | ✅ | 跨国 / 供应链 |
| **契约锁** | ✅ | ✅ | 大型企业 / 集团 |

### 4.2 开源自建

- **Documenso**（14,718 stars）—— 自托管电子签，需对接中国 CA（CFCA / 国密）
- **适用**：对数据敏感 / 不想依赖第三方 / 已有 IT 团队

### 4.3 海外合规

- **DocuSign**（国际版）—— eIDAS / ESIGN Act 合规，跨境通用
- **Adobe Sign**—— 与 Adobe 生态整合

## 5. 风险清单

| # | 风险 | 触发条件 | 缓解措施 |
|---|---|---|---|
| 1 | 电子签无 CA 认证 | 选用未持牌平台 | 必查：CA 认证 + 可信时间戳 |
| 2 | 授权代表越权 | 受托人超出授权范围 | 索要授权委托书原件 + 签字样本 |
| 3 | 邮寄丢失 | 顺丰保价不够 / 客户拒收 | 双份各执一份 + 骑缝章 |
| 4 | 中英版本条款不一 | 双轨时未做对比 | 法务双语审核 + 中英版本同源 |
| 5 | 平台倒闭 | 小众平台 | 选头部平台 + 审计日志本地备份 |
| 6 | 客户事后拒认 | 电子签纠纷 | 平台出具第三方电子证据存证证明 |
