# cn-contract-clauses.md

> 6 类合同条款详解 + 中国法律依据

## 1. 标准条款（基础层）

适用所有合同。

### 1.1 当事人信息

**必填字段**：

- 甲方乙方**全称**（与营业执照一致，不可简称）
- **统一社会信用代码**（营业执照号）
- **法定代表人**姓名
- **住所地址**（与营业执照一致）
- **联系方式**（电话 / 邮箱）

**风险点**：

- 简称 / 旧名 / 关联公司名 → 主体不适格
- 营业执照号错位 → 合同无效

**法律依据**：《民法典》第 502 条（合同生效要件）

### 1.2 标的

**必填字段**：

- 商品 / 服务 / 软件 / 解决方案的**全称 + 规格 + 数量 + 质量**
- 若含技术参数：附件列明（避免主合同冗长）

**风险点**：

- 标的描述模糊 → 履约争议
- 标的违法（如违禁品）→ 合同无效（《民法典》第 153 条）

### 1.3 金额

**必填字段**：

- **含税总价** + 税率
- **币种**（CNY / USD / EUR）
- **大小写一致**（防止篡改）

**风险点**：

- 金额大小写不一致 → 以大写为准（《合同法》惯例，民法典第 470 条未明文但实务遵循）
- 未注明含税 / 不含税 → 履约争议

### 1.4 起止日期

**必填字段**：

- **生效日**（签字日 / 约定日）
- **终止日**（含当日 / 不含当日）
- **续约条款**（自动续约 / 需双方书面确认）

**风险点**：

- 终止日早于生效日 → 无效
- 续约条款缺失 → 合同到期默认终止

### 1.5 签署栏

**必填字段**：

- 甲方乙方**签字**（法定代表人或授权代表）
- **盖章**（公司公章 / 合同专用章）
- **签字日期**

**风险点**：

- 仅签字无盖章 → 法人主体效力瑕疵
- 仅盖章无签字 → 需授权委托书

## 2. 服务等级 SLA（适用于 SaaS / 服务交付类）

### 2.1 可用性指标

| 等级 | 可用性 | 月度停机上限 | 典型场景 |
|---|---|---|---|
| 标准 | 99.9% | 43.2 分钟 | 中小企业 SaaS |
| 高 | 99.95% | 21.6 分钟 | 金融 / 医疗 |
| 不停服 | 99.99% | 4.32 分钟 | 政企 / 关键基础设施 |

### 2.2 响应时间

| 优先级 | 响应时间 | 解决时间 |
|---|---|---|
| P0（业务中断） | 30 分钟 | 4 小时 |
| P1（功能受限） | 2 小时 | 24 小时 |
| P2（一般问题） | 24 小时 | 72 小时 |
| P3（咨询类） | 72 小时 | 1 周 |

### 2.3 补偿机制

- **服务费折扣**：月度服务费 × 不可用百分比 × 系数（如 2 倍）
- **SLA 信用额度**：单次故障上限 = 月度服务费 × X%
- **不可绕过**：客户不能"换折扣"换取更高的可用性

### 2.4 测量口径

- **统计周期**：月度 / 季度
- **排除窗口**：计划维护（提前 7 天通知）/ 客户侧原因 / 不可抗力
- **测量点**：服务商侧监测（独立第三方更佳）

### 2.5 风险点

- 可用性百分比承诺过满 → 履约不能
- 排除窗口过宽 → SLA 名存实亡
- 补偿机制模糊 → 争议

**法律依据**：《民法典》第 590 条（违约责任）+ 第 577 条（继续履行 / 补救措施）

## 3. 数据合规（适用于数据处理 / SaaS / 跨境）

### 3.1 合法性依据

依据《个人信息保护法》（PIPL）第 13 条：

- 用户**明示同意**（推荐，书面 + 可撤回）
- **合同必需**（履约必要）
- **法律义务**（法定职责）
- **公共利益**（应急 / 突发公共卫生）

### 3.2 数据存储与跨境

依据 PIPL 第 38-39 条：

- **境内存储**：境内收集 / 产生的数据**原则上境内存储**
- **跨境传输**前置条件之一：
  - 通过**国家网信办安全评估**（重要数据 / 大规模）
  - **个人信息保护认证**（专业机构认证）
  - **标准合同**（与境外接收方签 SCC）
  - 其他法律法规规定

**风险点**：

- 未做安全评估 → 跨境违规 → 责令整改 + 罚款（最高 5000 万 / 上一年营业额 5%）
- 标准合同未签 / 未备案 → 违规

### 3.3 数据主体权利

依据 PIPL 第 44-50 条，客户 / 用户享有：

- **知情权**：处理目的 / 方式 / 范围
- **决定权**：是否同意 / 撤回
- **查询权**：复制 / 携带
- **更正权**：错误数据
- **删除权**：处理目的实现 / 停止服务
- **解释说明权**：自动化决策

**合同必备条款**：服务商承诺配合甲方响应数据主体权利请求。

### 3.4 数据安全措施

依据《数据安全法》第 27 条：

- **加密**（传输 TLS 1.2+ / 存储 AES-256+）
- **脱敏**（展示 / 测试场景）
- **访问控制**（最小权限 + 审计日志）
- **应急预案**（数据泄露 24 小时内报告 + 72 小时内评估）
- **第三方处理者**：明确谁处理 / 谁承担责任

### 3.5 风险点

- 未签跨境 SCC → 违规
- 未承诺响应数据主体权利 → 履约不能
- 未约定数据泄露责任 → 出现泄露时争议

**法律依据**：《个人信息保护法》《数据安全法》《网络安全法》

## 4. 知识产权

### 4.1 现有 IP 归属

**典型约定**："各自独立开发的知识产权归各自所有。"

**合同必备条款**：

- 背景 IP 清单（附件）
- 背景 IP 许可范围（是否可商用 / 转让）
- 背景 IP 改进的归属

### 4.2 合作产生 IP

三种典型模式：

| 模式 | 适用 | 风险 |
|---|---|---|
| 归甲方 | 甲方付费定制 | 甲方 IP 池丰富 |
| 归乙方 | 标准化产品 | 乙方可复用降本 |
| 共同共有 | 联合开发 | 行使权利需双方一致 |

### 4.3 许可范围

**四要素**：

- **范围**：使用目的 / 业务场景
- **期限**：合同期内 / 永久
- **地域**：中国 / 全球
- **是否可转让** / 可分许可

### 4.4 侵权责任

**典型约定**：

- 乙方（产品方）负责：自有产品 / 服务侵犯第三方 IP 的应诉 + 赔偿
- 甲方负责：基于乙方产品的二次开发 / 客户化定制导致的侵权

**风险点**：

- 权属不清 → 后续维权不能
- 许可范围超限 → 违约

**法律依据**：《民法典》第 123 条（知识产权客体）+ 第 844-861 条（技术合同）

## 5. 付款条款

### 5.1 价格

**必填字段**：

- **含税总价** + 税率（6% / 9% / 13%）
- **币种**（跨境需注明汇率机制）
- **是否含运杂费 / 实施费 / 培训费**

### 5.2 付款节奏

**典型模式**：

| 模式 | 适用 | 风险 |
|---|---|---|
| 一次性 | 小金额 / 短期 | 客户集中支付压力大 |
| 分期（30/60/90） | 大金额 / 长期 | 中间节点争议 |
| 里程碑 | 项目交付类 | 里程碑定义不清 |
| 订阅 | SaaS | 续约 / 自动扣费争议 |

### 5.3 付款方式

- **银行转账**（对公账户必填）
- **票据**（汇票 / 本票 / 支票）
- **信用证**（跨境大金额）

### 5.4 发票

- **开票时间**：付款前 / 付款后 / 服务完成后
- **税率**：13%（一般纳税人销售货物）/ 6%（服务）/ 9%（建筑等）
- **开票主体**：与签约主体一致（不一致需代收代付协议）

### 5.5 逾期

- **违约金**：日万分之五（≈ 年化 18.25%）—— 司法实践认可
- **滞纳金**：额外罚息（如有）
- **停服条款**：逾期 X 天后停止服务（需在合同明确）

### 5.6 涨价机制

- **年度调价幅度上限**：CPI / 5%（避免任意涨价）
- **通知期**：涨价前 30 天书面通知
- **不接受涨价**：客户有权终止合同

### 5.7 风险点

- 逾期违约金过高（超 24% 年化）→ 法院可能调减
- 涨价幅度无上限 → 客户被动

**法律依据**：《民法典》第 580 条（金钱债务）+ 第 585 条（违约金调整）

## 6. 违约责任

### 6.1 根本违约

**定义**：合同目的无法实现（如延迟交付超过 X 天 / 质量严重不符）

**后果**：

- 单方解除合同（《民法典》第 563 条）
- 赔偿**全部损失**（直接 + 间接）
- 支付违约金

### 6.2 一般违约

**定义**：未影响合同目的实现（如单次响应超时 / 单次延迟）

**后果**：

- 补救期（如 5 个工作日）
- 违约金（如 30% 服务费）

### 6.3 赔偿上限

**典型约定**：

- **直接损失**：实际发生的费用
- **上限**：合同总额 X%（如 100% / 50% / 30%）
- **不含间接损失**：利润损失 / 商誉损失（除非特别约定）

### 6.4 不可抗力

**三要素**（依据《民法典》第 180 条）：

- **不能预见**
- **不能避免**
- **不能克服**

**典型**：自然灾害 / 疫情 / 政府行为 / 战争

**合同必备条款**：

- **通知期**：事件发生后 X 天内书面通知
- **证明**：官方 / 公证机构出具
- **后果**：部分 / 全部免责
- **持续超过 X 天**：任何一方可终止合同

### 6.5 争议解决

**两种选择**：

| 方式 | 适用 | 利弊 |
|---|---|---|
| 仲裁 | 商业合同首选 | 一裁终局 / 保密 / 国际可执行（纽约公约） |
| 诉讼 | 政企 / 强执行 | 可上诉 / 公开 / 强制执行更广 |

**仲裁机构**（中国）：

- 中国国际经济贸易仲裁委员会（CIETAC）—— 涉外首选
- 北京仲裁委员会
- 上海国际仲裁中心

**法律依据**：《仲裁法》第 16-20 条 + 《民法典》第 116-137 条

### 6.6 法律适用

- **中华人民共和国法律**（默认）
- 其他法域（如香港 / 纽约州）—— 涉外合同可约定

### 6.7 风险点

- 赔偿上限偏低（≤ 10% 合同总额）→ 客户可能拒签
- 管辖法院 / 仲裁机构不利 → 履约成本高
- 法律适用不约定 → 争议时不确定
