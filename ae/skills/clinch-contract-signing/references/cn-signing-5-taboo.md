# cn-signing-5-taboo.md

> 5 类中国签约禁忌详解 + 红线 + 案例

## 禁忌 1：阴阳合同（最严重）

### 1.1 定义

同一交易签两份合同，"阳合同"用于备案 / 报税，"阴合同"用于实际执行（金额 / 条款不同）。

### 1.2 典型案例

**案例 A**：某房地产开发商与购房人签"阳合同"房价 8000 元 / m²（备案），"阴合同" 12000 元 / m²（实际成交）。差额 4000 元 / m² 房款现金支付不入账。

**后果**：

- 行政：补缴契税 + 个人所得税 + 罚款 + 滞纳金
- 民事：若房价下跌，购房人拒按"阴合同"付款，主张以"阳合同"为准——开发商损失 4000 元 / m² 房款
- 刑事：构成逃税罪（《刑法》第 201 条），责任人 3-7 年有期徒刑

### 1.3 法律依据

- **《刑法》第 201 条**：纳税人采取欺骗、隐瞒手段进行虚假纳税申报或者不申报，逃避缴纳税款数额较大并占应纳税额 10% 以上的，处 3 年以下有期徒刑或者拘役，并处罚金；数额巨大并占应纳税额 30% 以上的，处 3-7 年有期徒刑，并处罚金
- **《民法典》第 146 条**：行为人与相对人以虚假的意思表示实施的民事法律行为无效
- **《税收征收管理法》第 63 条**：偷税的，由税务机关追缴其不缴或者少缴的税款、滞纳金，并处不缴或者少缴的税款 50% 以上 5 倍以下的罚款

### 1.4 红线

- **所有合同只能有一份最终执行版本**
- **备案版本与执行版本必须一致**（金额 / 标的 / 付款 / 期限）
- 销售为冲业绩"做差价"→ 立即举报 + 终止合作
- 客户主动要求"做差价"→ 拒绝 + 备案拒绝理由

## 禁忌 2：先签后审（致命）

### 2.1 定义

销售为冲业绩，不经法务 review 直接让客户签字。

### 2.2 典型案例

**案例 B**：某 SaaS 公司销售急于签约 Q4 业绩，未经法务 review 直接让客户在销售自拟的合同上签字。合同条款中约定"客户可在任意时间无理由解除合同且全额退款"，且"数据所有权归客户"。

**后果**：

- 客户履约 1 个月后全额退款 + 拿走所有数据
- 公司损失：合同金额 + 数据 IP + 服务成本
- 法务事后才发现：合同已签，无法补救

### 2.3 法律依据

- **《民法典》第 153 条**：违反法律、行政法规的强制性规定的民事法律行为无效
- **《民法典》第 502 条**：依法成立的合同，自成立时生效（但无效的合同自始无效）

### 2.4 红线

- **任何金额 / 任何客户，必须先过我方法务 review 再签**
- **金额阈值决定 review 层级**：
  - < 10 万：法务助理审
  - 10-100 万：法务总监审
  - 100-500 万：法务总监 + 销售副总审
  - ≥ 500 万：法务总监 + 销售副总 + 外部律师审
- **标准模板例外**：使用公司最新发布的标准模板（v1.x 已法务审核），可由销售直接发起——但仍需逐条确认变量字段正确

## 禁忌 3：不盖章（形式要件缺失）

### 3.1 定义

合同只有签字没盖章，或只有电子签没盖实体章，或电子签无 CA 认证。

### 3.2 典型案例

**案例 C**：某客户方业务人员签了合同，但未盖公司章。3 个月后履约争议，客户以"未经公司授权"为由否认合同效力。

**后果**：

- 合同效力瑕疵：需证明该业务人员有代表权 / 表见代理
- 客户主张表见代理不成立 → 合同无效 → 我方损失

**案例 D**：某科技公司用国内某电子签平台签合同，未与第三方 CA 机构对接。2 年后客户以"电子签名不符合法律要求"为由否认合同。

**后果**：

- 电子签无效（《电子签名法》第 13-14 条要求第三方 CA + 可信时间戳）
- 合同自始无效

### 3.3 法律依据

- **《电子签名法》第 13 条**：电子签名同时符合下列条件的，视为可靠的电子签名：
  - 电子签名制作数据用于电子签名时，属于电子签名人专有
  - 签署时电子签名制作数据仅由电子签名人控制
  - 签署后对电子签名的任何改动能够被发现
  - 签署后对数据电文内容和形式的任何改动能够被发现
- **《电子签名法》第 14 条**：可靠的电子签名与手写签名或者盖章具有同等的法律效力
- **《民法典》第 490 条**：当事人采用合同书形式订立合同的，自双方当事人签字或者盖章时合同成立

### 3.4 红线

- **法人主体 → 必须盖章 + 法定代表人签字**（或授权代表 + 委托书）
- **电子签 → 必选用持牌平台**（e-签宝 / 法大大 / 上上签）+ CA 证书 + 可信时间戳
- **涉外 → 双轨**（电子签中文版 + 纸质签字盖章英文版）
- **行业限制**：金融 / 医疗 / 政府客户，部分场景必须纸质 + 实体章——签约前必问客户所属行业监管要求

## 禁忌 4：代签无委托（程序瑕疵）

### 4.1 定义

客户方由非法定代表人 / 非授权代表签字，且未索要授权委托书原件。

### 4.2 典型案例

**案例 E**：某客户公司采购总监（非法定代表人）签了合同，无授权委托书。3 个月后客户公司称"该采购总监无权签约"，拒付尾款。

**后果**：

- 主张表见代理（《民法典》第 172 条）：需证明"合同相对人有理由相信行为人有代理权"
- 若举证不能 → 合同无效 → 我方损失
- 履约风险：签字人离职 / 越权 → 客户拒绝履行

### 4.3 法律依据

- **《民法典》第 172 条**：行为人没有代理权、超越代理权或者代理权终止后，仍然实施代理行为，相对人有理由相信行为人有代理权的，代理行为有效
- **《民法典》第 170 条**：执行法人或者非法人组织工作任务的人员，就其职权范围内的事项，以法人或者非法人组织的名义实施的民事法律行为，对法人或者非法人组织发生效力

### 4.4 红线

- **任何非法定代表人签字，必须索要授权委托书原件**
- **授权委托书必填项**：
  - 委托人（公司全称 + 法定代表人姓名 + 签字 + 公司盖章）
  - 受托人（姓名 + 身份证号 + 联系方式 + 签字样本）
  - 授权范围（标的 / 金额 / 期限）
  - 授权期限（如 30 天 / 60 天）
- **授权委托书作为合同附件归档**
- **签字样本比对**：核对受托人签字样本与合同签字一致

## 禁忌 5：未做尽调（隐性风险）

### 5.1 定义

首次签约前未做主体资格审查，盲目签约。

### 5.2 典型案例

**案例 F**：某公司销售签了 1000 万的 SaaS 年单，签约前未查客户公司状态。客户公司 1 个月后被申请破产重整，所有未履行合同列入破产财产，我方作为普通债权人按比例受偿（约 5-10%）。

**后果**：

- 损失 900 万+ 服务费
- 已投入的交付成本无法回收

**案例 G**：某公司销售签了合同，签约前未查客户失信记录。客户公司法定代表人被列为失信被执行人，付款能力存疑。

**后果**：

- 付款拖延 / 拒付
- 诉讼执行难

### 5.3 必查 4 项

#### 5.3.1 营业执照

**查询渠道**：国家企业信用信息公示系统（gsxt.gov.cn）

**必查字段**：

- **主体存续**：存续 / 注销 / 吊销
- **统一社会信用代码**：与客户提供一致
- **法定代表人**：与签约代表一致 / 是否有变更
- **注册资本**：实缴 vs 认缴
- **经营期限**：是否过期
- **登记机关**：是否异常

#### 5.3.2 司法风险

**查询渠道**：

- 中国裁判文书网（wenshu.court.gov.cn）
- 中国执行信息公开网（zxgk.court.gov.cn）

**必查字段**：

- **涉诉记录**：作为被告的案件数量 / 类型 / 金额
- **被执行记录**：是否被强制执行 / 失信被执行人
- **限制高消费**：法定代表人 / 实控人

#### 5.3.3 信用记录

**查询渠道**：

- 信用中国（creditchina.gov.cn）
- 第三方征信：启信宝 / 天眼查 / 企查查

**必查字段**：

- **行政处罚**：工商 / 税务 / 行业监管
- **经营异常**：列入异常名录 / 严重违法
- **股权冻结 / 质押**：影响实际控制
- **欠税公告**：财务风险信号

#### 5.3.4 关联方

**查询渠道**：股权穿透图（启信宝 / 天眼查）

**必查字段**：

- **股权结构**：实际控制人 / 一致行动人
- **关联方**：是否与已知失信 / 高风险主体有关联
- **重复签约**：同一实控人下的其他主体是否有未履约历史

### 5.4 红线

- **首次签约前必查 4 项**——任一项有高风险信号（如失信被执行 / 严重违法 / 行政处罚密集），必先内部评审
- **关联方交易**：同一实控人下的多个主体签合同，必先评估整体风险
- **尽调报告归档**——作为合同附件，保留 ≥ 6 年（《会计档案管理办法》要求）
- **复检**：客户主体状态每 6 个月复检一次（重大合同 / 长期合同）

## 红线总表（速查）

| # | 禁忌 | 触发条件 | 法律后果 | 红线动作 |
|---|---|---|---|---|
| 1 | 阴阳合同 | 同一交易两份合同 / 金额不一 | 逃税罪 + 合同无效 | 一份最终执行版本，备案与执行一致 |
| 2 | 先签后审 | 销售为冲业绩不经过法务 review | 合同无效 / 条款风险 | 任何金额必先过我方法务 review |
| 3 | 不盖章 | 法人主体无盖章 / 电子签无 CA | 效力瑕疵 / 电子签无效 | 法人盖章 + 法定代表人签字；电子签选持牌 |
| 4 | 代签无委托 | 非法定代表人签字无委托书 | 表见代理风险 / 履约不能 | 必索授权委托书原件 + 签字样本 |
| 5 | 未做尽调 | 首次签约前未查主体 | 主体无效 / 失信被执行 / 资金断裂 | 首次签约前 4 项必查；尽调报告归档 |
