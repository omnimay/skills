# 中文会议室礼仪

> 中国本土实践（无海外方法论来源）。
> 用途：拜访前 1.4 备资料包 + 拜访中全程——贯穿用。

## 一、座次安排

中国会议室常见座次：

### 主宾位

- 客户 EB / Champion 坐在主宾位（通常为进门右手边或面门位置）
- 不要让客户坐在背门位置（不礼貌）

### 自己位

- 销售坐客位（通常为进门左手边或背门位置）
- 不要坐主宾位（喧宾夺主）

### 陪同位

- 销售陪同（同事 / 老板）坐在销售旁边
- 不要让陪同坐在主宾位或重要客户旁边（喧宾夺主）

## 二、名片礼仪

- 双手递名片（文字朝向对方）
- 双手接名片（接过来看一眼 + 念出名字 + 放在桌面显眼位置）
- 不要把名片塞口袋（不重视）
- 不要当场在名片上写字（不尊重）

## 三、茶水位置

- 茶水由客户方准备（领导先上茶）
- 不要主动帮客户倒茶（客户会倒给你）
- 自己的茶杯放在右手边（方便拿）

## 四、陪同动线

- 进门：销售先入 + 客户后入（客户优先）
- 落座：客户先坐 + 销售后坐
- 离场：销售先起 + 客户后起 + 销售送客户到电梯 / 车
- 送行：销售送到电梯 / 车门口，目送客户离开

## 五、说话礼仪

- 称呼用「姓 + 职务」（张总 / 李总 / 王经理）
- 不要直呼其名（不礼貌）
- 说话声音适中（不要太大或太小）
- 不要打断客户讲话（不礼貌）
- 客户讲完后停顿 2-3 秒再回应（表示尊重 + 思考）

## 六、肢体语言

- 坐姿端正（不要翘二郎腿）
- 目光接触 EB / Champion（不看手机）
- 客户讲话时点头（表示在听）
- 不要频繁看表（暗示想结束）
- 不要在客户讲话时翻资料（不尊重）

## 七、礼物 / 伴手礼仪

- 拜访前准备好礼物（小礼物 / 公司小物料）
- 不要送贵重物品（合规风险 + 客户压力）
- 不要送烟酒 / 茶叶 / 高档礼品（反腐合规）
- 礼物在离场时送，不在开始时送（避免显得动机不纯）

## 八、离场礼仪

- 议程完成后主动总结（确认下一步）
- 主动起身（暗示结束）
- 送客户到电梯 / 车门口
- 目送客户离开
- 回公司后立即发感谢微信

## 九、紧急情况应对

- 高管临时缺席 → 礼貌接待其他参会人 + 主动问 EB 回来时间 + 现场约下次 EB 时间
- 议程被客户改 → 同步修改（按客户优先级调）
- 客户提前离场 → 礼貌送行 + 留微信 + 留礼物
- 客户明显失去兴趣 → 用留台阶话术保住关系（Warm Walk-Away）
- 客户发脾气 → 不反驳 + 主动暂停 + 转入内部协调

## 十、合规红线

- 不拍照 / 录音 / 录像（除非明确告知 + 取得同意）
- 不打听客户内部八卦（人事变动 / 派系斗争）
- 不在客户会议室评价竞品
- 不透露未授权的客户案例（其他客户名 / 合作金额）
- 不透露未公开的公司内部信息（融资 / 战略 / 高管变动）
