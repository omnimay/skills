# 拜访中节奏表

> 方法论来源：onewave deal-closer-playbook Timing Benchmarks（MIT）；30/30/30 谈话比例与 EBR 会议结构为销售通用方法论，加中国版改造（5/15/5/5）。
> 用途：拜访前 1.3 设计议程 + 拜访中 2.x 跑节奏——双用。

## 一、三档时长版本

### 30min 压缩版（默认）

中国拜访最常见时长。节奏：5 / 15 / 5 / 5 + 弹性 5min。

| 段 | 时长 | 目标 | 内容 |
|---|---|---|---|
| 开场 | 5min | 破冰 + 议程确认 | 自介 + 议程同步 + 议程确认（必做） |
| 高管段 | 15min | 5 段式 + 信任前置 | 痛点 / 方案 / 证明 / 差异化 / ask |
| 互动 | 5min | 信号抓取 | 诊断问句 + 沉默 + 含蓄解码 |
| 闭合 | 5min | 确认式收口 + 三件套 | 反问闭合 + 留台阶 + 微信 + 礼物 |
| 弹性 | 5min | 缓冲 / 应急 / 延长互动 | 议程未达预期时优先砍高管段 |

判定：高管段超过 20min = 互动被压；互动少于 3min = 信号没抓到；闭合少于 3min = 没逼出下一步。

### 60min 标准版（推荐）

完整三角分段。节奏：5 / 20 / 10 / 15 / 10。

| 段 | 时长 | 目标 | 内容 |
|---|---|---|---|
| 开场 | 5min | 同上 | 同上 |
| 高管段 | 20min | 5 段式 + 信任前置 + ROI | EB 在场时重点讲 |
| 技术业务段 | 10min | 三角色切分（技术 + 业务） | 按产品介绍话术三角色版本展开 |
| 互动 | 15min | 深度信号抓取 | 诊断问句 + 沉默 + 含蓄解码 + 中层博弈 |
| 闭合 | 10min | 确认式收口 + 三件套 + 内部协调 | 反问闭合 + 留台阶 + 微信 + 礼物 + 内部同步 |

判定：三角分段必须触达 EB；如 EB 缺席，技术业务段优先砍。

### 90min 完整版（含午餐 / 茶歇）

节奏：5 / 20 / 15 / 15 / 20 / 10 / 5。

| 段 | 时长 | 目标 | 内容 |
|---|---|---|---|
| 开场 | 5min | 同上 | 同上 |
| 高管段 | 20min | 5 段式 + 信任前置 + ROI | EB 在场 |
| 技术业务段 | 15min | 三角色完整 | 产品介绍话术全角色 |
| 茶歇 | 15min | 关系建立 + 非正式沟通 | 陪同动线 + 共同话题 + 不要急于聊业务 |
| 互动 | 20min | 深度信号 + 异议现场处理 | 4 类反对 + 中层博弈 |
| 闭合 | 10min | 确认式收口 + 三件套 | 同上 |
| 弹性 | 5min | 应急 | 议程未达预期时优先砍茶歇外段 |

判定：茶歇段不聊业务，专注关系；如客户主动聊业务，顺势但控制时间（不超过 5min）。

## 二、节奏合规判定（硬规则）

| 时长 | 偏离阈值 | 后果 |
|---|---|---|
| 30min | 偏离超过 30%（某段超 1.5 倍） | 重设议程 |
| 60min | 偏离超过 30% | 重设议程 |
| 90min | 偏离超过 20% | 重设议程 |

典型问题：

- 高管段超 20min = 互动被压，信号没抓到。下次主控时间。
- 互动段超 30min = 闭合被压，没逼出下一步。按 `closing-moves.md` 强制收口。
- 闭合段超 10min = 客户开始犹豫不决。用 Warm Walk-Away 留台阶。

## 三、三角分段判定

| 角色 | 在场时 | 不在场时 |
|---|---|---|
| EB（高管） | 必须讲高管段 5 段式 | 按 `closing-moves.md` 试探下次 EB 时间 |
| Champion（业务总监） | 必须讲业务段 | 重点服务，争取成为内部推手 |
| Influencer（IT/采购） | 必讲技术段 + 商务条款试探 | 主动约二次拜访 |
| User（基层） | 必讲业务段 + 询问一线痛点 | 通过 Champion 转达 |

三角齐全 = 60min 标准版；三角缺 1 = 砍对应段；三角缺 2 = 30min 压缩版 + 重点在 EB 段 + 互动段。

## 四、节奏合规 vs 30/30/30 改造说明

30/30/30 法则（销售拜访通用方法论）：30% 客户讲 / 30% 我们讲 / 30% 共识。

- 美式 enterprise 拜访 60min 标准。
- 中国版改造：开场 + 闭合各 5min（共识建立 + 共识确认）+ 高管段 + 技术业务段（共 30min 我们讲）+ 互动段 15min（客户讲 60%，我们讲 40%）= 30/30/30 改造版。
- 茶歇段不计（关系建立，不分比例）。

## 五、议程同步话术

议程同步必须现场做，模板：

> 「张总，今天我们大概 60 分钟，我想跟您聊三件事：一是您这边目前在做 XX 项目的背景，二是我们针对 XX 的方案大致方向，三是接下来怎么往下推。您看这样行不行？要不要调整？」

判定：

- 客户同意 = 进入开场
- 客户改议程 = 同步修改（按客户优先级调）
- 客户拒绝议程 = 警示信号（客户没想好好谈），按 `closing-moves.md` Warm Walk-Away 试探
