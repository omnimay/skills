# 拜访前 72h 参会人 Brief 模板

> 拜访简报模板，加中国化变量。
> 用途：拜访前 72h 必出的一份 brief——进会议室前 10 分钟扫一眼用。

## 模板字段（10 项）

### 1. 客户公司速描（≤5 句话）

- 行业 / 规模（员工数 + 年营收区间）/ 业务模式（B2B/B2C/平台）
- 公开关键变化（最近 3 个月：融资 / 收购 / 高管变动 / 业务扩张）
- 决策链完整性（已知 3 角色以上 = 绿；只知 1-2 人 = 黄；只知联系人 = 红）

### 2. 参会人卡片（每人一卡）

| 字段 | 内容 | 来源 |
|---|---|---|
| 中文姓名 + 英文名（如有） | | CRM / 邮件签名 |
| 职务 + 部门 | | LinkedIn / 公司官网 |
| 角色定位 | 经济买家 EB / 拥护者 Champion / 影响者 Influencer / 用户 User | 见 stakeholder-mapping.md |
| 已知利益 / 痛点 | | 上次沟通 / 行业信号 |
| 已知反对倾向 | | 上次沟通 / 行业信号 |
| 微信 / 企微可达性 | | CRM / 上一手转介 |
| 沟通偏好（数据派 / 关系派 / 流程派） | | 上次沟通判断 |
| 上次沟通结论 | | CRM 备注 |
| 触达频率（红/黄/绿） | | 本次拜访目标更新 |

### 3. 已知信号（信号卡）

- **触发 NOW 的信号**：行业政策 / 公司大事 / 决策人异动 / 内部 IT/数字化项目立项
- **反向信号（anti-signals）**：高管沉默 / 关键人缺席 / 时间表反复改

### 4. 风险点（5 项以内）

- 高管临时缺席 / 新增未通知参会人 / 客户已选竞品 / 预算未到位 / 时间表不真实

### 5. 待问问题（5-8 条）

- 按优先级排序：必问（开门必须问）/ 探问（互动段问）/ 验问（闭合段验）

### 6. 议程设计

- 总时长（30 / 60 / 90 min）+ 分段时间（按 meeting-rhythm.md）
- 每段目标（开场 / 高管段 / 互动 / 闭合）

### 7. 资料包清单

- 必带：合同样板 / 同业案例 / 团队介绍 / 产品手册 / 名片
- 不带：未确认报价单 / 内部财务数据 / 未授权客户案例

### 8. 礼仪 checklist

- 座次（主宾位 / 自己位）
- 名片（双手递接 + 双手接）
- 茶水位置（领导 vs 自己）
- 陪同动线（谁陪同 / 谁接送）

### 9. 紧急预案

- 高管临时缺席 → 应对话术（按 `closing-moves.md` Warm Walk-Away 改写）
- 议程被客户改 → 同步 vs 接受判断
- 异议升级为冲突 → 暂停 + 内部同步

### 10. 拜访后 24h 复盘卡（提前填字段）

- 信号变化 diff 字段（红/黄/绿升级/降级）
- 下一动作字段（动作/owner/deadline/验收/内部协调）
- 内部同步字段（5 句话模板）

---

## 出 brief 的判定

- 10 项字段缺一即标 missing，不猜。
- 标 missing > 3 项 = 红色（brief 不可用，需用户补信息）；≤ 3 项 = 黄色（可用合理假设并标注）；0 项 = 绿色（直接用）。
- brief 必须在拜访前 24h 完成（72h 备战 → 48h 内跑信号卡 → 24h 出 brief）。
