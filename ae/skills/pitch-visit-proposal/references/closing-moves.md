# 临门一脚推进动作

> 方法论来源：onewave deal-closer-playbook Final Reverse Question + Warm Walk-Away（MIT），续约钩子为销售通用方法论，改写为中国版。
> 用途：拜访中 2.5 闭合 5min + 拜访后 3.2 下一动作清单——双用。

## 一、确认式收口（中文版反问闭合）

美式版（deal-closer-playbook）：「假定同意」型反问（"If we move forward, what would be the timeline?"）。

中文版改造为「**确认式收口**」——话术模板：

- 「王总您看这样行不行——我们 X 月 X 日把方案初稿发您，您 X 月 X 日前给反馈？」
- 「张总下一步我们 X 时间 X 动作您看 OK 吗？」
- 「李总如果 X 月 X 日前能确认，我们 X 月 X 日上线，您看这样安排如何？」

判定：

- 客户确认时间 + 动作 = 通过（立即记入 CRM）
- 客户改时间 + 动作 = 通过（按客户版本记入 CRM）
- 客户回避 = 警示信号（可能未真正感兴趣，转 Warm Walk-Away）

## 二、留台阶 + 留微信 + 礼物三件套（中文版 Warm Walk-Away）

美式版（deal-closer-playbook）：不强推 + 给台阶 + 留机会。

中文版改造为三件套：

### 1. 留台阶

如客户没表态或议程失控，给台阶：

- 「我理解这个决定需要内部讨论」
- 「今天时间也比较紧，要不先到这里？」
- 「这事确实不急，您们内部先沟通一下」

判定：客户接受台阶 = 关系未破，下次还有机会；客户不接受台阶（继续拉你讲）= 实际仍有兴趣。

### 2. 留微信

加微信（不只换名片）+ 微信扫一扫要快（30 秒内完成，别让客户等你打开 App）。

话术：

- 「王总，方便加个微信吗？后续材料我直接发您微信。」
- 「李总我们扫一下，方案初稿第一时间给您看。」

判定：加微信成功 = 触达频率升级（黄 → 绿）；客户拒绝加微信 = 警示信号（可能不打算继续推进）。

### 3. 礼物

小礼物 / 公司小物料（不是贵重物品）——中国 B2B 礼仪，离场送行用。

选择标准：

- 不贵重（100-300 元区间）
- 有公司 logo / 品牌记忆点
- 实用（笔记本 / 钢笔 / U 盘 / 公司定制小物料）
- 不踩雷（不送烟酒 / 茶叶 / 高档礼品——反腐合规）

话术：

- 「王总这是我们公司的 X 小礼物，您留着做个纪念。」
- 「李总路上注意安全，这是给您的伴手礼。」

## 三、临门一脚钩子（中文版 Renewal Hooks）

美式版（customer-success-manager）：续约 / 增购 / 转介绍。

中文版改造为四类钩子（拜访提案场景适用）：

| 钩子类型 | 场景 | 话术 |
|---|---|---|
| 试用钩子 | 客户想体验产品 | 「王总要不您先试用 2 周？我们给您开专用账号」 |
| POC 钩子 | 客户想验证效果 | 「我们做 1 个月 POC，验证 X 场景下 XX 指标，您看哪些指标最关键？」 |
| 小范围试点钩子 | 客户想降低风险 | 「要不先在您 X 部门跑 1 个季度，验证完再全面铺？」 |
| 标杆案例参观钩子 | 客户想看真实案例 | 「我们 X 月 X 日在 XX 公司有个现场参观，要不要一起？」 |

## 四、mutual close plan（双方行动计划）

美式版（deal-closer-playbook）：双方共同制定下一步。

中文版改造为「**5 字段计划**」——

| 字段 | 内容 | 例子 |
|---|---|---|
| 动作 | 具体下一步 | 「我们 X 月 X 日前发方案初稿」 |
| Owner | 谁负责 | 「我们这边李总负责，您那边张总对接」 |
| Deadline | 具体到日 | 「X 月 X 日」 |
| 验收 | 验收标准 | 「您收到后 X 天内给反馈」 |
| 内部协调 | 谁需要知情 | 「您内部需要先跟王总沟通」 |

判定：

- 客户现场同意 5 字段 = 强升级信号
- 客户改字段 = 通过（按客户版本记入 CRM）
- 客户拒绝写字段 = 警示信号（未真正进入推进阶段）

## 五、闭合段判定

| 判定项 | 通过 | 不通过 |
|---|---|---|
| 客户确认下一步时间 | 升级：双方对齐 | 警示：可能只是客套 |
| 客户加微信 | 升级：触达到位 | 警示：拒绝加微信 |
| 客户接受礼物 | 关系建立 | 警示：拒绝礼物 |
| 客户留具体下次时间 | 推进 | 警示：下次再说 |
| 客户离场态度积极 | 关系到位 | 警示：敷衍散场 |

## 六、闭合未达预期时的 Warm Walk-Away

如议程失控 / 客户失去兴趣 / 关键人缺席：

话术：

- 「王总我理解您今天时间比较紧，要不我们下次再约？」
- 「张总这事确实不急，您先跟领导沟通，下次我们带着具体方案再来。」
- 「李总您先忙，我们留个微信，下次有需要随时联系。」

原则：

- 不强推
- 不冷场
- 留台阶
- 留微信
- 留具体下次时间（如能争取）
- 留礼物（按场景）
