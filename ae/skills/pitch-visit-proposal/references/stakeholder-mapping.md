# 利益相关人应对

> 方法论：四角色干系人框架（EB / Champion / Influencer / User，销售通用方法论），加中国化改造（决策链非线性 + 含蓄解码 + 中层博弈）。
> 用途：拜访前 1.2 跑信号卡 + 拜访中 2.3 信号抓取 + 拜访后 3.1 信号变化 diff——三用。

## 一、四角色定义（核心）

| 角色 | 定义 | 中国化补充 |
|---|---|---|
| 经济买家 EB（Economic Buyer） | 最终拍板预算的人 | 中国常见 EB = 总经理 / CIO / CTO；国央企 EB 多为副总以上 |
| 拥护者 Champion | 帮你内部推动的人 | 中国常见 Champion = 业务总监 / 项目经理；中层是天然 Champion 候选 |
| 影响者 Influencer | 能影响 EB 但不直接决策 | 中国常见 Influencer = 采购总监 / IT 主管 / 财务总监 |
| 用户 User | 实际使用产品的人 | 中国 User 早期可能没话语权，后期是关键 |

## 二、中国决策链非线性（差异化补齐）

美式 enterprise 决策链：EB 拍板 → 采购执行 → 使用。线性、清晰。

中国决策链：非线性 + 多线并进。

- 国央企：党委会 / 总经理办公会 / 信息化领导小组三轮决策，缺一不可；EB 不一定最终拍板。
- 民企：老板拍板，但常受老板娘 / 副总 / 财务总监 影响。
- 外企中国子公司：全球总部 + 亚太区 + 中国区三层审批，EB 在中国区但预算在全球总部。
- 事业单位 / 医院 / 学校：招标 + 评标 + 纪检三层，EB 是名义上的。

应对：拜访前必查客户类型（工商信息 + 企查查股东结构），按类型选议程。

## 三、四角色红黄绿判定

| 颜色 | 含义 | 触达频率 |
|---|---|---|
| 绿 | 关系到位，微信/企微常聊 | 1 周内可主动约 |
| 黄 | 通但未深 | 2 周内主动破冰 1 次 |
| 红 | 没摸清 / 失联 / 首次接触 | 拜访前必触达 1 次 |

判定升级条件：

- 绿 → 降级 = 客户连续 2 次未回应 / 议程临时改期 / 关键问题被回避
- 红 → 升级 = 加微信 / 加企微 / 约下次具体时间

## 四、含蓄表达解码（中国化独有）

| 含蓄表达 | 解码 | 应对 |
|---|---|---|
| 再看看 | 未确认 / 想比较 | 不追问；给 easy no 出口 |
| 差不多吧 | 还在比 / 没下定决心 | 帮客户算账（具体数字） |
| 我们内部评估一下 | 想压价 / 需要更多证据 | 出试点方案 + 退出条款 |
| 价格再商量 | 想压价 | 不接话；等客户先出价 |
| 你们先做个方案看看 | 拖延 / 没真实需求 | 问决策流程 + 时间表 |
| 今天先到这里 | 已失去兴趣 / 时间到 | 留台阶 + 留具体下次时间 |
| 我回去跟领导汇报 | EB 不在场 / Champion 不敢拍板 | 现场约 EB 时间 |
| 我们老板不在 / 出差了 | EB 回避 | 问 EB 回来时间，约下次 |
| 这个事情不急 | 优先级低 / 拖延 | 出 easy no 出口：今天不定也行 |
| 我们再考虑一下 | 基本拒绝 | 留台阶 + 留微信 |

## 五、中层博弈指标（差异化补齐）

中国大客户常见中层（IT / 采购 / 法务 / 业务总监）作为独立决策维度，需独立评估：

| 中层 | 评估权 | 红黄绿指标 |
|---|---|---|
| IT 中层 | 技术评估权 + 二次开发评估权 | 微信企微可达性 + 技术问题回应速度 |
| 采购中层 | 价格谈判权 + 商务条款权 | 历史合作倾向 + 标准条款接受度 |
| 法务中层 | 合规风险评估权 | 标准条款接受度 + 法务介入阶段 |
| 业务中层 | 真实需求评估权 + Champion 候选 | 痛点共鸣度 + 内部推动意愿 |

中层博弈常见信号：

- 中层主动挑刺 = 抢谈判筹码（升级信号：中层被授权了）
- 中层沉默 = 已被 EB 绕过（降级信号：中层失势）
- 中层频繁追问 = 想拿回主动权（应对：主动给信息）

## 六、四角色现场应对话术（差异化补齐）

### 对 EB：少讲功能，多讲战略

「王总，您看这件事对咱们公司未来 3 年的数字化战略有什么影响？」——把球丢给 EB。

### 对 Champion：给弹药，让他内部推动

「李总，这是我准备的内部推进材料，包括 ROI 测算 + 案例 + FAQ，您看下够不够？」——Champion 需要弹药。

### 对 Influencer：尊重流程，给证据

「陈总，这是我们的资质 + 同行业案例 + 客户原话，您看下技术评估这边还需要什么材料？」——给 Influencer 弹药。

### 对 User：聊场景，问痛点

「张老师，您平时用 XX 系统的时候，最头疼的是什么？」——User 给出真实需求。

## 七、四角色现场判定

| 信号 | 判定 |
|---|---|
| EB 主动问预算 | 升级：EB 真在评估 |
| Champion 主动约下次 | 升级：Champion 内部推动 |
| Influencer 主动问条款 | 升级：进入商务谈判阶段 |
| User 主动问培训 | 升级：考虑上线 |
| EB 沉默 > 10 秒 | 降级：可能未听懂 / 不感兴趣 |
| Champion 频繁看手机 | 降级：可能已被否决 |
| Influencer 提竞品 | 降级：客户已接触竞品 |
| User 不在 | 降级：基层没参与感 |
