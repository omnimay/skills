# 拜访后 24h 复盘卡

> 中国本土实践补齐（无海外方法论来源）。
> 用途：拜访后 24h 内必出的复盘卡——衔接 clinch-progression-strategy 推进主线。

## 一、信号变化 diff（拜访前 vs 拜访后）

把拜访前 1.2 跑的红 / 黄 / 绿 vs 拜访后实际跑的红 / 黄 / 绿 对比，标 升级 / 持平 / 降级 / 转冷。

| 角色 | 拜访前 | 拜访后 | 变化 |
|---|---|---|---|
| EB | 颜色 | 颜色 + 备注 | 升级/持平/降级/转冷 |
| Champion | 同上 | 同上 | 同上 |
| Influencer | 同上 | 同上 | 同上 |
| User | 同上 | 同上 | 同上 |

判定：

- 升级 = 触达频率 + 1 档（如黄 → 绿）
- 持平 = 颜色不变，备注补充
- 降级 = 触达频率 -1 档（如绿 → 黄）
- 转冷 = 立即按转冷流程升级处理

转冷信号（警示）：

- 决策人缺席
- 关键问题被回避
- 高管沉默 > 10 秒
- 客户高管明确拒绝
- 客户已选竞品

## 二、下一动作清单（5 字段）

对接 clinch-progression-strategy 主线 4。

| 字段 | 内容 | 例子 |
|---|---|---|
| 动作 | 具体下一步 | 我们 X 月 X 日前发方案初稿 |
| Owner | 谁负责 | 我们这边李总负责，您那边张总对接 |
| Deadline | 具体到日 | X 月 X 日 |
| 验收 | 验收标准 | 您收到后 X 天内给反馈 |
| 内部协调 | 谁需要知情 | 您内部需要先跟王总沟通 |

原则：

- deadline 必须具体到日（「下周」= 无 deadline）
- Owner 必须具体到人（不是「我们」或「您们」）
- 验收必须可量化（「给反馈」≠「满意」）
- 内部协调必须明确（避免 Champion 偷偷走流程）

## 三、内部同步卡（5 句话模板）

写 5 句话同步给老板 + 团队，不是写给自己看的日记：

1. **一句话结论**：这次拜访推进到了哪一步（如「进入 POC 阶段」/「客户已选竞品」/「需要老板出面」）
2. **关键信号**：升级 / 持平 / 降级 + 1-2 个具体证据
3. **下一动作 + Owner**：具体到日 + 具体到人
4. **风险点**：1-2 个具体风险（如「EB 临时缺席」「客户预算未到位」）
5. **需要支持**：1-2 个具体支持项（如「需要老板 X 月 X 日前给 EB 打一个电话」）

判定：老板能在 30 秒内读完并做出决策 = 通过。

## 四、CRM 更新

拜访后 24h 内必做：

- 拜访记录：粘贴 brief + 议程 + 互动段关键对话 + 闭合段收口
- next step：5 字段动作清单
- 触达频率更新：每个角色 +1 档 / -1 档 / 持平
- Stakeholder Health 重打分：红 / 黄 / 绿 + 中层博弈指标 + 微信企微可达性
- 关键信号：升级 / 持平 / 降级 / 转冷 标签
- 案例库：如有新案例入库，标脱敏等级

## 五、复盘卡判定

| 判定项 | 通过 | 不通过 |
|---|---|---|
| 信号变化 diff 完整 | 4 角色都标 | 缺角色 |
| 5 字段动作清单 | 5 项都填 | 缺字段 |
| 内部同步卡 | 30 秒能读完 | 超过 1 页 |
| CRM 更新 | 24h 内完成 | 超过 24h |
| 转冷信号识别 | 立即按转冷流程升级处理 | 拖到下次拜访 |

## 六、复盘结果的后续处置

| 复盘卡内容 | 处置方式 |
|---|---|
| 拜访对话全文 / 五维态度 | 进入结构化沟通复盘（逐段还原对话 + 五维态度判定） |
| 下一动作 / 卡点 / 路径 | 交 clinch-progression-strategy 出推进思路 |
| 客户已到逼单窗口 | 进入临门逼单节奏，制定逼单计划 |
| 异议深度挖掘 | 多轮异议深挖处理 |
| 转冷信号 | 按转冷流程立即升级处理 |
| 后续邮件 / 微信 | 24h 内发出跟进触达 |
