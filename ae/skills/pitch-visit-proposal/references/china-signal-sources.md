# 中国信号源（信号卡用）

> 用途：拜访前 72h 跑信号卡时使用——按本表信号源跑一遍，给每个参会人贴红/黄/绿。
> 顺序：水滴式 — 从公开 → 半公开 → 内部信源，按可获得性依次展开。

## 公开信号源（无需授权，可直接查）

### 1. 工商信息类

- **企查查**（qcc.com）/ **天眼查**（tianyancha.com）—— 工商注册 / 股东 / 法人 / 对外投资 / 司法风险
  - 信号：法人变更 / 股东变更 / 新增对外投资 = 公司战略调整（升级信号）
  - 信号：司法风险增加 / 失信被执行人 = 客户预算紧张（降级信号）
- **启信宝**（qixin.com）—— 同上，备选

### 2. 招投标类

- **中国招标投标公共服务平台**（cebpubservice.com）—— 全国招投标公告
- **千里马招标网**（qianlima.com）/ **剑鱼标讯**（jianyu.tech）—— 招投标信息聚合
  - 信号：客户近期发布招标 = 有预算在找方案（升级信号）
  - 信号：客户中标某竞品 = 已选竞品（转冷信号，需立即升级处理）

### 3. 招聘类（强信号）

- **Boss 直聘**（zhipin.com）/ **拉勾**（lagou.com）/ **前程无忧**（51job.com）
  - 信号：新增「数字化总监」「IT 总监」「业务系统 PM」岗位 = 公司正在立项数字化项目（升级信号，时机最好）
  - 信号：招聘要求"熟悉 XX 系统" = 客户可能已选竞品（降级信号）

### 4. 行业新闻类

- **36 氪**（36kr.com）/ **虎嗅**（huxiu.com）/ **亿欧**（iyiou.com）/ **钛媒体**（tmtpost.com）
  - 信号：客户被报道融资 / 上市 / 业务扩张 = 升级信号
  - 信号：客户被报道裁员 / 业务收缩 = 降级信号
- **公司官网新闻动态** / **官方公众号** —— 一手信号最准

### 5. 社交类（半公开）

- **脉脉**（maimai.com）—— 互联网职场社交
  - 信号：高管 / 业务总监动态（如跳槽 / 升职 / 公开演讲） = 决策人变化（升级或降级）
- **LinkedIn 中国版**（linkedin.com）—— 外企 / 海归高管
- **微博**（weibo.com）/ **知乎**（zhihu.com）—— 高管个人发声

## 半公开信号源（需有连接）

### 6. 同行 / 友商

- 同行业其他客户（已合作 / 未合作）的反馈
- 友商销售的朋友圈 / 行业群消息
- 行业展会 / 论坛的口碑

### 7. 行业自媒体 / KOL

- 行业垂直媒体（如「企服头条」「崔牛会」等）
- 行业 KOL 公众号 / 知乎专栏

## 内部信号源（需 CRM / 既有客户）

### 8. CRM 备注

- 上次沟通结论 + next step
- 历史拜访记录 + 触达频率
- Stakeholder Health 评分历史

### 9. 既有客户案例库

- 同行业既有客户的成功案例
- 同类客户的拜访 brief 历史（脱敏）

### 10. 老板 / 团队内部信源

- 老板的行业人脉
- 团队中曾服务过该客户的成员

## 信号分类（按信号类型分）

| 信号类型 | 含义 | 时效 | 来源 |
|---|---|---|---|
| **触发 NOW** | 时机到了，本周就该联系 | 强（24-72h 内） | 招聘 / 招标 / 工商变更 |
| **公司大事** | 中期影响 | 中（1-4 周） | 融资 / 上市 / 收购 |
| **角色异动** | 决策人变化 | 强（24-72h 内） | 脉脉 / LinkedIn |
| **行业事件** | 大方向影响 | 中（1-4 周） | 政策 / 行业报告 |
| **内部变化** | 客户内部动作 | 强（24-72h 内） | 客户公众号 / 内部人脉 |
| **反向信号** | 失联 / 沉默 / 缺席 | 强（24-72h 内） | 拜访后 / 沟通后 |

## 信号卡填写规则

- 每类信号至少 1 条（无 = 标"未发现"）。
- 触发 NOW 信号 ≥ 1 条 = 拜访理由"为什么是现在"成立。
- 反向信号 ≥ 1 条 = 拜访目的升级为"摸底 / 升温"，而非"提案"。
- 信号卡完成后给每个参会人重打分（红/黄/绿）。
