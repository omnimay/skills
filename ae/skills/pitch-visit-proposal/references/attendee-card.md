# 参会人卡片字段表

> 拜访参会人卡模板，加中国化字段（含微信企微可达性、中层博弈指标）。
> 用途：每个参会人填一张卡，拜访前 24h 内完成。

## 字段定义（10 项）

### 1. 基础字段（4 项）

- **中文姓名 + 英文名**（如 Wang Wei / David Wang）
- **职务 + 部门**（如 销售总监 / 营销中心）
- **职级**（高管 / 中层 / 基层）—— 用于判断触达深度
- **决策权**（决策 / 影响 / 知情）—— 用于判断是 EB 还是 Champion 还是 User

### 2. 角色定位（4 类）

| 角色 | 定义 | 中国化补充 |
|---|---|---|
| **经济买家 EB（Economic Buyer）** | 最终拍板预算的人 | 中国常见 EB = 总经理 / CIO / CTO；国央企 EB 多为副总以上 |
| **拥护者 Champion** | 帮你内部推动的人 | 中国常见 Champion = 业务总监 / 项目经理；中层是天然 Champion 候选 |
| **影响者 Influencer** | 能影响 EB 但不直接决策 | 中国常见 Influencer = 采购总监 / IT 主管 / 财务总监 |
| **用户 User** | 实际使用产品的人 | 中国 User 早期可能没话语权，后期是关键 |

### 3. 触达状态（红/黄/绿）

| 颜色 | 含义 | 中国化补充 |
|---|---|---|
| 🟢 **绿** | 关系到位，微信/企微常聊 | EB 级绿 = 关键；Champion 级绿 = 稳 |
| 🟡 **黄** | 通但未深 | 中国常见：电话通 + 微信加但未深聊 |
| 🔴 **红** | 没摸清 / 失联 / 首次接触 | 中国常见：只知道姓名 / 邮件，未见面 |

### 4. 含蓄表达解码（中国化独有）

| 含蓄表达 | 解码 | 应对 |
|---|---|---|
| "再看看" | 未确认 / 想比较 | 不追问；给 easy no 出口 |
| "差不多吧" | 还在比 / 没下定决心 | 帮客户算账（具体数字） |
| "我们内部评估一下" | 想压价 / 需要更多证据 | 出试点方案 + 退出条款 |
| "价格再商量" | 想压价 | 不接话；等客户先出价 |
| "你们先做个方案看看" | 拖延 / 没真实需求 | 问"决策流程 + 时间表" |
| "今天先到这里" | 已失去兴趣 / 时间到 | 留台阶 + 留具体下次时间 |

### 5. 中层博弈指标（差异化补齐）

中国大客户常见中层（IT/采购/法务/业务总监）作为独立决策维度，需独立评估：

- **IT 中层**：技术评估权 + 二次开发评估权 —— 红黄绿 + 微信企微可达性
- **采购中层**：价格谈判权 + 商务条款权 —— 红黄绿 + 历史合作倾向
- **法务中层**：合规风险评估权 —— 红黄绿 + 标准条款接受度
- **业务中层**：真实需求评估权 + Champion 候选 —— 红黄绿 + 痛点共鸣度

### 6. 微信企微可达性（差异化补齐）

| 等级 | 含义 |
|---|---|
| 加微信 + 常聊 | 可发资料 / 可紧急联系 |
| 加微信 + 偶聊 | 可发资料 / 不紧急 |
| 加企微 + 未私聊 | 仅工作沟通 |
| 仅名片 / 邮箱 | 红（需拜访后补加） |

### 7. 沟通偏好（3 类）

- **数据派**：喜欢看数字 / 表格 / 案例 —— 多给 ROI / 客户原话 / 行业报告
- **关系派**：喜欢聊行业 / 公司 / 个人 —— 多破冰 + 找共同话题
- **流程派**：喜欢看流程图 / 时间表 / 责任分工 —— 多给里程碑 + RACI

### 8. 上次沟通结论

- 上次 next step 是否完成
- 上次未答问题清单
- 上次识别的新信号

### 9. 本次拜访目标

- 必达（高层支持 / 预算确认 / 时间表 / 进入 POC）
- 争取（具体方案 / 试用 / 案例参观）
- 试探（真实决策人 / 真实需求 / 真实反对）

### 10. 触达频率更新

- 拜访前 1 周触达 ≥ 2 次 = 绿
- 拜访前 1 周触达 1 次 = 黄
- 拜访前 1 周触达 0 次 = 红

---

## 出卡判定

- 10 项字段缺一即标 missing，不猜。
- 红黄绿三色字段必须明确标色（不写"待定"）。
- 含蓄表达解码字段必须有（首次接触除外）。
- 中层博弈指标按客户类型填（国央企 = 必填 / 民企 = 选填 / 外企 = 选填）。
