# 拜访提案（pitch-visit-proposal）

## 目的

把一次客户拜访从「讲了什么」推到「推进到了哪一步」——按 **72h 备战 / 60min 跑节奏 / 24h 复盘** 三段时间轴走完，销售读完知道今天该干啥、明天该交啥。

**边界**：不做产品话术、PPT 排版、演示脚本；不做单点异议深挖；不做整体推进思路 → `clinch-progression-strategy`；不做逼单执行；不做单次沟通复盘。

## 完整画面

```
前 72h 备战         │ 当下 60min 跑节奏   │ 后 24h 复盘
─────────          │ ───────────────    │ ──────────
① 参会人 brief    │ ① 开场 5min        │ ① 信号变化 diff
② 信号卡         │ ② 高管段 15-20min   │ ② 下一动作清单 5 字段
③ 议程            │ ③ 互动 10-15min    │ ③ 内部同步卡 5 句话
④ 资料包 + 礼仪  │ ④ 技术/业务 5-15min │ ④ CRM 更新
                  │ ⑤ 闭合 5-10min     │
```

读完心里有：**一句话打法**（找谁 / 聊啥 / 签啥）+ **三档节奏**（30/60/90min）+ **参会人卡只填 4 项** + **ROI 三档**（保守/基线/激进，**主动给保守让客户往上调**）+ **POC 三档台阶**（1 店/10 店/全集团）+ **现场三方签字纪要**（90% 销售不做的锁单动作）+ **24h 复盘交付**。

---

## 一、前 72h 备战

**期望产物**：brief.md 落地（参会人卡 + 信号卡 + 议程 + 资料包），销售进会议室前 10 分钟扫一眼能上场。

### 1.1 参会人 brief（每人一张卡，只填 4 项）

11 字段是 CRM 该记的，不是拜访备战要写的——销售没时间填假设字段。**只填 4 项**：

| 字段 | 怎么填 |
|---|---|
| **角色定位**（EB / Champion / Influencer / User） | 见 stakeholder-mapping.md |
| **已知痛点**（客户原话 + 信号源） | 上次沟通 / 行业信号 |
| **反对倾向**（价格 / 竞品 / 时机 / 需求 / 中层博弈） | 上次沟通 / 信号卡 |
| **本次目标**（必达 / 争取 / 试探 三档） | 销售自己定 |

必填项缺一就标 missing，不猜。**红黄绿三色不写「待定」**。

### 1.2 跑信号卡（4 类源 + 1 反向）

**触发 NOW 信号 ≥ 1 条 = 拜访理由成立；反向信号 ≥ 1 条 = 拜访目的降级为「摸底 / 升温」**。

| 类别 | 源 | 升级信号 |
|---|---|---|
| 工商变更 | 企查查 / 天眼查 | 股东变更、新增投资（战略调整） |
| 招投标 | 千里马 / 剑鱼标讯 | 近期发布招标（有预算） |
| 招聘 | Boss 直聘 / 拉勾 | 新增 IT 总监 / 业务系统 PM（立项中） |
| 行业新闻 | 36 氪 / 虎嗅 / 公司公众号 | 融资 / 上市 / 业务扩张 |
| **反向** | 任意 | 招投标中标某竞品（**已选竞品 = 转冷**） |

完整源清单 + 案例见 `references/china-signal-sources.md`。

### 1.3 设计议程（现场同步给客户）

**议程必须现场同步并获得确认**——议程不确认 = 全场被拖着走。三档时长：

- **30min 压缩版**（5/15/5/5）：首次拜访默认
- **60min 标准版**（5/20/10/15/10）：三角齐全走全
- **90min 完整版**（5/20/15/15/20/10/5 + 茶歇 15min）：含午餐/茶歇，茶歇不聊业务

完整节奏表见 `references/meeting-rhythm.md`。

### 1.4 备资料包 + 礼仪

**必带**：合同样板 / 同业案例 / 团队介绍 / 产品手册 / 名片 / 礼物（≤ 200 元 / 不送烟酒/高档茶叶）。**不带**：未确认报价单 / 内部财务数据 / 未授权客户案例。礼仪完整版（座次 / 名片 / 茶位 / 送行动线）见 `references/visit-meeting-etiquette.md`。

### 三类拜访侧重（按目的取舍）

| 拜访类型 | 节奏取舍 | 关键风险 |
|---|---|---|
| **首次拜访** | 高管段压到 10min，互动段拉长到 15min 摸底 | 没拿到关键人脉就离场 |
| **二次拜访** | 高管段走完整 5 段式 + 互动段预答 4 类反对 | 没逼出 next step |
| **提案演示** | 60min 标准版全跑，互动段收窄（演示为主） | 讲完没信号，没决策推进 |
| **高管对齐** | 砍技术/业务段，高管段拉到 25min + ROI | EB 缺席 / 议程被改 |

## 二、当下 60min 跑节奏

**期望产物**：按节奏跑完整 + 抓信号 + 收口。

### 2.1 五段节奏

1. **开场 5min** — 破冰 ≤ 60s + 自介 ≤ 60s + **议程同步**（客户改不改 = 第一道共识测试）。
2. **高管段 15-20min** — 5 段式：痛点 → 方案 → **证明**（资质 / 同类客户 / 客户原话 三件之一必含——中国客户不接受「没证明」就听产品）→ 差异化 → **ask**。
3. **互动 10-15min** — 客户讲 60%，我们讲 40%。诊断问句 + 沉默抓信号（决策链完整性 / 预算真实区间 / 时间表 / 真实反对）。**4 类高频反对即兴**：价格 / 竞品 / 时机 / 需求，按「承认 → 诊断 → 重构 → 反问」4 步走；**中层博弈型**（IT/采购/法务总监主动挑刺）= 给位置 + 给材料 + 让其成 Champion 候选。
4. **技术/业务 5-15min** — 三角齐全走三角色（按产品介绍话术展开），不齐就砍。
5. **闭合 5-10min** — **现场三方签字会议纪要**（销售 + 客户接口人 + Champion，三方电子签 + 一句话结论 + 5 字段动作清单 + 邮件确认）。**这是 90% 销售不做的锁单动作**——口头承诺 7 天归零，三方签字 = 法律留痕 + 内部推力。配套：留台阶（关系不破）+ 加微信（30s 内扫）+ 礼物（离场时送）。

### 2.2 ROI 三档（核心老炮动作）

**主动给保守数字，让客户自己往上调**——比憋个大数被砍下来强 10 倍。给区间 = 客户不主动提数字 = 推进失锚，销售被带回舒适区。

- **保守**（50% 达成可能）：客户教育你「算少了」
- **基线**（70% 达成可能）：你最 supportable 的结果
- **激进**（85% 达成可能）：保守 + 基线 + 你没说出口的隐藏价值

### 2.3 POC 三档台阶（逼 next step 时不能空）

- **A 档**（1 店 / 2 周）：最低门槛，业务 VP 拍板
- **B 档**（10 店 / 4 周）：区域总监拍板，A 跑通后再上
- **C 档**（全集团 / 3 月）：董事会级别，B 跑通后再上

### 2.4 含蓄解码（中国化独有，不按字面听）

| 客户说 | 真实信号 | 应对 |
|---|---|---|
| 「再看看」 | 未确认 / 想比较 | 给 easy no 出口，不追问 |
| 「差不多吧」 | 还在比 / 没下定决心 | 出差异化 + 具体数字算账 |
| 「我们内部评估一下」 | 想压价 / 需要证据 | 出试点 + 退出条款 |
| 高管沉默 > 10s | 信号缺失 / 不感兴趣 | 转诊断问句，不强推 |
| **嫌慢 = 感兴趣 / 嫌多 = 还在犹豫** | 心理位移 | 跟进节奏按信号调 |

完整解码 + 中层博弈全角色见 `references/stakeholder-mapping.md` 和 `references/objection-patterns.md`。

### 2.5 取舍锚

- **EB 在场** → 高管段打满，技术段可砍
- **三角齐全** → 高管 + 技术 + 业务三段都讲
- **客户首次见面** → 高管段压到 10min，互动段拉长到 15min 摸底
- **客户已表态反对** → 互动段拉长，闭合段逼确认

## 三、后 24h 复盘

**期望产物**：debrief.md 落地（信号 diff + 5 字段动作清单 + 5 句话同步 + CRM 更新），老板 30 秒读完能做决策。

### 3.1 四件交付

1. **信号变化 diff** — 拜访前红/黄/绿 vs 拜访后实际红/黄/绿，标升级 / 持平 / 降级 / 转冷。**转冷信号**（决策人缺席 / 关键问题被回避 / 高管沉默 > 10s / 客户已选竞品）= 立即按转冷流程升级处理。
2. **下一动作清单**（5 字段）— 动作 / owner / deadline（**具体到日，「下周」= 无 deadline**）/ 验收 / 内部协调。
3. **内部同步卡**（5 句话）— ①结论（推进到了哪一步）②关键信号 ③下一动作 + owner ④风险点 ⑤需要支持。**老板 30 秒能读完并做决策**。
4. **CRM 更新** — 拜访记录 + next step + 触达频率 + Stakeholder Health 重打分。

### 3.2 取舍锚

- **信号升级** → 下一动作清单优先
- **信号转冷** → 立即按转冷流程处理，其他可推迟
- **信号持平** → 内部同步卡重点写「等什么」

完整复盘卡模板见 `references/post-visit-debrief.md`。

## 归因式反例（偷懒的后果）

| 念头 | 后果 |
|---|---|
| 没做议程确认就开讲 | 全场被拖着走，时间失控，重要项没讲到 |
| 通篇功能罗列 + 无数字 | 听完记不住，没差异化，被当「又一个供应商」 |
| 不做信任前置直接讲产品 | 中国客户不买账，30 秒丢失注意力 |
| 公开 diss 友商 | 被认为不专业，被拉黑 |
| 参会人卡片填 11 字段 | 销售没时间填，临场抓瞎 |
| ROI 给区间不给三档 | 客户不主动提数字 = 推进失锚 |
| POC 不给三档台阶 | next step 时逼不出具体动作，离场后失联 |
| 闭合段只口头承诺 | 7 天归零，无内部推力，商机停滞 |
| 送贵重礼品 / 烟酒 / 打听客户内部八卦 | 反腐合规风险 + 客户压力 |
| 不服务中层（IT/采购/法务总监） | 中层用流程把事拖黄 |
| 24h 复盘只写自己看 | 信号变化错过，下一动作延迟，商机停滞 |

## 中国 B2B 适配（差异化锚）

正文只放差异化锚，完整版下沉 reference：

- **客户不说「不」，靠信号抓取**（含蓄解码表见 §2.4 + reference）
- **中层不是反对，是「看你在不在乎我」**（给位置 + 给材料 + 让其成 Champion）
- **决策链非线性**：国央企（党委会 / 总经理办公会 / 信息化领导小组三轮）/ 民企（老板 + 副总 / 老板娘）/ 外企（全球 + 亚太 + 中国区三层）
- **反腐合规不踩雷**：礼品 ≤ 200 元 / 不送烟酒 / 离场时送 / 客户拒收就收回
- **中层博弈**（IT/采购/法务/业务总监主动挑刺 = 抢谈判筹码，**升级信号**而非降级）

完整版（座次 / 名片 / 茶位 / 陪同动线 / 离场送行 / 中层博弈全角色 / 含蓄解码扩展）见 `references/visit-meeting-etiquette.md` 和 `references/stakeholder-mapping.md`。
