# 反模式与不做

## 反模式

### 1. 跳过诊断直接报价

**偷懒做法**：跳过议价前诊断（O1-O5），直接给报价

**后果**：应对错位——客户要 POC 你给折扣；客户预算不足你给高价档

**正确做法**：先诊断动机（O1-O5），再选择应对策略

### 2. 只给 1 个报价

**偷懒做法**：只给 1 个报价（客户没选择框架）

**后果**：客户在"买 vs 不买"之间选，容易流失；议价空间小

**正确做法**：给 4 档报价（Powerhouse / Value / Baseline / Performance），客户在框架内选

### 3. 平白让步（无回报）

**偷懒做法**：客户要求折扣，直接给折扣（不换条件）

**后果**：让步无积累，每次都被继续砍；价格越来越低

**正确做法**：每让步必换回报（折扣换账期 / 案例权 / 转介绍 / 范围缩减）

### 4. 折扣超出权限未升级

**偷懒做法**：客户要求折扣超出权限，不升级审批，直接给折扣

**后果**：价格倒挂 / 红线触发 / 亏损

**正确做法**：按层级升级（销售代表 ≤5% / 销售总监 5-15% / GM 15-25% / >25% 触发红线）

### 5. 锚定竞品价格

**偷懒做法**：客户提竞品价格，跟着竞品价格议价

**后果**：进入价格战，价值被稀释；客户只看价格不看价值

**正确做法**：价值再锚定 / 差异化凸显 / 不锚定竞品价格

### 6. 编造客户 ROI / 数字

**偷懒做法**：为了成交，编造客户 ROI / 数字

**后果**：失去信任 + 后续被动；客户发现后拒绝成交 / 要求赔偿

**正确做法**：用真实数据 / 标注 [MISSING — confirm before sending] / 不编造

## 不做

### 1. 不做公司层定价

- **范围**：公司层定价（产品定价 / 市场定价）
- **原因**：上游策略，非本合同议价范围
- **替代**：交给公司定价委员会 / 产品团队

### 2. 不做合同撰写

- **范围**：合同条款撰写
- **原因**：属于 pitch 桶（交付物）
- **替代**：用 `clinch-contract-signing`

### 3. 不做死单挽回

- **范围**：已丢单复活（死单挽回，不在本 skill 范围）

### 4. 不做降温预警

- **范围**：商机降温信号识别（降温预警，不在本 skill 范围）

### 5. 不自动写回 CRM

- **范围**：自动写回 CRM / 自动发消息
- **原因**：read-only 原则（只分析，不执行）
- **替代**：手动写回 CRM / 手动发消息

### 6. 不教授关系 / 回扣

- **范围**：关系 / 回扣等违规操作
- **原因**：法律风险 / 声誉损失
- **替代**：识别客户暗示后礼貌拒绝并升级（"这个我们做不到，但可以改条款 / 范围 / 账期"）
