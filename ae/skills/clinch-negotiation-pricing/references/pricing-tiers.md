# 报价结构设计

## 4 档报价结构

| 档位 | 倍数 | 角色 | 典型内容 |
|---|---|---|---|
| Powerhouse 高锚 | 1.30-1.50x | 拉高心理价位 | 高级策略师 + 专属团队 + 全功能 + 优先支持 |
| Value ⭐ | 1.0x | 推荐档（甜蜜点） | 标准团队 + 核心功能 + 正常支持 |
| Baseline 底线 | 0.40-0.50x | 范围/服务缩减 | 基础团队 + 核心功能 + 有限支持 |
| Performance | 0.30-0.40x + bonus | 风险共担 + KPI 奖金 | 基础价低 + 成果达标后奖金触发 |

## Why These Tiers 哲学（必附）

### Why 4 档不是 3 档？

- 心理学锚定：4 档提供"选择框架"，客户在框架内选而非"买 vs 不买"
- 覆盖更广：高锚（拉高期望）+ 中主力（推荐）+ 底线（预算敏感）+ 绩效（风险厌恶）
- 避免二元对立：3 档容易变成"要么贵要么便宜"，4 档增加"风险共担"维度

### Why 中档是 1.0x？

- 中档 = 基准 = "正常应该付的价格"
- 高锚 1.3-1.5x 让中档显得合理（对比效应）
- 底线 0.4-0.5x 让中档显得"值得"（避免客户直接砍到最低）
- 绩效档 0.3-0.4x + bonus 让中档显得"稳定"（绩效档有风险）

### Why 有 Performance 档？

- 降低决策风险：客户怕买错 → 绩效挂勾对齐激励
- 对齐利益：客户付基础价 + 成果奖金 = 双方共担风险
- 适用场景：竞争激烈 / 客户决策风险大 / 新客户试水

### Why Powerhouse 1.3-1.5x 不夸张失信？

- 1.3-1.5x 是"合理溢价"：高级策略师 + 专属团队 = 成本更高 + 价值更高
- > 1.5x 会失去可信度：客户认为"这是宰我"
- 1.3-1.5x 让中档 1.0x 显得"划算"（对比效应）

## 报价文档结构

1. **档位对比表**（4 档 × 倍数 × 角色）
2. **每档详情**（交付物 / 额外项 / 排除项 / ROI 投射）
3. **Why These Tiers 哲学说明**（4 个 why）
4. **推荐档标注**（⭐ Value 档）
5. **客户选择指引**（如何选档：预算充足选 Powerhouse，预算敏感选 Baseline，风险厌恶选 Performance，不确定选 Value）

## 注意事项

- 永远不要只给 1 个报价（客户没选择框架，议价空间小）
- 永远不要给 2 个报价（客户在"买 vs 不买"之间选，容易流失）
- 3 档可以（高锚 + 中主力 + 底线），但缺"绩效风险共担"维度
- 5 档过载（客户选择困难，决策延迟）
