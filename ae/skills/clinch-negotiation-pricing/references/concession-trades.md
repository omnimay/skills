# 让步交换原则

## 铁律

**每让步必换回报**——给折扣就换条件（年限 / 付款方式 / 转介绍 / 案例权 / 范围 / 增值）

## 6 种让步换回报组合

### 1. 折扣 ↔ 提前付款 / 年付 / 多年合同

**场景**：客户要求折扣

**交换**：给折扣，换提前付款（如 Net 15 代替 Net 30）/ 年付（代替月付）/ 多年合同（代替 1 年）

**模板**：
- "我们可以给 X 折扣，但需要你同意提前付款 / 年付 / 签多年合同"

### 2. 折扣 ↔ 公开案例权 / 联合营销

**场景**：客户要求折扣

**交换**：给折扣，换公开案例权（客户同意公开合作案例）/ 联合营销（客户同意联合推广）

**模板**：
- "这个幅度我们可以接受，但需要你同意公开案例 / 联合营销"

### 3. 折扣 ↔ 成功转介绍

**场景**：客户要求折扣

**交换**：给折扣，换成功转介绍（客户承诺成功后转介绍其他客户）

**模板**：
- "我们可以给到这个折扣，但需要你承诺：项目成功后转介绍 1-2 个客户"

### 4. 折扣 ↔ 范围缩减（模块 / 用户数 / 服务期）

**场景**：客户要求折扣但预算不足

**交换**：给折扣，换范围缩减（减少模块 / 用户数 / 服务期）

**模板**：
- "如果预算有限，我们可以缩减范围：[具体方案]，价格下降"

### 5. 折扣 ↔ 产品反馈权 / 共建模块

**场景**：客户要求折扣且有产品影响力

**交换**：给折扣，换产品反馈权（客户同意参与产品反馈）/ 共建模块（客户同意共建某模块）

**模板**：
- "我们可以给到这个折扣，但需要你同意参与产品反馈 / 共建某模块"

### 6. 增值（培训 / 服务 / 模块）↔ 价格不动

**场景**：客户想要更多价值但不想多付钱

**交换**：给增值（培训 / 服务 / 模块），价格不动

**模板**：
- "价格不动，但我们可以加 [培训 / 服务 / 模块] 作为增值"

## 让步包组合

当客户要求大幅折扣（15-25%）时，准备组合让步包：

**示例**：
- 折扣 10% + 账期 Net 15（代替 Net 30）+ 公开案例权 + 成功转介绍 1 个客户

**原则**：
- 每个让步都换回报
- 多个让步组合，不单一让步
- 让步包整体价值 ≈ 客户要求的折扣幅度

## 常见错误

- **平白让步（无回报）** → 让步无积累，每次都被继续砍
- **单一让步** → 只给折扣，不换条件
- **让步过度** → 一次让到最大幅度，没有议价空间
