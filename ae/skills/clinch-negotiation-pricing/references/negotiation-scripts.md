# 议价对话策略

## 3 种应对策略

### 1. Reversal（反问）

**适用场景**：客户说不清 / 表达模糊 / 没有具体理由

**模板**：
- "太贵是相对于什么？"
- "合理价位是多少？"
- "除了价格，是否还有别的问题影响决定？"
- "您说'再考虑下'，具体是在考虑什么？"

**目标**：让客户说出真正的顾虑

### 2. Reframe（重新框架）

**适用场景**：客户有固定认知 / 锚定竞品价格 / 只看价格不看价值

**模板**：
- "换个角度：3 年单价其实只有..."
- "如果不解决这个问题，每年的损失是..."
- "竞品价格更低，但他们的 [关键差异] 是..."
- "我们理解您想省钱，但省钱不等于省钱——关键是 ROI"

**目标**：从不同角度重新定义问题

### 3. Clarify（澄清）

**适用场景**：客户表达模糊 / 有多个顾虑 / 需要优先级排序

**模板**：
- "当然可以；想确认一下：除了价格，是否还有别的问题影响决定？"
- "您提到 [X]，具体是指什么？"
- "如果我理解正确，您最关心的是 [X]，对吗？"

**目标**：确认客户真正在意的点

## 砍价幅度分级应对

### < 5%（小幅砍价）

**应对**：接受换条件

**标准回复**：
- "我们可以给到 X 折扣，但需要你同意提前付款 / 年付 / 签多年合同"
- "这个幅度我们可以接受，但需要换个条件：[具体条件]"

**目标**：让步换回报，不让步白给

### 5-15%（中幅砍价）

**应对**：让步换回报

**标准回复**：
- "这个幅度需要升级审批，但我会帮你争取——同时需要你同意 [条件]"
- "我们可以给到这个幅度，但需要换条件：[案例权 / 转介绍 / 范围缩减]"

**目标**：让步换回报，积累议价资本

### 15-25%（大幅砍价）

**应对**：升级 + 让步包

**标准回复**：
- "这个幅度超出我权限，我会帮你升级到销售总监 / GM"
- "同时我们准备一个让步包：[折扣] + [账期] + [案例权] + [转介绍]"

**目标**：升级审批 + 准备组合让步包

### > 25%（超幅砍价）

**应对**：触发红线 → 改范围 / 服务 / 账期

**标准回复**：
- "这个价格我们做不到——成本线在这里"
- "但我们可以改范围 / 服务 / 账期：[具体方案]"
- "或者您考虑 Baseline 档（0.4-0.5x）——范围缩减，价格下降"

**目标**：不改价格，改范围 / 服务 / 账期

## 常见错误

- **平白让步（无回报）** → 让步无积累，每次都被继续砍
- **跳过诊断直接应对** → 应对错位，客户要 POC 你给折扣
- **锚定竞品价格** → 进入价格战，价值被稀释
- **编造客户 ROI / 数字** → 失去信任 + 后续被动
