# 报价阶段风险登记

## 10 类风险（三维评估）

| 风险 | 含义 | severity | likelihood | confidence |
|---|---|---|---|---|
| 报价后沉默 | 报价后长时间无回应 | 高 | 中 | 中 |
| 砍价过大 | 客户要求折扣 > 我方底价 | 高 | 中 | 中 |
| 要求免费试用 | 客户要求先免费用一段时间 | 中 | 高 | 高 |
| 要求加量不加价 | 客户要求扩展范围但价格不变 | 中 | 中 | 中 |
| 审批流程拖延 | 客户内部审批链过长 | 中 | 高 | 高 |
| 竞品压价 | 客户用竞品价格压我方 | 高 | 中 | 中 |
| 合同条款分歧 | 双方对账期 / 质保 / SLA 有分歧 | 中 | 中 | 中 |
| 账期分歧 | 客户要求超长账期 | 中 | 中 | 中 |
| 价格红线触发 | 客户要求折扣超出 25% 红线 | 高 | 低 | 高 |
| 价格倒挂 | 折扣后低于成本 / 渠道价 | 高 | 低 | 高 |

## 三维评估矩阵

### severity（严重度）

- **高**：可能导致丢单 / 亏损 / 价格倒挂
- **中**：可能导致延迟 / 范围缩减 / 条款分歧
- **低**：可能导致小幅让步 / 账期调整

### likelihood（可能性）

- **高**：很可能发生（>70%）
- **中**：可能发生（30-70%）
- **低**：不太可能发生（<30%）

### confidence（置信度）

- **高**：多源互证 / 有书面证据
- **中**：单源可信 / 部分推断
- **低**：弱证据 / 旧信息 / 矛盾

## 风险应对策略

### 报价后沉默

**应对**：
- 24h 内跟进（电话 / 微信 / 邮件）
- 提供额外信息（ROI 计算 / 案例 / FAQ）
- 询问是否需要调整报价结构

### 砍价过大

**应对**：
- 诊断动机（O1 预算不足 / O2 价格对比 / O3 决策风险）
- 价值再锚定 / 差异化凸显
- 准备让步包（折扣换回报）
- 升级审批（5-15% / 15-25%）

### 要求免费试用

**应对**：
- POC（付费 POC / 试用转付费）
- 绩效挂勾（基础价 + 成果奖金）
- 退订条款（30 天退订）

### 要求加量不加价

**应对**：
- 范围缩减（减少模块 / 用户数 / 服务期）
- 增值（培训 / 服务 / 模块）换价格不动
- 分阶段交付（先基础版，后续扩展）

### 审批流程拖延

**应对**：
- 识别决策链（幕后老板 / 中间人 / 审批层级）
- 提供内部说服材料（ROI 计算 / 案例 / FAQ）
- 缩短审批周期（提供限时优惠 / 优先支持）

### 竞品压价

**应对**：
- 价值再锚定（不锚定竞品价格，锚定价值）
- 差异化凸显（关键差异 / 独特优势）
- 不进入价格战（改条款 / 范围 / 账期）

### 合同条款分歧

**应对**：
- 识别分歧点（账期 / 质保 / SLA）
- 提供替代方案（灵活账期 / 延长质保 / 升级 SLA）
- 让步换回报（折扣换账期 / 质保 / SLA）

### 账期分歧

**应对**：
- 灵活账期（Net 15 / Net 30 / Net 60）
- 折扣换账期（提前付款折扣）
- 分期付（首付 + 尾款）

### 价格红线触发

**应对**：
- 不改价格，改条款 / 范围 / 账期
- 提供 Baseline 档（0.4-0.5x）——范围缩减，价格下降
- 升级审批（GM 审批）

### 价格倒挂

**应对**：
- 立即停止让步
- 重新评估成本结构
- 提供 Baseline 档 / Performance 档
- 放弃客户（如果无法盈利）

```markdown
| 2 | ... | ... | ... | ... | ... |
```

## 常见错误

- **跳过风险评估** → 报价后被动应对
- **低估风险** → 准备不足，丢单
- **高估风险** → 过度让步，亏损
