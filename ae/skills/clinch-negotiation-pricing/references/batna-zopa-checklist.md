# BATNA + ZOPA 准备清单

## BATNA（Best Alternative to a Negotiated Agreement）

### 客户 BATNA 清单

列出客户的最优替代方案：

1. **竞品 A**：[名称] / [价格] / [功能] / [适配度]
2. **竞品 B**：[名称] / [价格] / [功能] / [适配度]
3. **竞品 C**：[名称] / [价格] / [功能] / [适配度]
4. **自建**：时间 [X 月] + 成本 [X 万] + 风险 [高/中/低]
5. **不买**：痛点持续成本 [X 万/年] + 机会成本 [X 万/年]

### 我方 BATNA 清单

列出我方的最优替代方案：

1. **其他客户**：是否有类似需求的其他客户？
2. **产品调整**：是否可以调整产品适应其他市场？
3. **放弃**：放弃此客户的成本 [X 万] + 机会成本 [X 万]

## ZOPA（Zone of Possible Agreement）

### 议价区间计算

- **客户底线**：基于客户预算 + 决策链 + 痛点强度 + 竞品价格
- **我方底价**：基于成本 + 折扣权限 + 战略价值 + 长期收益
- **议价区间**：[客户底线, 我方底线]

### 议价目标

- **目标落点**：ZOPA 中位偏上（不锚定我方底价）
- **理想结果**：接近我方底线（但不超过客户底线）
- **可接受结果**：ZOPA 中位（双方都满意）
- **底线结果**：接近客户底线（但仍在盈利区间）

## 准备步骤

1. **收集信息**：客户预算 + 竞品报价 + 决策链 + 痛点强度
2. **计算客户 BATNA**：列出客户的最优替代方案
3. **计算我方 BATNA**：列出我方的最优替代方案
4. **确定客户底线**：基于客户 BATNA 估算
5. **确定我方底价**：基于成本 + 折扣权限 + 战略价值
6. **计算议价区间**：[客户底线, 我方底线]
7. **设定议价目标**：ZOPA 中位偏上

## 常见错误

- **跳过 BATNA 准备** → 不知道客户底线，议价被动
- **只准备我方底价** → 不知道客户 BATNA，无法价值锚定
- **锚定我方底价** → 失去议价空间，客户砍价就接受
- **没有 ZOPA 概念** → 不知道议价区间，容易让步过度
