# 中国场景适配

## 中国特殊因素

### 1. RMB 计价

- 人民币（RMB）计价，百万 / 千万级单位
- 含税 / 不含税
- 增值税发票（专票 / 普票）

### 2. 微信 / 企微议价沟通

- 主要沟通渠道：微信 / 企微（非邮件）
- 电话议价：重要但常用于"重大让步"前
- 微信议价技巧：文字 + 语音 + 表情包（缓和气氛）

### 3. 合同条款博弈

#### 招投标

- 评分规则：技术分 vs 价格分
- 投标策略：技术方案高分 + 价格分合理
- 避免低价中标（价格分高但技术分低）

#### 三方比价

- 客户要求三方比价（至少 3 家供应商报价）
- 应对：提供差异化价值，不进入价格战
- 模板：[报价单] + [技术方案] + [案例]

#### 账期

- 常见账期：Net 30 / Net 60 / Net 90
- 月结 / 季结 / 年结
- 折扣换账期：提前付款折扣

#### 质保

- 常见质保期：1 年 / 2 年 / 3 年
- 质保范围：硬件 / 软件 / 服务
- 延长质保：收费服务

#### SLA（服务等级协议）

- 响应时间：1h / 4h / 24h
- 解决时间：4h / 24h / 72h
- 可用性：99.9% / 99.95% / 99.99%
- 升级 SLA：收费服务

### 4. 决策链识别

#### 幕后老板

- 表面决策人：CEO / 总经理
- 幕后老板：实际控制人 / 大股东 / 家族成员
- 识别方法：多次沟通后发现决策人变化 / 关键决策需"请示"

#### 中间人

- 中间人角色：介绍人 / 顾问 / 关系人
- 中间人利益：佣金 / 回扣 / 关系维护
- 应对：识别中间人利益，但不教授违规操作

#### 审批层级

- 常见审批层级：部门经理 → 总监 → VP → CEO
- 审批周期：1 周 / 2 周 / 1 月
- 缩短审批：提供限时优惠 / 优先支持

### 5. 项目制 / 年度框架协议 / 试用转付费

#### 项目制

- 常见于：软件开发 / 系统集成 / 咨询服务
- 付款节点：首付 30% + 里程碑 30% + 验收 30% + 质保 10%
- 风险：项目延期 / 范围变更 / 验收不通过

#### 年度框架协议

- 常见于：长期合作 / 多项目合作
- 框架内容：价格 / 服务范围 / SLA / 账期
- 优势：锁定客户 / 简化流程 / 降低议价成本

#### 试用转付费

- 常见于：SaaS / 软件 / 服务
- 试用期：7 天 / 14 天 / 30 天
- 转付费：试用结束后自动转为付费
- 风险：客户不转化 / 试用滥用

## 中国适配注意事项

### 1. 关系 / 回扣

- **不教授**：关系 / 回扣等违规操作
- **识别**：客户暗示"要回扣"的信号
- **应对**：礼貌拒绝并升级（"这个我们做不到，但可以改条款 / 范围 / 账期"）

### 2. 隐性决策人

- **识别**：幕后老板 / 中间人 / 审批层级
- **应对**：多次沟通确认决策人 / 提供内部说服材料

### 3. 价格敏感度高

- **现象**：中国市场价格敏感度高，客户习惯"先砍 30%"
- **应对**：高开策略 + 守底价话术 + 不锚定竞品价格

## 常见错误

- **忽略微信 / 企微沟通** → 沟通渠道错配
- **忽略决策链识别** → 议价对象错误
- **教授违规操作** → 法律风险 / 声誉损失
