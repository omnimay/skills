# 折扣权限分层

## 3 级折扣权限

### 1. 销售代表（≤5%）

**权限范围**：≤5% 折扣

**升级条件**：无（销售代表可直接决定）

**适用场景**：小幅砍价（< 5%）/ 客户诚意合作 / 快速成交

### 2. 销售总监（5-15%）

**权限范围**：5-15% 折扣

**升级条件**：客户潜力量 / 竞争态势

**适用场景**：中幅砍价（5-15%）/ 战略性客户 / 竞争激烈

### 3. GM（15-25%）

**权限范围**：15-25% 折扣

**升级条件**：战略性大客户 / 对标竞争

**适用场景**：大幅砍价（15-25%）/ 战略性大客户 / 对标竞争

### 4. 不允许（>25%）

**权限范围**：>25% 折扣

**升级条件**：触发红线 → 改条款 / 范围 / 账期

**适用场景**：超幅砍价（>25%）→ 触发价格红线 → 改条款 / 范围 / 账期

## 折扣权限管理原则

### 1. 按层级授权

- 销售代表：≤5%
- 销售总监：5-15%
- GM：15-25%
- 不允许：>25%

### 2. 升级路径

- 客户要求折扣超出当前层级 → 升级审批
- 升级审批需准备：客户潜力量 / 竞争态势 / 战略价值 / 长期收益

### 3. 红线触发

- 客户要求折扣 >25% → 触发价格红线
- 红线触发后：不改价格，改条款 / 范围 / 账期

## 常见错误

- **折扣超出权限未升级** → 价格倒挂 / 红线触发
- **越级审批** → 破坏折扣权限体系
- **没有升级路径** → 客户要求折扣超出权限，无法应对
