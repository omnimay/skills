# 议价动机分类体系

## 5 类议价动机（O1-O5）

| 动机 | 典型表现 | 应对方向 |
|---|---|---|
| O1 预算不足 | "预算被砍了" / "跨年度审批" / "能否分期" | 账期分期 / 范围缩减 / 多年合同分摊 |
| O2 价格对比 | "竞品 X 报价更低" / "能否对标" / 反复要求价格解释 | 价值再锚定 / 差异化凸显 / 不锚定竞品价格 |
| O3 决策风险 | "怕买错" / "能否先试用" / "能否分阶段上线" | POC / 试用 / 绩效挂勾 / 退订条款 |
| O4 政治因素 | 内部反对 / 多人决策冲突 / 推动者失势 | 帮客户找内部支持 / 提供内部说服材料 |
| O5 优先级 | "真不急" / "还在评估其他选项" / "Q3 再谈" | 重塑紧迫感 / 搁置 / 价值触发 |

## 诊断步骤

1. **收集线索**：客户原话 + 上下文（谁说的、什么场景、是否有书面证据）
2. **归类动机**：匹配 O1-O5 之一或组合（如 O1+O3 = 预算不足+决策风险）
3. **验证假设**：通过提问确认（"除了价格，是否还有别的问题影响决定？"）
4. **选择应对**：基于动机选择对应策略（详见 negotiation-scripts.md）

## 常见误判

- **把 O2（价格对比）误判为 O1（预算不足）** → 错误给折扣，客户仍对比竞品
- **把 O4（政治因素）误判为 O5（优先级）** → 客户内部有人反对，你只是搁置
- **跳过诊断直接报价** → 应对错位，客户要 POC 你给折扣
